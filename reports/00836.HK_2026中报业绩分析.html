中性偏谨慎

华润电力 2026 中报营业额 549.77 亿港元（+9.4%，人民币口径 484.73 亿、+4.6%）、归母净利润 66.49 亿港元（−15.5%）、核心业务利润 69.72 亿港元（−15.8%）、每股基本盈利 1.28 港元（−15.8%）。业绩呈现典型「营收增、利润降、结构分化」：售电量 +12.8%（光伏 +42.8%、火电 +16.9%）驱动营收增长，但综合上网电价同比 −7.2%（燃煤 −7.0%、风电 −6.3%、光伏 −9.2%）、风电利用小时 −19.0%（风速下降）致可再生能源核心利润 −30.7%；火电核心利润逆势 +16.1%（煤价温和、利用小时 +0.5%、市场化让利有限）。亮点在财务端：现金及等价物 331.53 亿港元（较年初 +184%）、净负债/总权益由 150.8% 降至 115.5%、华润新能源分拆 A 股上市募资；应占联营/合营业绩分别 +141%/+71%（山西中润铝业、甘肃常乐、英国海上风电等）与出售附属公司收益 +223.8% 部分对冲主业下滑。需关注：煤电发电量占比历史性跌破 50%、电价市场化持续下行、风电气候依赖、流动负债净额 270 亿港元与净负债率仍偏高。估值偏低（收 18.66 港元、PE(TTM) 7.27x、PB 0.87x 破净、股息率 TTM 6.04%），具高股息+破净防御价值，但盈利趋势承压。

✓ 核心利好
  • 营收增、利润降、结构分化：H1 营业额 549.77 亿港元（+9.4%，人民币口径 +4.6%）、归母 66.49 亿港元（−15.5%）、核心业务利润 69.72 亿（−15.8%）、EPS 1.28 港元（−15.8%）。售电量 +12.8%（光伏 +42.8%、火电 +16.9%）驱动营收，但综合电价 −7.2% + 风电利用小时 −19% 致利润下滑。
  • 火电改善对冲可再生下滑：火电核心利润 30.65 亿港元（+16.1%，煤价温和、利用小时 +0.5%），可再生能源核心利润 39.07 亿（−30.7%，风电 −19% 利用小时 + 电价下行）；联营合营业绩分别 +141%/+71%（山西中润铝业、甘肃常乐、英国海上风电）与出售附属公司收益 +223.8% 部分缓冲主业。
  • 财务端显著去杠杆：现金及等价物 331.53 亿港元（较年初 +184%）、净负债/总权益由 150.8% 降至 115.5%、总负债/总资本 57.6%；华润新能源分拆 A 股上市募资优化资本结构（控股权益 83.80%→81.81%）。
  • 低估值破净高股息：收 18.66 港元、PE(TTM) 7.27x、PB 0.87x（破净）、股息率 TTM 6.04%、派息率 25.0%（逆势 +1.6pp）；机构平均目标价约 20.81 港元（+11.5%），具防御配置价值。
⚠ 核心风险
  • 电价市场化持续下行（核心红旗）：2026H1 综合上网电价 −7.2%（燃煤/风电/光伏 −7.0%/−6.3%/−9.2%），煤电发电量占比历史性跌破 50%（49.7%），清洁能源优先消纳 + 市场化交易压低结算电价，盈利趋势承压。
  • 风电利用小时骤降 / 气候依赖（核心红旗）：风电利用小时 −19.0%（风速下降）直接致可再生核心利润 −30.7%；气候不可控，短期波动显著，H2 风资源回归程度决定修复幅度。
  • 债务结构与流动性偏弱：净负债/权益 115.5%、流动比率 0.76、流动负债净额 270 亿港元，存在短债缺口依赖再融资；煤价阶段性反弹（标煤 +1.0%）压缩火电点火价差；减值（郑州气电项目 4.17 亿）+ 应收 +12.3% 需跟踪。

预期来源与统计时点：无单季一致预期（港股卖方以全年预测为主，统计时点 2026-08-26 中报后）。按 v2 修正 B 全年进度校验：① 2025 全年营收 1,020 亿港元、归母 145.19 亿港元；市场对 2026E 营收预期约 1,050–1,100 亿港元、归母约 130–150 亿港元；H1 营收 549.77 亿约占全年 50%、归母 66.49 亿约占 46%–51%，符合季节性（H2 通常略弱于 H1 因冬季风资源波动、电价淡季）。② 长桥证券评述「业绩优于预期（came in ahead of expectations）」——尽管归母 −15.5%，但火电改善 + 联营合营大增抵消了可再生下滑，市场反应正面（公告日股价 +2.1%）；机构 16 家评级 7 强买/7 买入/2 卖出，平均目标价约 20.81 港元（+11.5%）。H1 业绩处预期上沿，结构优于同业（华能 −28.9%、中国电力 −50.8%）。

行业坐标与供需

行业所处阶段与传导方向：电力行业处于「能源转型阵痛、煤电历史性拐点」阶段：2026 上半年煤电发电量占全国总发电量比重降至 49.7%，自有统计以来首次跌破 50%，清洁能源优先消纳挤占煤电出力空间；同时市场化交易电量占比快速扩围（华润电力已达 96.2%，同比 +11.8pp），新能源边际成本低，持续压低结算电价（燃煤 −7.0%、风电 −6.3%、光伏 −9.2%）。煤价 2026H1 阶段性反弹（标煤单价 +1.0%），「电价降 + 煤价升」压缩火电点火价差（华润 −30.4 元/MWh 至 119.5 元）。行业主线：煤电从「卖电量」转向「容量 + 灵活性 + 调节服务」多元盈利；新能源「量增价跌」回归理性投资（国电电力风光归母 −25%/−62%）；水电受益来水与集中投产。华润电力以「火电压舱石 + 风光成长 + 联营合营」组合应对。

量价 / 供需 / 价格位置 / 政策：① 装机：2026-06 管理并网 105,700 MW、附属并网 88,944 MW；火电 42,970 MW（占 48.3%）、风+光+水 45,974 MW（占 51.7%，较年初 +0.9pp）；风电 29,495 MW（在建 6,647）、光伏 16,008 MW（在建 5,830）；H1 新增新能源并网 1,583 MW（风 808 + 光 775），获可再生能源开发指标 4,410 MW。② 电量：附属售电量 120,436,401 MWh（+12.8%），光伏 +42.8%、火电 +16.9%、风电 −3.2%（风速下降）；风电利用小时 1,027（−19.0%）、光伏 581（−14.1%）、燃煤 2,081（+0.5%）；市场化定价占比 96.2%（+11.8pp）。③ 电价：燃煤 364.0 元/MWh（−7.0%）、风电 371.8 元/MWh（−6.3%）、光伏 276.7 元/MWh（−9.2%）；燃煤点火价差 119.5 元/MWh（−30.4 元）。④ 燃料：标煤单价 832.3 元/吨（+1.0%）、单位售电燃料成本 244.5 元/MWh（+1.3%）、供电煤耗 287.73 g/kWh（−0.8%）。⑤ 资本开支：H1 现金资本开支 144.47 亿港元（可再生 111.66 + 火电 20.60 + 技改 6.47 + 煤矿尾款 1.19 + 综合能源 4.55），全年预计约 472 亿港元。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：重资产、高杠杆公用事业，以ROIC−WACC 衡量价值创造（v2 修正 C，允许定性）。估算（H1 半年口径年化）：NOPAT ≈ 归母净利 66.49 亿×2 ≈ 133 亿（财务费用净与少数股东调整小）；投入资本 IC = 总权益 1,664 亿 ＋ 净负债（借贷 2,257 − 现金 331 − 受限存款 3 ≈ 1,923 亿）≈ 3,587 亿；ROIC（年化）≈ 133 / 3,587 ≈ 3.7%（半年口径约 1.85%）。WACC ≈ 6.5%（电力 β 偏低、债权占 57%、股权 43%、税后加权）。ROIC−WACC ≈ −2.8pp，价值创造偏弱——这是受监管公用事业的普遍特征：回报靠「监管允许的合理资本回报 + 规模扩张 + 新能源成长」驱动，而非超额资本回报；当前电价下行 + 风电利用小时骤降进一步压制 ROIC。投资逻辑更偏「高股息 + 破净 + 资产重估（华润新能源分拆）」而非 ROIC 扩张（v2 修正 C 允许定性）。

增长归因（量 / 价 / 成本 / 非经）：量：营业额 549.77 亿港元（+9.4%，人民币口径 +4.6%），主因附属售电量 +12.8%（光伏 +42.8%、火电 +16.9%）抵消综合上网电价 −7.2%；其中火电分部收入 403.06 亿（+12.7%）、可再生能源分部收入 146.71 亿（+1.2%）。价：净利率 12.87%（−3.8pp，归母 66.49/营业额 549.77）、经营利润率 17.76%（−6.6pp），电价下行 + 风电利用小时骤降拖累 margin；但火电点火价差仍维持 119.5 元/MWh 为正。成本：总经营成本 459.30 亿港元（+17.9%，快于营收 +9.4%）：燃料 260.30 亿（+19.9%，售电量增 + 标煤单价 +1.0%）、折旧摊销 105.96 亿（+21.8%，新项目投产）、员工 +2.3%、减值 +15.7%（郑州航空港气电项目计提 4.17 亿）。投资/其他：应占联营企业业绩 15.93 亿（+141%，山西中润铝业、甘肃常乐电厂、重庆能源）、应占合营 +71%（英国海上风电、锦州电厂）、其他损益 +223.8%（出售附属公司收益 2.30 亿），合计增厚利润约 +12 亿港元，部分对冲主业下滑。结论：归母 −15.5% = 可再生 −30.7%（风电 −19% 利用小时 + 电价 −6.3%）− 电价市场化下行 − 政府补助减少（其他收入 −39.7%）＋ 火电 +16.1% ＋ 联营合营 +141%/+71% ＋ 出售收益；经营基本盘承压但被多元收益部分缓冲。

盈利质量（扣非 vs 归母，真 / 虚）：质量「真」、无会计粉饰。核心业务利润 69.72 亿港元（−15.8%）与归母 66.49 亿（−15.5%）降幅一致，差额仅 3.23 亿为永久资本证券持有人（93.7 百万）与少量非经常性；非经常性损益小：其他损益 +2.59 亿（含出售附属公司收益 2.30 亿、属偶发）、减值 4.72 亿（含郑州气电项目 4.17 亿一次性，非洗大澡）。现金验证：经营现金流净额 102.14 亿港元（−27.6%，主因应收增加、税费支付），OCF/归母 ≈ 154%（仍 >100%）；现金及等价物较年初 +184% 至 331.53 亿（含华润新能源分拆募资），盈利有现金支撑、无背离。

业务分部与地区拆解
华润电力按运营及可呈报分部披露（2026 中报，港元）：
• 火力发电（含燃煤/燃气/煤炭生产） 外部收入 403.06 亿（+12.7%）、分部税前利润 40.62 亿（−0.2%）、本公司拥有人应占核心业务利润 30.65 亿（+16.1%）——压舱石，受益煤价温和、利用小时 +0.5%、市场化让利有限；纯火电（不含煤炭）核心利润 27.97 亿（+0.3%）。
• 可再生能源（风/光/水） 外部收入 146.71 亿（+1.2%）、分部税前利润 52.41 亿（−24.5%）、本公司拥有人应占核心业务利润 39.07 亿（−30.7%）——主拖累，风电利用小时 −19.0%（风速下降）、风电电价 −6.3%、光伏电价 −9.2%。
增量利润归因：火电 +4.24 亿 vs 可再生 −17.30 亿，结构分化显著；联营合营 +12 亿、出售收益 +1.79 亿为边际增量缓冲。地域：绝大部分资产与运营位于中国（人民币），呈列货币为港元，存在功能/呈列货币折算差异。
资产负债与周转效率
资本结构（高杠杆、较年初显著去化）：总负债/总资本 57.6%、净负债/总权益 115.5%（较年初 150.8% −35.3pp，大幅改善）；借贷 2,256.63 亿港元（较年初 2,135.08 亿 +5.7%），但现金及等价物 331.53 亿（+184%）、受限存款 3.26 亿，净债显著下降（华润新能源分拆募资 + 经营积累）。
流动性（偏弱、需关注）：流动比率 0.76（年初 0.52）、速动比率 0.72（年初 0.47），流动负债净额 270.03 亿港元（公司说明可持续经营、银行授信充足）；现金短债比（现金 331.53 / 短期借贷 648.52）≈ 0.51x，短期偿债依赖再融资与经营回流。
资产质量与周转：应收账款、其他应收及预付款项 478.64 亿（年初 426.02 亿，+12.3%，快于营收 +9.4%），账龄 60 日以上占 70.8%（新能源补贴结算周期长，行业特性）；存货 53.88 亿（+4.6%，稳定）；商誉 11.08 亿（年初 10.75 亿，占净资产 0.91%，无泡沫）；固定资产（PPE）2,909 亿（+4.4%，新项目投产）。
现金流健康度

现金流匹配度：回落但仍健康。经营现金流净额 102.14 亿港元（−27.6%，去年同期 141.16 亿），主因应收增加（新能源补贴回款周期）、税费支付增加、存货微增；OCF/归母 ≈ 154%，现金含量仍 >100%，盈利有真金白银支撑。现金及等价物较年初 +184% 至 331.53 亿（含华润新能源分拆上市募资净额 243.47 亿港元 + 经营净流入 102 亿 + 借贷净增）。盈利现金含量：经营现金流虽降，但远高于归母净利，无借钱分红迹象。

OCF 拆解归因（v2 修正 E）：OCF 拆解（亿港元）：经营流入净额 102.14（−27.6%）。关键项：① 收款端：应收账款账龄 0–30 日 98.83 亿、31–60 日 9.51 亿、60 日以上 261.93 亿（合计 370.27 亿应收，新能源补贴结算周期长）；电费一般 30 日内到账，但风光超出火电标杆价部分需待政府补贴目录拨付、周期长。② 资本开支：H1 现金 CapEx 144.47 亿（可再生 111.66 为主），投资活动净流出 140.26 亿（去年同期 −207.64 亿，同比下降因部分由募资覆盖）。③ 税费支付：所得税 + 其他税费随利润与产量增；④ 华润新能源分拆：募资净额 243.47 亿港元显著改善现金。归因：OCF 回落主因营运资金（应收 + 补贴回款慢）占用，非盈利质量恶化。

自由现金流与覆盖能力：由经营现金流与募资共同覆盖。H1 CapEx（现金）144.47 亿港元，FCF = OCF 102.14 − CapEx 144.47 ≈ −42 亿（半年口径为负，因新能源建设高峰）；但融资活动净流入 246.62 亿（含华润新能源分拆募资 243.47 亿 + 借贷净增 100 亿 − 偿债 412.74 亿 − 利息 24.52 亿），充分覆盖投资与分红。覆盖能力：净负债/权益降至 115.5%、现金 331.53 亿，中期分红 16.62 亿港元（占 H1 归母 25.0%）由经营现金流充分覆盖，分红可持续、非借钱分红；全年 CapEx 约 472 亿由经营 + 债务 + 权益融资组合支撑。

估值与股东回报

相对估值水位：低估值、破净、高股息。以 2026-08-26 收盘价 18.66 港元计：总市值约 966 亿港元，PE(TTM) 7.27x、PB(LF) 0.87x（破净）、股息率 TTM 6.04%。A 股 2025 全年 EPS 2.80 港元、每股净资产约 21.5–23.5 港元（PB 0.79–0.87x）。相对同业（华能国际 PE ~8x、国电电力 PE ~13x、中国电力 PB ~0.6x），华润电力估值处历史低位、PB 破净反映对电价下行与盈利趋势的悲观预期；机构 16 家评级 7 强买/7 买入/2 卖出，平均目标价约 20.81 港元（+11.5%），部分来源目标价区间 21–27 港元。

周期正常化估值（v2 修正 F）：电力公用事业受监管、盈利波动主要来自电价/来水/风速，利润正常化以中性电价 + 正常风资源还原（v2 修正 F）。当前 2026H1 风电利用小时 −19%（气候异常偏低）、若回归正常（约 1,200 小时）可再生利润可修复 +20%–30%；中性电价假设下 2026E 归母约 135–150 亿港元。正常化 PE = 966 亿港元 / 140 亿（中性年化归母）≈ 6.9x；若按 2025 全年 145 亿则 ~6.7x。结论：PE(TTM) 7.27x + PB 0.87x（破净）+ 股息率 6% + 华润新能源分拆资产重估，估值偏低；当前低价已反映电价下行与风电气候风险，下行有破净+高股息托底，上行取决于电价企稳、风资源正常化与新能源补贴回款加速。

股东回报可持续性：高股息、派息率提升。2026 中期股息每股 0.321 港元（含税，同比 −9.8%，因归母下滑），按已发行股份 51.77 亿股合计约 16.62 亿港元，派息率 25.0%（同比 +1.6pp，逆势提升）；2025 全年合计派息 1.127 港元/股（中期 0.356＋末期 0.771），2026 全年若按 2× 中期则约 0.642 港元、股息率 TTM 约 3.4%，但加 2025 末期后 TTM 股息率约 6.04%。可持续性：经营现金流 102 亿 + 现金 331 亿充分覆盖，非借钱分红；华润集团控股、分红政策稳定。回购：本期无普通股回购（资产负债表明确「无购买、出售或赎回上市证券」）。资本配置以「高分红 + 新能源 CapEx + 华润新能源分拆」为主。

管理层指引与前瞻
「十五五」开局、转型与回报并重：2026 年现金资本开支预计约 472 亿港元，聚焦沙戈荒大型风光基地、海上风电、中东部优质项目，并做优煤电基本盘（「一厂一策」提质增效）。电量/电价：随新能源装机增长售电量续增，但市场化电价承压（长协电价下降）；煤电点火价差维持 119.5 元/MWh。股东回报：维持约 25%–40% 派息率区间、高股息政策；华润新能源（A 股 2026-07-02 深交所上市）分拆募资优化资本结构（控股权益由 83.80% 摊薄至 81.81%）。风险敏感：煤电发电量占比跌破 50%、电价市场化、风电利用小时波动、煤价反弹、人民币/港元汇率。（前瞻性陈述，非承诺）
同业可比与相对表现
电力板块可比（2026 中报/最新）：
• 华润电力：归母 66.49 亿（−15.5%）、PB 0.87x（破净）、PE(TTM) 7.27x、股息率 6.04%、净负债/权益 115.5%——火电+可再生综合、结构分化（火电+16.1% vs 可再生−30.7%）、去杠杆显著。

• 长江电力：水电稳健、来水驱动，与华润电力电源结构差异大。
