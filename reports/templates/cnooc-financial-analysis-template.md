# 中国海洋石油财报分析模板

适用范围：中国海洋石油有限公司（00883.HK / 600938.SH）季度、中期及年度报告、业绩公告和相关运营资料。

本模板固定核验方法，不固定结论；不包含任何一期财报的预设数字，也不默认油价上涨必然带来利润增长、低市盈率代表低估，或高分红可以持续。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充去年同期、上期报告、年度储量报告、资本开支及产量指引、股息公告。用作预期或行业比较的资料必须能注明来源和日期。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 报告期、准则、价格资料或储量数据不足时，继续完成可核实部分，并注明“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的中国海洋石油财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析油气价格、销量与产量、单位成本、储量和项目进度、资本开支及现金流。没有原始数据或可靠预期时，不要反推或作确定性结论。

### B. 强制执行规则

1. **派生数字用 Python 计算。** 同比、环比、百分点、单位换算、量价分解、储量比率、单位成本、现金流、净现金及估值均以原始数计算；使用 `Decimal` 或等价精确计算。无法运行代码时明确说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”。每个估算列出公式、输入、假设和敏感性，不伪装成公司披露值。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”。不因附注未提及就写“没有风险”。
4. **范围、期间和单位必须一致。** 区分合并与母公司、权益产量与总产量、产量与销量、单季与累计、人民币与美元、桶与桶油当量、金额发生额与现金支付额。
5. **先核对会计列报再归因。** 投资收益、联营合营损益、汇兑、商品套期或其他衍生工具、税费及减值可能列在不同位置；先按当期报表和附注确认，不重复加减或统称为“主业”。
6. **关键判断溯源。** 为重大数字和风险标注公告名称、日期、页码或附注；行业价格、储量标准、同业数据标注来源、时点、币种和口径。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查重述、汇率、单位、权益比例、并表范围和取整。原因未证实前保留差异。
8. **不预设周期结论。** 油价上涨不自动等于销量增长、单位成本下降或利润质量提高；油价回落也不自动代表公司亏损。结论须结合成本、财政条款、税费、汇率、储量和项目进度。
9. **市场预期必须可核验。** 一致预期须注明数据来源、统计时点及采用的利润口径。没有可核验预期时，明确写“无可核验一致预期”，改做公司指引进度或历史区间比较，不得以媒体标题、事后股价反应或分析师自行外推冒充市场预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日和估值日；期后事项单独列示，不作为报告期已经实现的业绩证据。

### C. 数据抽取与底稿

先建立统一数据底稿，再生成表格、图表与结论。至少包括以下字段：

| 字段 | 要求 |
|---|---|
| 指标及原科目 | 保留公告原名；说明所属报表、业务或运营口径 |
| 期间及类型 | 起止日期；单季、累计、期末余额、期初期末变动或日均 |
| 数值及单位 | 原数、币种、单位、正负号、精度；换算须列公式 |
| 范围 | 合并、母公司、权益应占、总量或净量；A/H 股信息分别记录 |
| 数据状态 | 披露原数、同口径差减、估算、未披露、未提供、不适用 |
| 来源 | 文件、公告日、页码、附注、原文定义、是否重述 |
| 计算链 | 公式、比较基数、假设、限制及校验结果 |

**最低财务数据集：**利润表、资产负债表、现金流量表及附注；油气销售、成本、税费、减值、投资收益、借款、弃置义务和资本开支资料；可得时补充各季度累计报表、储量及运营资料。

**最低行业及运营数据集：**

- 原油、天然气分别记录权益产量、销售量、平均实现价格、币种与单位。区分总产量、权益产量、净产量及销售量，不以一种替代另一种。
- 尽可能取得跨年度的可比序列，建议至少 8 个季度；不足时标注序列长度，并降低周期位置、季节性及趋势判断的置信度。
- 记录主要油价基准（如 Brent、Dubai 或合同引用基准）的期间均价、来源与统计口径；公司实现价格与基准价格分别列示。
- 记录天然气定价机制、地区、长协或现货等披露信息；不得用原油价格代替气价。
- 记录油气单位成本的公司定义、所含成本项目、币种、分母（产量或销量）和比较期。公司“主要成本”“桶油成本”“lifting cost”等术语不能未经定义直接横向比较。
- 可取得时记录储量类别、净权益口径、评估标准、储量接替、储量寿命、开发井及投产项目；区分有机新增、收购、价格及技术修订。
- 记录资本开支预算、发生额、现金付款、勘探／开发／生产用途、项目投产及爬坡情况；分开收购、勘探费用和弃置支出。

**单季重建：**只有同一财年、口径一致的累计流量才能相减，例如第三季 = 前九月累计 − 半年累计。列出两份来源并标为“同口径推导”。期末余额、储量、产能、比率及均价不能简单相减重建单季数据；缺数时不得由取整增速倒推。

**取数优先级：**在口径和范围可比的前提下，优先使用财务报表及附注原数、公司同口径运营资料、同口径累计数差减、管理层正文约数。第三方价格和行业资料用于行业坐标，不能替代公司披露的实现价格。

### D. 油气行业专属分析口径

#### D1. 行业景气与商品价格

- 说明分析期油气供需、库存或产能变化、主要基准价格区间及波动驱动；区分可验证的行业事实与宏观判断。
- 比较公司实现油价与适用基准，分析价差、油品质量、运输、销售地区、合同定价及结算时点等可披露因素。没有资料时不猜测价差来源。
- 原油与天然气分别分析；天然气应关注地区定价、长协、现货、管输及政策机制，不与原油混算。
- 给出价格所处历史区间或分位时，注明取样区间、数据源及币种；历史跨度不足时标注限制。
- 输出“价格环境 → 公司实现价格 → 对收入／利润的可能传导”，不得把相关性表述成已证实因果。

#### D2. 产销量与收入量价归因

- 原油和天然气分开列示权益产量、销售量及同比变化；解释差额时优先核查库存、权益比例、并购、项目爬坡、停产检修和销售时点。
- 只有销售量与实现价格期间、币种、范围一致时，才可进行量价分解。可用：
  - 量的影响 = `(Q1 − Q0) × P0`
  - 价的影响 = `(P1 − P0) × Q0`
  - 量价交互 = `(Q1 − Q0) × (P1 − P0)`
  - 其中 `Q` 为对应产品销售量，`P` 为同口径实现价格；计算结果应与相应销售收入变动勾稽。
- 原油、天然气分别计算；贸易、加工、内部交易或其他收入单列。不能用“净产量 × 实现价格”硬凑合并收入。
- 若公司未披露可比销量或价格，只能列示报告披露的增速或方向，并明确无法量化拆分。

#### D3. 成本、税费与盈利弹性

- 分析单位成本时列清成本范围：生产操作、折旧折耗摊销、勘探费用、运输、税费及弃置等是否包含。只有口径可比才跨期或跨公司比较。
- 区分单位成本上升来自油服与材料价格、人工、汇率、产量变化、项目组合、成熟油田递减或一次性项目；没有明细时不强行归因。
- 单列资源税、特许权使用费、特别收益金（如适用）、所得税及海外项目财政条款；涉及产品分成合同（PSC）时，核实成本回收、分成比例及权益产量定义。区分税费计提与实际支付，区分中国和海外地区。
- 价格敏感性优先采用公司披露的敏感性。若自行建立情景，注明基准油价、产量、实现价差、汇率、财政条款、税率、套期及其他假设，并将结果标为估算。
- 禁止直接用“油价每涨／跌 10 美元 × 总产量”作为净利润敏感性；权益比例、销量、合同定价、产量分成、税费、汇率及套期都会改变结果。

#### D4. 储量、开发项目与生产可持续性

- 记录储量的分类、报告标准（如公司采用的 PRMS、SEC 或其他口径）、评估日期、权益范围和独立评估情况；不同标准或净／总口径不得直接比较。
- 储量接替率按公司披露定义计算；只有新增储量、生产量及调整项范围明确时才自行计算。将有机发现、收购、价格／技术修订分开；未披露时写“无法计算”，不把储量增长直接等同于勘探成功。
- 储量寿命等比率须说明使用的储量类别和年化产量；作为静态参考，不等同实际可生产年限。
- 对主要新项目跟踪最终投资决定、预算、建设进度、计划／实际投产时间、初期产能、爬坡、实际权益产量及成本；区分项目公告和已实现产量。
- 分析成熟油田自然递减、调整井／提高采收率投入和新项目接替；无田块级数据时，不把公司整体产量变动归因于特定项目。

#### D5. 勘探开发会计与减值

- 核查勘探及评价支出的资本化／费用化政策、成功与失败井处理、转入油气资产时点及政策变更；对照附注，不能仅凭科目余额判断利润调节。
- 核查油气资产折耗是否采用产量法及其储量基础、资产寿命、残值和弃置成本估计；重要估计变动应说明对折旧折耗的影响。
- 对减值核查资产组、触发迹象、基准油气价格、长期价格曲线、储量、产量曲线、折现率、开发成本及税费假设。区分减值与减值转回，不推断未披露的资产所在地或原因。
- 同时分析减值、折旧折耗、勘探费用和投资收益对利润的影响；不得把经常性折耗或资产减值一概称为“非经常性”并全部加回。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示公司主体、证券代码、报告期、公告日、会计准则、币种、审计／审阅状态、信息截止日及材料缺口。先给一句话结论，并分列已验证事实、计算结果和判断。

#### 二、行业价格与供需坐标

展示分析期基准油价、公司实现油价、气价、油气供需和历史位置。说明主要传导路径及不确定性；第三方资料须注明来源和日期。

#### 三、业绩、量价与利润质量

展示营业收入、油气销售收入、营业成本、营业利润、利润总额、归母净利润、每股收益及同比变化。分别解释：

1. 原油与天然气的销量／实现价格变化；
2. 成本、税费、折旧折耗及产量组合变化；
3. 投资及联营损益、汇兑、减值、处置等项目；
4. 归母与非控股权益、所得税对净利润的影响。

不得把商品价格涨幅直接当作公司利润增幅，也不得用单一盈利指标代替盈利质量判断。

#### 四、运营、储量与项目执行

列示权益产量、销量、油气结构、主要地区或项目贡献、储量及储量接替资料。比较公司产量目标与进度，并检查新项目投产、爬坡和成熟田递减；缺少项目级数据时明确说明。

#### 五、资本开支、现金流与资产负债

- 列示经营现金流及其与集团净利润的匹配情况。只有现金流量表补充资料足够时才做完整 OCF 调节；资产负债表余额变化不能直接替代营运资金现金流。
- 分列资本开支预算、发生额与现金支付；区分勘探、开发、生产、并购及弃置支出。
- 同时列示公司定义的 FCF（如有）及分析口径 `OCF − 可核验的资本开支现金付款`，明确两者差别，防止重复扣除。
- 列示现金、定期存款、受限资金、有息债务、租赁负债、净现金／净债务及到期结构。净现金按明确公式计算，不把不可自由调拨或受限资金等同可分配现金。
- 单列弃置义务／复垦义务的余额、变化及估计假设；区分账面准备和实际现金支出。

#### 六、资产质量与财务排雷

按第 F 节清单逐项标注“已见风险信号／未见明显异常／信息不足”，附金额、依据、可能影响及待核实凭证。对审计意见、关联方交易、或有负债、资产减值及财务估计重点说明。

#### 七、估值、股东回报与情景

- 分别列示 A 股和 H 股估值日期、价格、股本、币种、汇率和市值，不把两地市值简单相加。
- 周期股估值至少提供正常化油价／气价下的利润或现金流情景，列明产量、实现价差、成本、税费、汇率、资本开支和股本假设。情景不是预测。
- 可比较 PE、EV/EBITDA、企业价值／储量等指标，但须使用一致的周期、债务、储量标准和权益口径；储量估值只是辅助指标，不等同可实现价值。
- 列示已宣派、已批准未支付、已支付股息和实际回购现金支出。区分分红方案、支付状态和股息率；不以历史股息率承诺未来回报。
- 缺少可靠股价、股本、汇率或情景依据时，只给估值框架和缺口，不输出目标价、买卖评级或确定性安全边际。

#### 八、结论与下期跟踪

结论包含：

1. 当前盈利主要由价格、产量、成本或其他项目中的哪些因素驱动；
2. 储量与项目组合对未来产量的支撑和证据限制；
3. 现金流覆盖资本开支、弃置支出和股东回报的情况；
4. 最重要的风险、需要补充的原始资料及判断置信度。

选择 3–5 项有辨识力的跟踪指标，逐项给出当期基准、下一期所需数据和验证方向。跟踪项须对应本报告已识别的风险，不设无依据的预警阈值。

### F. 中国海洋石油行业化排雷清单

| 检查项 | 核查内容 | 风险信号或限制 |
|---|---|---|
| 油气价格与实现价差 | 基准油价、实现价格、气价、合同及地区结构 | 基准价格上升但实现价未同步；价差变化无法解释 |
| 产量与销售量 | 权益／总量、产量／销量、库存及权益变化 | 产量、销量和收入方向长期背离且缺少解释 |
| 储量接替 | 分类、标准、评估日期、有机新增、收购及修订 | 储量接替弱化、依赖收购或价格修订；口径不一致 |
| 项目执行 | 预算、延期、成本超支、实际产量及爬坡 | 投产延期、预算上修、产量／成本持续偏离计划 |
| 单位成本 | 定义、币种、成本范围、产量分母 | 单位成本趋势恶化，或口径变动造成表面改善 |
| 勘探及评价资产 | 成功／失败井、资本化政策、转入油气资产 | 资本化政策变化、长期未转固或失败项目处置不清 |
| 油气资产减值 | 价格曲线、储量、折现率、产量及成本假设 | 减值集中发生、假设敏感、转回依据不透明 |
| 弃置义务 | 预计负债、折现率、通胀、时间及实际支出 | 义务余额变化与开发规模不匹配，估计假设大幅调整 |
| OCF 与利润 | 折旧折耗、营运资金、税费、减值和投资收益 | 长期背离且缺少现金流补充资料；余额变化被误当现金流 |
| 资本开支与 FCF | 预算、发生额、付款额、并购、弃置及分红 | FCF 口径混用、资本开支付款缺失或重复扣除 |
| 财政条款与税费 | 资源税、特许权使用费、特别收益金（如适用）、海外税费 | 价格上涨时税费弹性被忽略；计提与支付混淆 |
| 汇率与套期 | 收入、成本、债务、外币折算及衍生品 | 汇兑收益被当作经营改善，套期范围或损益不透明 |
| 海上安全与环境 | 生产事故、停产、泄漏、极端天气、整改及赔偿 | 重大事故、停产或环境义务对产量、成本和现金流影响未充分披露 |
| 海上供应链与设施 | 油服、钻井平台、海底设备、运输及长周期备件 | 关键设施检修、供应短缺或项目延期导致产量和预算偏离 |
| 关联方与股东 | 母集团交易、服务采购、销售、资产转让及担保 | 定价、余额、审批或披露不足；不得因国企背景而排除风险 |
| 其他资产负债风险 | 债务期限、受限存款、商誉、应收、存货、诉讼及承诺 | 短期偿付压力、资金受限、并表变化或或有负债未充分解释 |
| 审计与披露 | 审计意见、关键审计事项、估计变更、重述 | 非标意见、重大估计不确定性、前后口径不可比 |

阈值应根据业务、地区、油田生命周期和公司披露定义判断，不机械套用通用模型的固定比例。每个红旗说明“现象 → 可能影响 → 证据及不确定性 → 下一步核查资料”。

### G. Python 最小计算规范

所有金额先统一币种和单位，所有公式使用原始精度；只有展示时才四舍五入。示例函数用于计算，不代替期间、单位、口径和来源核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        return None
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Amount must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if current is None or previous is None or previous <= 0 or current < 0:
        return None
    return current / previous - Decimal("1")


def price_volume_bridge(q0, q1, p0, p1):
    q0, q1, p0, p1 = map(D, (q0, q1, p0, p1))
    if any(value is None for value in (q0, q1, p0, p1)):
        return None
    volume_effect = (q1 - q0) * p0
    price_effect = (p1 - p0) * q0
    interaction = (q1 - q0) * (p1 - p0)
    return {
        "volume_effect": volume_effect,
        "price_effect": price_effect,
        "interaction": interaction,
        "reconciled_change": volume_effect + price_effect + interaction,
    }


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if ocf is None or capex is None:
        return None
    return ocf - capex
```

使用限制：

- `price_volume_bridge` 的数量必须是**销量**，价格须为匹配期间、币种及产品的实现价格；只有油气销售收入可比时才与收入变动勾稽。
- 该量价桥只拆出量、价和交互项，不包含产品组合、汇率、贸易及其他调整；有差额时列示差额，不强行归因。
- 未披露现金 CapEx 时，`analytical_fcf` 返回无法计算；不得用资本开支预算、固定资产余额变化或资本化发生额替代付款。
- 储量接替率、单位成本、价格敏感性等只有在定义与数据齐备时计算，并与公司披露定义对照。
- 不对负基数、跨零值或零分母使用误导性增长率；优先说明金额变化或“由盈转亏／转为净负债”。
