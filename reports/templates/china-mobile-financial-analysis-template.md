# 中国移动财报分析模板

适用范围：中国移动有限公司（00941.HK / 600941.SH）的季度、中期及年度报告、业绩公告及相关运营资料。

本模板固定分析方法，不固定结论；不包含任何一期财报的预设数字，不默认用户增长带来收入增长、5G 套餐客户均为 5G 网络活跃用户、云及政企业务增长必然提高利润，或高股息必然可持续。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充去年同期、上期及年报、运营数据、资本开支指引、股息及回购公告。同业、行业及市场预期资料须注明来源和日期。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 报告期、指标定义或其他资料不足时，继续完成可核实部分，明确注明“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的中国移动财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析通信服务收入、移动及家庭客户和 ARPU、政企与云业务的收入质量、网络资本开支、现金流及股东回报；缺少原始数据或可核验预期时不要反推或作确定性结论。

## 可复用分析指令

### A. 角色、目标与输入

你是一位熟悉电信运营商、网络投资及企业数字化业务的买方分析师。目标是判断通信服务与数字化业务增长是否转化为可持续利润和现金流，检查用户、流量和 ARPU 的变化是否可比，并评估网络投入、租赁、营运资金及股东回报的资金需求。不将用户规模、流量、收入或 EBITDA 增长直接等同于价值创造。

| 输入参数 | 填写值或默认规则 |
|---|---|
| 上市主体 | 中国移动有限公司；若附件属于中国移动通信集团或其他主体，先说明边界 |
| 股票代码 | 00941.HK、600941.SH；区分不同交易市场、股价、币种及对应股份 |
| 报告期 | `<YYYYQn / YYYYH1 / YYYYFY>`；以公告实际期间为准 |
| 公告及准则 | `<公告文件 / 公告日期 / 报表标示的会计准则>`；不预设不同准则或报表口径完全一致 |
| 信息截止日 | `<日期>`；默认公告日，截止日之后资料不得回填为当时已知事实 |
| 比较资料 | `<去年同期 / 上期 / 年报 / 运营及资本开支资料>`；标注缺失项 |
| 计量单位 | 默认财务金额人民币亿元；保留原始币种、单位及精度，用户数、流量和 ARPU 沿用披露定义 |
| 行情及估值 | `<证券代码 / 股价 / 日期 / 币种 / 各类股份数 / 汇率>`；缺失时不输出目标价或安全边际 |
| 输出形式 | 中文 HTML；优先桌面宽屏，按本模板“交付规范”执行 |

### B. 强制执行规则

1. **派生数字用 Python 计算。** 增速、百分点、单位换算、ARPU 相关计算、成本率、现金流及估值以原始数据和 `Decimal` 或等价精度计算；无法运行时说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”；估算列公式、输入、假设和限制。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；不得因附注未提及就写“没有风险”。
4. **期间、范围和单位一致。** 区分集团与母公司、合并收入与归母利润、期末客户数与期间平均客户数、单季与累计、人民币与港元、发生额与现金付款。
5. **先识别披露定义和会计列报。** 通信服务与产品销售、收入分类与客户市场分类、已计入成本的项目、租赁及投资收益可能采用不同口径；不得重复加总或重复调整。
6. **关键判断溯源。** 标注公告名称、日期、页码或附注；运营指标、同业、行业及行情数据标注来源、时点、单位、统计对象和定义。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查重述、定义变动、并表范围、单位与取整，原因未证实前保留差异。
8. **不预设经营结论。** 客户数、套餐客户、连接数、收入、云收入及流量增长均不能单独证明真实使用、利润率提升或现金回收改善。
9. **市场预期必须可核验。** 一致预期须注明来源、统计时点及利润口径；缺失时写“无可核验一致预期”，改做历史或公司指引对比，不以事后股价反应冒充预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日和估值日；期后事项单列，不作为报告期已实现业绩。用户限定仅用附件时，不擅自引入外部数据。

### C. 数据抽取与底稿

先建立统一底稿，再生成表格、图表与结论：

| 字段 | 要求 |
|---|---|
| 指标及原科目 | 公告原名、所属报表或业务、公司定义及会计位置 |
| 期间及类型 | 起止日期；单季、累计、期末余额、期间平均或单月指标 |
| 数值及单位 | 原数、币种、单位、正负号及精度；换算须列公式 |
| 范围 | 合并、母公司、归母；个人、家庭、政企、连接或其他统计对象 |
| 数据状态 | 披露原数、同口径差减、估算、未披露、未提供、不适用 |
| 来源 | 文件、公告日、页码、附注、原文定义、是否重述 |
| 计算链 | 公式、比较基数、假设、限制及校验结果 |

**最低财务数据集：**三大报表及附注；服务收入与产品销售收入、营业成本与费用性质、折旧摊销、财务费用、投资及联营损益、所得税；现金、债务、租赁负债、应收款、合同资产和负债、资本开支、股息及回购。能取得时补充季度或累计报表、分业务及客户市场资料。

**最低行业及运营数据集：**

- 移动客户数、净增客户、流失率、移动 ARPU、数据流量及使用情况，保留公司披露的统计范围、月份及平均口径；5G 套餐客户与 5G 网络客户分别记录。
- 家庭宽带客户、家庭客户综合 ARPU、宽带及增值业务等指标按披露定义记录；不假定家庭宽带 ARPU 等同家庭综合 ARPU。
- 按公司当期披露记录个人、家庭、政企及新兴市场，以及云、IDC、专线、物联网、ICT、系统集成或其他业务；注明是否为收入、客户数、连接数或合同金额，以及是否存在交叉。
- 资本开支计划、发生额和现金付款；可取得时记录网络、算力、云、数据中心及其他投入分类，以及基站、覆盖、利用率和共建共享资料。
- 可取得时记录资费、监管政策及同业可比指标的来源、时间和定义；不把外部市场统计当成公司收入或使用量。
- 尽可能取得跨年度可比序列，建议至少 8 个季度；不足时标注长度，降低趋势与季节性判断的置信度。

**取数优先级：**在定义、期间、币种及范围可比的前提下，优先使用报表及附注原数、公司同口径运营资料、同口径累计数差减、管理层正文约数。第三方资料只能作为补充坐标，不能替代公司披露。

**单季重建：**只有同一财年、口径一致的累计流量才能相减，例如第三季收入＝前九月累计收入－半年累计收入，列明两份来源并标为“同口径推导”。期末客户数、ARPU、比率、EPS、平均用户数及期末余额不能简单相减重建单季指标；缺数时不得由取整增速倒推。

**基础勾稽：**按当期报表列示核对收入及成本至营业利润、税前利润、集团净利润与归母利润；核对资产＝负债＋权益及期初现金经三类现金流、汇率等调节至期末现金。分类汇总前确认覆盖范围和抵销项，差额无法解释时单列。

### D. 电信运营商行业专属分析口径

#### D1. 行业竞争、政策与收入结构

- 说明可核验的移动通信、家庭宽带、企业数字化及云市场情况，关注资费、竞争、监管、网络共建共享和技术迭代；区分事实、管理层判断与分析判断。
- 列示总收入、通信服务收入、产品销售收入及公告披露的细分收入。终端等产品销售可能具有不同成本和利润率，不能把总收入增速直接等同服务收入增速。
- 检查个人、家庭、政企、新兴市场等管理口径与财务收入类别之间的关系。同一收入可能在不同维度交叉，只有披露证明互斥且覆盖完整时才能相加，并与合并收入勾稽。
- 对增长与下降分别检查客户规模、套餐及业务结构、资费、使用量、一次性项目及并表变化；数据不足时不强行归因。

#### D2. 移动客户、5G、流量与 ARPU

- 分别列示期末移动客户数、净增客户、流失率、移动 ARPU、流量和平均使用量；说明期末、月均、期间平均、单客户或单连接的区别。不得把新增客户、净增客户及期末客户数混为一谈。
- 5G 套餐客户、5G 网络客户、活跃使用者和 5G 手机用户如有披露，应按原定义分别列示；不得互相替代，也不能仅凭套餐渗透率推断收入或利润提升。
- ARPU 通常为期间某类收入与相应平均客户数、月份有关的月均指标，但必须以公司实际定义、收入范围、平均方法和单位为准。若只知道期末客户数，不能用其冒充期间平均数。
- 仅在收入、客户范围、期间、税费及包含项目完全一致且平均客户数可得时，才可用 `期间平均客户数 × 月数 × 月均 ARPU` 做对应收入的示意和勾稽；列示差额，不把示意值当作报表收入。跨期差减 ARPU 不会得到单季 ARPU。
- 数据流量、每户流量或平均使用量与变现分别观察；流量增长不必然带来收入增长。使用量、客户数和价格范围不能匹配时，不做量价拆解。

#### D3. 家庭、政企与数字化业务

- 家庭业务关注宽带客户净增、家庭综合 ARPU、融合套餐、电视、组网或其他增值服务；明确指标分母及服务范围，不将单一业务客户数相加当作独立家庭数。
- 政企业务按披露分析连接、专线、云、IDC、ICT、系统集成等收入、客户或合同数据。中标额、订单及合同总额不是已确认收入；毛收入或签约增长不等于利润增长。
- 关注项目型收入与经常性服务收入的区别，以及外采软硬件、集成及交付成本、项目毛利率、客户集中度、回款和账龄。没有成本或回款资料时，明确无法判断盈利和现金质量。
- 只有公司说明定义且数据足够时，分析云或其他业务的收入、成本与投入；不得把收入同比增速直接解释为市场份额、盈利能力或独立现金回报。
- 物联网连接数、企业客户数和实际活跃使用指标分别记录；一家公司可对应多个连接，连接增长不等于付费客户或 ARPU 增长。

#### D4. 网络、算力与资本投入

- 列示资本开支预算、发生额、现金付款和分类，检查移动网络、传输、家庭网络、云及算力等投入与公司指引、项目交付及利用率。分类变化或缺失时不推断其用途。
- 对比 `资本开支发生额 ÷ 收入` 与 `资本开支现金付款 ÷ 收入`，分别注明分子、分母、期间和范围；区分购并、频谱相关支出及租赁，避免重复计入。
- 核查基站、机房、数据中心、算力设备及网络共建共享披露。基站数、算力规模或覆盖率不是流量、利用率、收入或投资回报的替代指标。
- 检查固定资产、在建工程、软件及其他无形资产的资本化、转固、折旧摊销、使用寿命和减值；投入下降不必然代表长期维护需求下降。费用性质表中折旧如已包含在营业成本或费用内，不再次扣除。
- 分析铁塔、网络及其他租赁的服务费用、使用权资产和租赁负债；确认公司与相关方的实际关系及交易条款，不能仅凭名称推定关联。共享安排的权利、义务及结算按合同和附注核查。

#### D5. 收入确认、利润及现金质量

- 检查服务、终端和融合套餐的履约义务、交易价格分摊、收入确认时点，识别预收款及合同负债。合同负债增加不自动等同新增订单或可自由分配现金。
- 对设备、ICT、云或其他存在第三方参与的业务，核查主要责任人／代理人判断及收入总额／净额列报。口径变化或无法核实会影响收入、毛利率及同比可比性，不凭外采比例自行判断。
- 跟踪应收账款、合同资产、未开票收入、账龄、减值及坏账回收；余额增长与收入增长方向背离只是线索，不足以单独证明虚增收入或坏账。
- 核查终端补贴、佣金、合同取得或履约成本的资本化、摊销及减值政策，以及设备销售成本、网络运维、电费、人员及折旧摊销。区分费用发生、资产形成和现金支出。
- 经营利润、归母利润、EBITDA 和调整后指标分别列示并按公司定义核对。EBITDA 不是经营现金流或自由现金流，不可忽略资本开支、租赁、利息及税费。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示主体、证券代码、报告期、公告日、会计准则、币种、审计／审阅状态、信息截止日和资料缺口。先给一句话结论，再区分已验证事实、计算结果和判断。

#### 二、行业与竞争坐标

展示可核验的资费、行业需求、移动及宽带竞争、政企和云市场、政策或网络投入环境；标注资料日期及与公司指标的可比性。资料不足时只列缺口，不推断行业地位变化。

#### 三、业绩、收入结构与利润质量

列示总收入、通信服务收入、产品销售收入、营业利润、归母净利润、每股收益、公司披露的 EBITDA 及同比。按公告归因移动、家庭、政企及其他业务，再分析成本、折旧摊销、税费、投资和非控股权益影响；无法拆分的项目不强行量化。

#### 四、客户经营与数字化业务

分别展示移动客户、5G 指标、移动 ARPU、流量、家庭宽带及家庭综合 ARPU，以及政企、云、连接和项目业务资料；注明定义、平均／期末、分类交叉和不确定性。分析增长能否对应收入、利润及回款，而非只列业务规模。

#### 五、资本开支、现金流与资产负债

- 列示经营现金流及与**集团净利润**的比较；只有现金流量表补充资料足够时才做完整调节，资产负债表余额变化不直接代替营运资金现金流。
- 分列 CapEx 预算、发生额和现金付款，以及网络、算力等可核验分类；注明项目、单位和期间，区分购并及租赁。
- 公司定义的 FCF（如有）和分析口径 `经营现金流 − 可核验的资本开支现金付款` 分别列示；核对现金流分类，检查租赁付款及其他项目是否已包含，避免重复扣减。未披露现金 CapEx 时不以发生额或预算替代。
- 列示现金、定期存款、受限资金、有息债务、租赁负债、净现金／净债务及到期结构。公司口径与自行计算口径分别列示，说明租赁负债是否包括；受限或不可自由调拨资金不等同可分配现金。
- 检查合同资产、应收及减值、合同负债、应付设备款、资本承诺、担保及或有事项；区分余额变动与实际现金支付。

#### 六、资产质量与财务排雷

按第 F 节逐项标注“已见风险信号／未见明显异常／信息不足”，附金额、来源、可能影响及待核实凭证。重点检查收入确认、应收回款、资本化、租赁和关联交易。

#### 七、估值、股东回报与情景

- 分别列示 A 股和 H 股报价、日期、币种及相应已发行股份数；核实股本结构、库存股和汇率。集团总股权市值如按各类股份分别计价，应将相应股份市值统一币种后汇总，不能把按全部股份分别计算的 A/H 估值相加；不将任一证券价格误作集团现金流。
- PE、EV/EBITDA、FCF 收益率等分别说明价格日期、股本、盈利期间、币种、现金与债务范围。EV 和 EBITDA 的租赁处理应一致，并与同业定义对照；缺少输入时不报具体倍数。
- 如建立情景，列明服务收入、客户及 ARPU、政企项目利润率、折旧、税费、资本开支、营运资金、租赁及股本假设。情景不是预测，不把单年低 CapEx 或高现金流机械外推。
- 区分已宣派、已批准未支付、已支付股息及实际回购支出；分红方案、派息率和股息率的期间、币种与股数一致。集团现金流覆盖与母公司可分配资金分别分析；不承诺历史分红可持续。
- 无可靠行情、股本、汇率或情景依据时，只给估值框架和资料缺口，不输出目标价、买卖评级或确定性安全边际。

#### 八、结论与下期跟踪

结论回答：服务收入与客户经营的驱动；家庭和政企增长的利润及回款证据；网络与算力投入对利润和现金流的影响；股东回报的覆盖及限制。选 3–5 项与本期风险对应的指标，逐项给出当期基准、下一期所需数据和验证方向，不设无依据的固定阈值。

### G. Python 最小计算规范

金额先统一币种和单位，费用及现金支出按支出为正的约定计算并保留原始符号；仅展示时四舍五入。示例不代替期间、单位、定义及来源核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        return None
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Value must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if current is None or previous is None or previous <= 0 or current < 0:
        return None
    return current / previous - Decimal("1")


def ratio(numerator, denominator):
    numerator, denominator = D(numerator), D(denominator)
    if numerator is None or denominator is None or denominator <= 0:
        return None
    return numerator / denominator


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if ocf is None or capex is None:
        return None
    return ocf - capex
```

使用限制：

- 增长率不适用于负基数、跨零值或零分母；优先说明金额变化或“由盈转亏”。比率还须检查实际经济含义，不因为函数返回数字就认定具有可比性。
- ARPU、客户和收入的推导必须符合 D2 的匹配条件；平均客户数或收入定义不足时不计算。
- 现金 CapEx 应按现金流量表和附注确认，与预算和发生额分开；FCF 中不重复扣除已计入经营现金流或 CapEx 的支出。
- 估值、分红覆盖及净现金计算须列出股本、币种、范围和租赁口径；缺少输入时不估算。
