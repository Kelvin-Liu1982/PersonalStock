# 腾讯控股财报分析模板

适用范围：腾讯控股（00700.HK）年度、中期、季度业绩公告及财报。版本：1.2。

本模板固定分析方法，不固定结论；不包含任何一期财报的预设数字，也不默认“毛利率提升”“AI已兑现”或“千亿回购”成立。

## 使用方式

1. 在新会话上传当期财报；能取得时，一并上传截至当期公告日的可比公告。中期及前三季分析尽量取得本年度及可比期间已披露的季度或累计报表，用于单季重建与跨期核对。
2. 将下方“可复用分析指令”整体提供给分析助手，或直接要求其读取本文件。
3. 确认报告期，按 H 节仅交付 PC 宽幅 HTML；缺少比较材料或估值输入时继续分析，明确写“未披露”或“未提供”，不得补造。

可直接使用的调用语句：

> 请严格按本模板分析附件中的腾讯控股财报，报告期以公告为准。先用Python计算并核对，再仅交付面向 PC 的宽幅 HTML 中文报告，不提供数据导出或打印功能。比较期、现金流细项或估值参数不足时，请说明限制，不要反推缺失数据。

### B. 强制执行规则

1. **全部派生数字调用Python。** 比率、同比／环比、百分点、变动额、单位及汇率换算、FCF、净现金、股数变化、估值均必须执行代码；用`Decimal`或等价精确计算保留原数，仅在展示时四舍五入。不能运行时明确披露，不声称已精算。
2. **事实、计算和判断分层。** 区分“公告披露”“Python计算”“分析判断”；表中注明数值是“披露原数”“同口径推导”还是“估算”。没有比较原数的管理层取整增速只标“公告口径，无法复算”。约数参与运算时仍标约数，展示精度由输入支持的精度决定。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；零值必须有明确依据。负基数、由盈转亏、由净现金转净负债等情形优先展示金额变化，不使用误导性增长率。
4. **期间、币种、归属范围必须一致。** 不把累计数当单季数，不把集团OCF与归母净利混算，不把港元回购直接除以人民币FCF，不混用合并全额与归母应占金额。
5. **先识别会计列报，再做利润净化。** 各期投资损益可能处于不同报表位置；禁止把“其他收益”一律等同投资收益，禁止重复扣除已列在经营盈利之后的投资及联营损益。
6. **附注溯源。** 重大变动必须查阅分部、费用性质、投资损益、减值、股份支付、借款、股息、收购和期后事项；每项关键结论注明公告页码或附注编号。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途，核查取整、汇率、全额／应占、并表／非并表及重述口径；原因未获证实时不得归咎于舍入，应保留差异及其对结论的影响。更新已交付报告时在口径说明中交代新增来源或改动原因，不为统一显示而静默改写历史报告。
8. **不预设利好或利空。** 必须验证而非套用高毛利替代、AI商业化、回购规模或游戏流水叙事；不存在充分证据时明确说无法验证。
9. **时点可追踪。** 区分报告期、期末和信息截止日。发生于报告期后、截至截止日已知的事件可作期后事项列示，不作为报告期收入已实现的证据。截止日后发布的材料不得回填为当时已知事实；若用户要求用更晚资料重评，明确标注新的截止日及修订内容。
10. **材料与市场信息分开。** 仅使用已取得材料；如按要求补充官方公告或行情，标明出处、日期及币种，不把事后资料伪装成当时可得信息，不发送或上传用户财报至无关服务。

### C. 数据抽取与计算底稿

先建立统一数据底稿，再生成表格、图表与结论。底稿字段至少包含：

| 字段 | 要求 |
|---|---|
| 指标及会计位置 | 原科目名称、属于经营／投资／融资或其他部分 |
| 期间与类型 | 起止日期；单季／累计／期末余额／日均或加权平均 |
| 金额与范围 | 原数、币种、单位；合并／归母／应占范围 |
| 精度与状态 | 原始披露精度；披露原数／同口径推导／估算／未披露／未提供／不适用。注明无法可靠计算的原因 |
| 溯源 | 文件、公告日、页码、附注及原始表述；重述情况，存在冲突时的采用值与用途 |
| 计算链 | 公式、输入指标、比较基数及必要假设 |

最低数据集：集团损益与Non-IFRS调节、三大分部收入及毛利、游戏及社交收入、费用与研发、现金流与现金CapEx、递延收入、净现金组成、投资组合、SBC、实际股数及股东回报、核心运营数据。

**数值标准化：**先识别原始括号、负号、千位分隔符和币种符号，再转为数值；费用及现金支出在减法公式中采用支出为正、冲回为负的约定，同时保留原始符号与转换依据。拒绝NaN或无穷值，不将其当成缺失值或真实金额继续计算。

**取数优先级：**在定义、期间、币种、合并及归属范围可比且截至信息截止日可取得的前提下，优先使用**财务报表及附注原数（含截至日已披露的最新可比重述）→ 同口径原数差减推导 → 管理层正文约数**。公司专有指标按其定义的对应披露取数；复核公告现金流桥时可单列管理层约数，不与用于增速和比率的报表原数或推导值混用。口径不同的数不能仅按精度择一。

**单季重建规则：**只有同一财年、口径一致的累计流量才能相减，例如第三季=九个月累计−半年累计、第四季=全年−九个月累计，并列明两份来源、标注“同口径推导”。比率、EPS、加权股数、MAU及期末余额不能靠差减重建单季流量；余额相减可列示头寸变动，不等于现金流。缺少原数时不利用取整环比倒推。

**勾稽顺序：**

- 收入−收入成本=毛利；毛利与全部经营费用及其他经营项目调节至IFRS经营盈利。
- IFRS经营盈利经投资、利息、财务成本、联营／合营及其他项目调节至税前和税后利润；集团净利润=归母+非控股权益。
- IFRS与Non-IFRS逐项调节，分开经营层面、集团净利层面、归母层面，保持税项与归属一致。
- 分部收入及毛利合计核对集团；资产=负债+权益；期初现金+三类现金流+汇兑及其他调节=期末现金。
- 按公告定义重算净现金与FCF；核对投资滚存、递延收入及SBC相关附注。
- 不因四舍五入出现小差额就认定错报；容差须由原始精度决定，不用任意大容差掩盖差异。

### D. 关键计算口径

#### D1. 盈利与主业利润

- 同比／环比=本期÷可比期−1；毛利率=毛利÷收入；费用率=相关费用÷收入；百分点变动=两期比率直接相减。
- 分开列示IFRS经营盈利、IFRS归母净利润、Non-IFRS经营盈利、Non-IFRS归母净利润，不互相替代。
- **Core OP代理值=毛利−销售及市场推广开支−一般及行政开支−其他经确认在毛利后单列的相关经营开支（若有）。** 按当期利润表列报扣除，每项只计一次。保留SBC和当期已计入损益的AI相关成本和费用；已计入收入成本的折旧、技术运营成本和已含在行政开支中的研发等，不按费用性质再次扣除。尚未计入损益的设备采购及算力预付不纳入Core OP。
- 另作“IFRS经营盈利→Core OP代理值”和“IFRS经营盈利→Non-IFRS经营盈利”调节；解释被排除的其他经营收支。若持续经营收支无法拆清，明确为代理值，不声称得到唯一、精确的真实主业利润。
- 投资及联营损益若已在经营盈利之外，不再从Core OP扣减。不得把所有经营资产减值、其他经营项目无条件加回。
- 已披露金额明确且影响重大的单项事件（如比较期一次性SBC），在原口径之外说明敏感性：列明假设、调整的是哪一期、以及对增速或利润率的影响；不覆盖原口径，不当作报表重述或常规加回。
- 公司“剔除新AI产品”指标单独展示，不能作为保留当期AI成本和费用的集团主业表现；差额仅在排除范围一致时解释，不等同现金CapEx或全部AI投入。
- **集团毛利率变化固定拆解法：**令 `w` 为分部收入占集团收入的比例，`m` 为分部毛利÷分部收入，`1` 为本期，`0` 为比较期。分部内贡献=`Σ w1 × (m1 − m0)`；收入结构贡献=`Σ (w1 − w0) × m0`。纳入所有可比分部，包括“其他”，用未舍入原数验证两项合计等于集团毛利率变化；如分部范围变更且不可重述、原数缺失或比率无定义而无法勾稽，不强行分配差额。

#### D2. 现金流、资本开支与净现金

- 区分CapEx发生额、现金付款、媒体内容付款、租赁付款及算力预付；购并、股权投资及理财购买另列，不能混作有机CapEx。
- CapEx强度分别计算“发生额÷收入”和“现金CapEx÷收入”，有无媒体内容必须注明；现金CapEx÷OCF要求期间一致，OCF过小或为负时说明解释局限。
- 窄口径FCF=OCF−不含媒体内容的现金CapEx。
- 广义FCF=OCF−现金CapEx−媒体内容付款，前提是内容付款既未包含在所用CapEx内，也未已作为经营现金支出计入OCF；否则不得重复扣除。
- 公司FCF按公告定义重算；若另扣租赁付款，明确数额与范围，避免再次扣除已包含的项目。经营租赁利息、融资及本金分类按当期附注核对。
- 披露调整后FCF、被排除项目和实际FCF；仅当差额完全由一项调整造成时，才可反推该项。算力预付若已在OCF中，不能在FCF中重复扣除。
- **累计FCF分三种状态，按各FCF口径分别判断。** 累计原数齐全，或各单季有完整同口径原数可加总，按原数复算并标明来源；原数不足、但所有单季均有同定义且覆盖完整的FCF约数或付款桥，可加总标为“约（单季加总估算）”，注明各季来源、不是累计披露原数；缺任一必要期间／付款项或定义不一致，填“无法计算”并列明缺口。未调整与调整后FCF不混加，不以发生额、内容摊销或资产余额替代付款。
- 净现比默认OCF÷集团税后净利润；如另列OCF÷归母净利，须标注范围不同，不能当作完全匹配的标准指标。
- 净现金按公告定义计算：现金及等价物+符合口径的定存及其他−借款−应付票据；列明租赁、受限资金及其他项目是否纳入。
- 定存与理财可能已包含在“定存及其他”，不得重复加总；受限现金若原本不在所用现金中，亦不得再扣一次。客户备付金、不可自由动用现金不视为股东可分配资金。
- 预付款、应付款余额变化不等于同额现金流，须考虑并购、汇兑、非现金资本采购及重分类；无完整明细时不编造营运资金现金流桥。

#### D3. 股东回报、SBC与估值

- **集团FCF对母公司股东现金支出的覆盖**＝集团实际（未调整）公司口径FCF÷（母公司实际回购现金付款＋向母公司股东实际支付的股息）。只在同期间、同币种、实际付款可核验且分母为正时给倍数；无法核验不算倍数。若实际FCF为负且确认当期有股东现金支出，直接写“不覆盖”，不报负倍数。不把集团FCF等同母公司可分配现金：少数股东权益、受限或不可调拨资金等可限制上划。
- 股息分列**拟派、已批准未付、已付**及其状态日期；未获必要批准的拟派股息不是既定义务或实际现金流。已付上一年度末期股息归入实际支付期间；非控股股东股息不进母公司分母。回购交易代价、权益变动和实际现金付款分列；换汇只能使用有出处、日期与币种的汇率，全年计划不当作已执行。
- SBC至少区分合并费用、仅权益结算部分、含联营分占的Non-IFRS集团调整及归母调整；分别匹配集团或归母Non-IFRS净利作为分母，不能随意混除或重复加总。
- 已发行股份净缩减率=(期初实际已发行股份−期末实际已发行股份)÷期初实际已发行股份；必须区分已注销、待注销、库存股、员工信托持股、实际新增发行及净额行权。
- 如另计算剔除库存股后的实际在外股数变化，单独说明范围并保持期初末一致。归属不等于新增发行，购回不等于报告期内已注销；加权平均基本或摊薄EPS股数变化不等于净缩股率。
- 估值优先使用口径一致的分部估值：归母股权价值=合并主业企业价值−对应非控股股东权益价值+未计入主业的投资组合归母可实现价值+匹配范围的净现金±其他必要调整。
- 用主业企业价值法时匹配债务与现金；若改用股权PE法，重新审视已包含的财务收益与净现金，不能机械重复加回。投资及联营利润若已经进入盈利估值，不能再次完整计入投资价值。
- 投资组合剔除已含在主业的附属公司价值和已含在净现金的理财；区分公允价值、账面价值、全额与应占，考虑税费、流动性及处置约束。未上市账面价值不是即时可变现价值。
- 缺少股价、股本、汇率或估值假设时，仅给估值框架与数据缺口，不输出目标价、安全边际百分比或买卖评级。

### E. 报告输出框架

#### 一、核心财务与运营指标速览

先给出分析期间、信息截止日、币种、单位、审计／审阅状态及材料边界，再用表格展示本期、上期、去年同期及同比／环比。

- 集团：收入、毛利、毛利率、IFRS经营盈利、Core OP代理值、IFRS归母、Non-IFRS经营盈利及归母、OCF、各适用FCF口径。
- 分部：VAS、营销、FBS的收入、毛利及毛利率；VAS细分本土游戏、国际游戏、社交网络的收入与可验证增速。不能把整个VAS毛利率当游戏子业务毛利率。
- 运营：微信及WeChat MAU、付费订阅会员；注明期末／季度日均，不能称为注册账户。视频号、小游戏、搜一搜、AI广告、支付、云及AI产品数据只列实际披露项。
- 资金：现金及等价物、定存及其他、借款、票据、净现金及其金额变化；按 D3 列回购口径与股息状态，并注明币种和期间。
- 当季与累计分表。年度报告无可比单季数据时，以年度比较为主；缺少季度桥接时不强造Q4。多年趋势仅在材料足够且口径可比时补充。

#### 二、核心主业增长质量与结构性毛利率

1. 比较毛利增速与收入增速，按 D1 固定方法拆解分部内、结构及“其他”分部的贡献；验证高毛利业务替代叙事是否持续，不默认毛利率跃升。
2. 把MAU、会员、视频号时长、小游戏生态、广告AI能力与收入及毛利交叉验证；量、价、变现率或并表贡献缺失时，不能直接建立因果归因。
3. 游戏结合本土与国际收入、固定汇率、DAU、上线周期和递延收入判断；集团递延含非游戏项目、缺少地区及流水拆分时，只能提供线索，不能断言流水领先／滞后或提前确认。
4. 费用率拆解研发、一般行政、销售推广、算力运营、折旧及SBC；注明费用性质与利润表列报的重叠，判断保留当期已计入损益的AI成本与费用后的经营杠杆方向。重大单项基数影响按 D1 另列敏感性。

#### 三、CapEx、AI算力投入与自由现金流

1. 展示发生额与现金付款、强度、可比增长及用途；GPU、服务器、云租赁、数据中心、自研模型和外部客户算力需求没有拆分时不代为分配。

### F. Python最小计算骨架

以下仅为可复用计算函数，不含任何真实或预设财务数据。调用前必须从公告抽取原数，以字符串转为`Decimal`；`None`表示无法计算，报告还需说明原因。币种、期间和范围的匹配由底稿检查保证，函数不能代替该检查。

```python
from decimal import Decimal, getcontext

getcontext().prec = 36
HUNDRED = Decimal("100")


def amount(raw_value):
    if raw_value is None:
        return None
    if isinstance(raw_value, bool):
        raise ValueError("Boolean values are not financial amounts")
    parsed = Decimal(str(raw_value))
    if not parsed.is_finite():
        raise ValueError("Financial amounts must be finite")
    return parsed


def strict_sum(*values):
    if not values or any(value is None for value in values):
        return None
    return sum(values, Decimal("0"))


def difference(current, previous):
    if current is None or previous is None:
        return None
    return current - previous


def ratio(numerator, denominator):
    if numerator is None or denominator is None or denominator == 0:
        return None
    return numerator / denominator


def percent(numerator, denominator):
    result = ratio(numerator, denominator)
    return None if result is None else result * HUNDRED


def growth_percent(current, previous):
    if current is None or previous is None or previous <= 0 or current < 0:
        return None
    return (current / previous - Decimal("1")) * HUNDRED


def percentage_point_change(current_percent, previous_percent):
    return difference(current_percent, previous_percent)


def core_operating_proxy(gross_profit, *operating_expenses):
    return difference(gross_profit, strict_sum(*operating_expenses))


def free_cash_flow(operating_cash_flow, *cash_outflows):
    return difference(operating_cash_flow, strict_sum(*cash_outflows))


def net_cash(cash_equivalents, deposits_and_other, borrowings, notes):
    return difference(
        strict_sum(cash_equivalents, deposits_and_other),
        strict_sum(borrowings, notes),
    )


def share_reduction_percent(opening_actual_shares, closing_actual_shares):
    if opening_actual_shares is None or opening_actual_shares <= 0:
        return None
    return percent(
        difference(opening_actual_shares, closing_actual_shares),
        opening_actual_shares,
    )
```

使用注意：

- 所有金额先统一单位；公式使用原数，而非展示用四舍五入数。
- `growth_percent`不用于净现金跨零、亏损基数或正转负情形；这些场景用金额差及“转亏／转为净负债”描述。
- `percentage_point_change`输入已是百分数值，例如`percent()`结果，不对比率重复乘100。
- `core_operating_proxy`只传入经确认在毛利后单列的经营费用，不传入已包含在毛利或其他项目中的研发、折旧等。
- `free_cash_flow`的现金支出项必须不重叠；已知明确无此项时才传入零，不以零代替未披露。季度加总前先按 D2 检查定义、完整性与精度。
- `ratio`不判断资金是否可分配或付款是否可核验；计算股东回报覆盖前必须先满足 D3，并确认分母为正。
- `share_reduction_percent`只接受范围一致的实际期初末股数，不能使用加权股数、归属股数或不同时段回购量代替。
