# 中远海控财报分析模板

适用范围：中远海运控股股份有限公司（01919.HK / 601919.SH）的季度、中期及年度报告、业绩公告及相关运营资料。

本模板固定核验方法，不预设具体财报数据、行业景气或投资结论。集装箱航运具有周期性，单期运价上涨、运量增长或低市盈率不必然意味着利润、自由现金流或股东回报可持续。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充上年同期、上期及年报、集运运营和航线资料、船队及新船订单、资本开支和股息公告。行业运价、运力、港口拥堵和一致预期需注明来源、时间和口径。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 航线运量、平均运价、租船、运力或现金资料不足时，继续完成可核实部分，标注“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的中远海控财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析集运航线运量、实现运价与费用、船队和租船、码头业务、资本开支及现金流。没有原始数据或可靠预期时，不要反推或作确定性结论。

## 可复用分析指令

### A. 角色、目标与输入

你是一位熟悉集装箱航运、航线经营、码头业务、船舶租赁和航运周期的买方分析师。目标是判断利润有多少来自运量、实现运价、航线及货种组合、运力成本和其他项目，核查船队与码头投资能否产生回报，以及现金流能否覆盖购船、租赁、环保改造和股东回报。不得把单期高运价盈利或账面现金直接当作可持续盈利或可分配资金。

### B. 强制执行规则

1. **派生数字用 Python 计算。** 增速、百分点、单位换算、量价桥、单位成本、现金流、净现金及估值以原始数和 `Decimal` 或等价精度计算；无法运行时说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”；估算列公式、输入、假设、限制及必要的敏感性。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；不因附注未提及就写“没有风险”。
4. **期间、范围和单位一致。** 区分集团与母公司、合并与联营合营、航运与码头、重箱与空箱、运量与运力、累计与单季、人民币与美元、收入发生额与现金收款。
5. **先核实列报与抵销。** 集运、码头、物流等业务收入、内部交易、权益法投资收益及财务费用可能交叉；核对分部口径及合并抵销，不重复计收入、利润或现金。
6. **关键判断溯源。** 为重大数字、风险及判断标注公告、日期、页码和附注；外部运价指数、燃油价格、船舶供给、法规和同业数据须注明来源、时点及定义。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查重述、汇率、单位、航线范围、空重箱、统计时点、合并范围和取整。原因未证实前保留差异。
8. **不预设周期结论。** 现货指数上升不自动代表公司实现运价或利润同比增长；运量增长不必然提高装载率、利润或现金流；短期绕航亦不必然长期利好承运人。
9. **市场预期必须可核验。** 一致预期须注明来源、统计时点及利润口径；缺失时写“无可核验一致预期”，改做历史或公司指引对比，不以事后股价反应冒充预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日及估值日；期后运价、航线事件和股息进展单列，不作为报告期已实现业绩。用户限定仅用附件时，不擅自引入外部数据。

### C. 数据抽取与底稿

先建立统一底稿，再生成表格、图表与结论：

| 字段 | 要求 |
|---|---|
| 指标及原科目 | 公告原名、所属报表或业务、公司定义、会计位置 |
| 期间及类型 | 起止日期；单季、累计、期末余额、期间均价、时点运力或年度预算 |
| 数值及单位 | 原数、币种、TEU／FEU、价格单位、正负号及精度；换算须列公式 |
| 范围 | 合并、母公司、联营合营或权益应占；承运、航线、码头、内外部交易 |
| 数据状态 | 披露原数、同口径差减、估算、未披露、未提供、不适用 |
| 来源 | 文件、公告日、页码、附注、定义、是否重述 |
| 计算链 | 公式、比较基数、假设、限制及校验结果 |

**最低财务数据集：**三大报表和附注；集运、码头及其他业务的收入、成本、分部抵销、联营合营损益、财务费用、汇兑和减值；货币资金、受限资金、借款、租赁负债、购船付款、资本承诺、应收及股息资料。

**最低行业及运营数据集：**

- 航线分区、运输量及其定义，记录重箱／空箱、是否包含中转或其他承运人舱位、业务主体及可比期间；区分计费箱、承运箱和港口吞吐量。
- 分业务和航线的收入、实现运价、币种和是否包含附加费、内陆运输、滞箱等；区分长协／现货与客户结构。
- 船队自有、租入及租出船舶的数量、容量、船龄、期租期限、新船订单、交付计划及资本承诺；记录运力的统计时点和权益／经营口径。
- 燃油、租船、港口、箱管、船员、折旧及折算等成本范围，适用时记录运力配置、航程、航速、重载率及空箱调运。
- 码头名称、持股、控制或权益法、吞吐量及其总量／权益口径；港口运营收入与集运内部港口费用应核查抵销。
- 可取得时记录适用航线的现货运价指数、燃油基准、订单及交付、贸易需求和运河或港口限制。建议至少取得 8 个可比季度；不足时降低周期和季节性判断的置信度。

**取数优先级：**定义和范围可比时，优先使用报表及附注原数、公司同口径运营资料、同口径累计差减、管理层正文约数。第三方指数是市场坐标，不能替代公司实现价格。

**单季重建：**只有同一财年、口径一致的累计流量才能相减；列明两份来源并标为“同口径推导”。期末余额、船队规模、运力、比率及均价不得简单相减；不得由取整增速反推原始数。

**基础勾稽：**核对收入及成本至经营利润、税前利润、集团净利润与归母净利润；核对资产＝负债＋权益及期初现金经三类现金流、汇率等调节至期末现金。分类汇总前确认覆盖范围和抵销项，差额无法解释时单列。

### D. 集装箱航运行业专属分析口径

#### D1. 运价、合同与需求

- 记录主要航线、运价指数的发布机构、时间、方向、目的地、币种、箱型和是否包含附加费；分开现货指数、长协价格和公司实际实现运价。指数不是公司账单或每箱收入。
- 对照公司披露的长协／现货占比、签约周期、履约量、附加费、运价调整及客户结构；未披露时不推断长协保护程度或价格重定时间。
- 航线供需须区分需求、实际装运量、班次、有效运力、航速及航程；分析拥堵、绕航、空班、运河限制或港口费时注明发生时间和来源，不假定事件必然推升净利润。
- 比较公司实现运价与指数时，说明航线和方向、期间均值、装运或结算时点、税费、货种与箱型；缺乏可比定义时不量化价差或归因。
- 输出“行业环境 → 可核验公司运量／实现价 → 收入及成本传导”，区分市场事实、管理层解释与分析判断。

#### D2. 运量、收入及量价归因

- 1 FEU 通常相当于 2 TEU，但具体业务披露应确认标准箱换算及箱型；TEU 是标准箱当量，不等于箱数、货值或航行距离。注明重箱、空箱、中转、往返和统计范围。
- 承运运量与码头吞吐量不能相加当作集团业务量：一票货物可能在不同码头多次装卸或中转。码头总吞吐量、权益吞吐量及合并范围不能互换。
- 仅在运量、实现价格、收入期间、币种、航线、附加费、载重状态及合并／抵销范围一致时，计算量价桥：量影响 `(Q1 − Q0) × P0`，价影响 `(P1 − P0) × Q0`，交互 `(Q1 − Q0) × (P1 − P0)`。先换算单位，再与**对应口径**收入变动勾稽。
- 分航线、方向或品牌拆解时须确认类别互斥且覆盖完整；附加费、合同组合、汇率、空重箱、中转、内部抵销或其他业务造成的未解释差额单列。
- 如以航运收入除运量估算单位收入，先确认收入与运量是否为同范围、是否包含非运费及附加费，并标为“混合口径平均收入估算”，不冒充公司公布的单航线运价。无法匹配时不计算。
- 缺少可比实现价格时不得以 SCFI、CCFI 或其他指数乘运量替代公司收入；缺少运量或价格时明确无法拆分。

#### D3. 运力、船队与装载

- 区分期末名义运力、期间平均可用运力、航次舱位、实际承运量、重箱量和空箱调运；仅当公司提供可比期间、航次和范围时计算装载率。不能用季度运量直接除以期末船舶 TEU 运力。
- 核查自有船、期租船、光租或其他租赁的数量、容量、费率、剩余期限与到期安排；注意租出船舶及合作舱位，避免重复计数。
- 区分新船订单、已签购船合同、交付日期、在建造成本、资本承诺和实际现金付款；订单规模及公司指引不是已投入运力或已实现盈利。
- 航线绕行、航速、港口等候、维修或空班会改变有效运力和单位成本；只有公司或可靠行业资料支持时才说明实际影响。
- 对联盟、舱位互换或合作经营，核对收入确认、实际控制运力、成本分摊及对手方；不把合作方船舶全部视作自有船队。

#### D4. 航运成本、租赁与会计

- 按披露区分燃油、租船、港使费、码头装卸、内陆运输、空箱调运、箱管、船员、折旧和维修；说明分母、币种、税费及固定／变动成本范围。
- 航线收入除运量与航运总成本除运量只有在口径、期间和抵销一致时才可比较；不把估算差额称为单箱净利润。
- 租船须核查适用准则、租赁期限、使用权资产、租赁负债、折旧、利息、变动租金及短期租赁豁免。租赁本金和利息在现金流中的分类依实际披露；不要把已计入成本的租金、折旧、利息及本金重复扣减。
- 核查燃油采购及附加费、运费衍生品、外汇与利率套期的范围及会计位置；套期或附加费不能默认完全抵消价格波动。
- 核查航程收入确认、预收运费、合同负债、应收账龄、滞箱费和减值；同一航程的计费、服务履约、收款和现金流时点可能不同。
- 核查船舶及码头资产的资本化、使用年限、残值、船坞检修、减值资产组和现金流预测；减值、折旧和处置收益不得一律当作可持续或非经常项目。

#### D5. 码头业务与协同

- 根据公告分别列合并码头收入、利润、吞吐量和权益法投资收益；标明持股、控制、期间、权益口径及内部交易抵销。
- 码头总吞吐量不等于可并表收入，权益吞吐量也不自动等于现金分红；不能将权益法利润和被投资公司全部利润重复计入。
- 核查泊位能力、利用率定义、特许经营或租赁期限、装卸价格、客户和关联交易；吞吐量增长不能直接推断码头利润改善。
- 航运公司支付港口及装卸费用与集团码头收入可能互为内部交易，先看抵销再判断协同；资料不足时不量化。

#### D6. 航运周期、环境及外部约束

- 关注可核验的全球贸易、航线需求、在役运力、新船交付和拆解、运河通行及港口拥堵。订单簿、名义运力和实际有效供给不是同一概念，不根据单个指标断言周期位置。
- 船舶燃料、排放与环保改造义务须按报告期适用法规、船旗／航线及公司披露核查；成本、资本开支及合规时间分别记录，不假定某项规则对所有航线同样适用。
- 关注海上安全、地缘事件、制裁或贸易限制、保险、索赔及网络系统风险；只按适用规定与披露判断，无资料不代表没有风险。
- 区分管理层指引、订单、期后事件和已经实现的运量或利润；未披露实际影响时不作确定性归因。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示主体、证券代码、期间、公告日、会计准则、币种、审计／审阅状态、信息截止日及资料缺口。先给一句话结论，区分披露事实、计算和判断。

#### 二、航运价格与供需坐标

分别列可核验的现货指数、长协信息、公司实现价格、航线和币种；结合可靠资料说明运力、燃油、航程及贸易需求。没有可比基准时不推断周期位置。

#### 三、业绩、运量与利润质量

列示收入、成本、营业利润、集团净利润、归母净利润及同比；分别分析集运、码头和其他披露分部。可比时量化航线运量、实现价、单位成本及量价桥；将内部抵销、汇兑、所得税、联营合营及非控股权益影响分开，无法拆分的不强行归因。

#### 四、船队、航线与码头运营

列示实际承运量及定义、主要航线、自有／租入船队、期末及可用运力、新船订单、码头吞吐量和权益范围；跟踪运力交付、装载与班次、租船期限、港口项目及安全环保信息，注明缺口。

#### 五、资本开支、现金流与资产负债

- 列示经营现金流及与**集团净利润**的比较；只有补充资料足够时做完整调节，不以余额变化代替现金流。
- 分列购船、购箱、码头及环保改造的预算、发生额和付款，按实际披露区分并购；公司 FCF 与分析口径 `经营现金流 − 可核验资本开支现金付款` 分别列示。
- 列示现金、定期存款、受限资金、有息债务、租赁负债、净现金／净债务及到期结构，明确公式和范围。不可自由调拨资金不等同可分配现金。
- 单列租船承诺、新船订单未付款、资本承诺、担保、诉讼及实际付款；核对已计入租赁负债或现金付款的部分，避免重复计算。

#### 六、资产质量与财务排雷

按第 F 节逐项标注“已见风险信号／未见明显异常／信息不足”，附金额、来源、可能影响及待核实凭证；重点检查高运价可持续性、运力、租赁、资产减值及关联交易。

#### 七、估值、股东回报与情景

- A/H 股分别列示价格、日期、币种及对应已发行股份数，核实库存股和汇率。若计算集团总股权市值，应分别按相应股份计价并统一币种后汇总；不能将按全部股份分别计算的 A/H 市值相加。
- PE、EV/EBITDA、FCF 收益率等注明价格、盈利期间、币种、债务、租赁、现金及非控股权益范围，并与同业口径对照；缺少输入时不输出具体倍数。
- 需要构建情景时，列明航线运量、实现运价、合同结构、船队和租船成本、燃油、港口、税费、汇率、资本开支、租赁和股本假设。情景不是预测，不把单年高运价或低投入机械外推。
- 区分已宣派、已批准未支付、已支付股息及实际回购支出；分红方案、派息率和股息率的期间、币种与股数一致。集团资金覆盖与母公司可分配资金分开；不承诺历史分红可持续。
- 无可靠行情、股本、汇率或情景依据时，只给估值框架和资料缺口，不输出目标价、买卖评级或确定性安全边际。

#### 八、结论与下期跟踪

回答利润由运量、实现运价、航线组合、成本及其他项目如何驱动；船队、租船和码头投资的证据；现金覆盖投入、承诺和股东回报的限制。选择 3–5 项对应本期风险的指标，逐项给出当期基准、下一期所需数据和验证方向，不设无依据固定阈值。

### G. Python 最小计算规范

统一币种、箱量及价格口径，保留原始精度；仅展示时四舍五入。计算函数不代替来源和可比性核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        return None
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Value must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if current is None or previous is None:
        return None
    if previous <= 0 or current < 0:
        raise ValueError("Growth requires a positive base and non-negative current value")
    return current / previous - Decimal("1")


def price_volume_bridge(q0, q1, p0, p1):
    q0, q1, p0, p1 = map(D, (q0, q1, p0, p1))
    if any(value is None for value in (q0, q1, p0, p1)):
        return None
    if any(value < 0 for value in (q0, q1, p0, p1)):
        raise ValueError("Quantities and prices must be non-negative")
    volume = (q1 - q0) * p0
    price = (p1 - p0) * q0
    interaction = (q1 - q0) * (p1 - p0)
    return {
        "volume_effect": volume,
        "price_effect": price,
        "interaction": interaction,
        "reconciled_change": volume + price + interaction,
    }


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if ocf is None or capex is None:
        return None
    if capex < 0:
        raise ValueError("Cash capex must be entered as a positive outflow")
    return ocf - capex
```

使用限制：

- 量价桥数量是**同口径实际运量**，价格为对应航线和箱型实现价格；先核实空重箱、币种、附加费与内部抵销。`万 TEU × 元／TEU ÷ 10,000 = 亿元`，数量以 TEU 计时应除以 100,000,000。
- 量价桥不自动解释航线及货种组合、合同、汇率、附加费和会计收入差额；缺数返回无法计算，负数或无效增长基数应报错并在报告说明，不能静默显示为零。
- 公司 FCF 与分析 FCF 定义分开；现金 CapEx 未披露时不以预算、订单金额或资产余额变化替代。检查购船和租赁付款是否已包含，避免重复扣减。
- 负基数、跨零值或零分母不计算误导性增长率；优先列金额变化或“由盈转亏”。装载率、单位成本及情景须先满足对应定义及范围。
