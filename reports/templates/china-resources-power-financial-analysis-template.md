# 华润电力财报分析模板

适用范围：华润电力控股有限公司（00836.HK）的季度、中期及年度报告、业绩公告及相关发电运营资料。实际证券代码、上市主体及业务范围以所提供文件为准。

本模板固定核验方法，不预设具体财报数字、政策或投资结论。火电、新能源发电及可能披露的煤炭等业务，其价格、成本、资产寿命和现金回收方式不同；电量或装机增长、煤价下跌及低市盈率不必然意味着利润、现金流或股东回报改善。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充上年同期、上期及年报、月度发电量和上网电量公告、分技术装机、新能源补贴、资本开支和股息资料。煤价、电价、政策、行业利用小时及市场预期须注明来源、时间和口径。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 电价、燃煤成本、发电与上网电量、补贴、权益装机或项目投入不足时，继续完成可核实部分，明确注明“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的华润电力财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析火电及新能源的装机、发电和上网电量、实现电价、燃料成本、补贴回款、资本开支及现金流。缺少原始数据或可靠预期时不要反推或作确定性结论。

### B. 强制执行规则

1. **派生数字用 Python 计算。** 增速、百分点、单位换算、量价桥、利用小时、燃料成本、现金流、净债务及估值以原始数和 `Decimal` 或等价精度计算；无法运行时说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”；估算列公式、输入、假设、限制及必要的敏感性。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；不得因公告未提及就写“没有风险”或假定补贴全部回收。
4. **期间、范围与单位一致。** 区分并表与权益装机、电量及利润，发电量与上网电量，期末装机与期间平均装机，MW 与 MWh，火电与各类新能源，含税与不含税电价。
5. **先核实列报与抵销。** 电、热、煤炭、绿证、补贴及其他收入可能交叉；核查内部煤炭供应、分部抵销、联营／合营收益和非控股权益，不重复计算利润、现金或绿色收益。
6. **关键判断溯源。** 标注公告、日期、页码或附注；煤价、电价、绿证、利用小时、政策及同业资料须注明地区、期间、单位、适用范围和来源。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查报表重述、并表／权益范围、并网时点、发电／上网、税费、补贴、交易规则和取整。原因未证实前保留差异。
8. **不预设行业结论。** 煤价下跌不必然使火电利润增长；风光装机增长不必然提高可结算电量或现金流；利用小时和上网电价变化不能单独说明项目回报。
9. **市场预期必须可核验。** 一致预期须注明来源、统计时点及利润口径；缺失时写“无可核验一致预期”，改做历史或公司指引对比，不以事后股价反应冒充预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日及估值日；期后事项单列，不作为报告期已实现业绩。用户限定仅用附件时，不擅自引入外部数据。

### C. 数据抽取与底稿

先建立统一底稿，再生成表格、图表与结论：

| 字段 | 要求 |
|---|---|
| 指标及原科目 | 公告原名、报表或业务、公司定义、会计位置 |
| 期间及类型 | 起止日期；单季、累计、期末余额、期间均价、时点或期间平均装机 |
| 数值及单位 | 原数、币种、MW、MWh、千瓦时、供电煤耗、税费及精度 |
| 范围 | 合并、母公司、控股、权益或联营／合营；火电、风电、光伏、供热及煤炭；省份与项目 |
| 数据状态 | 披露原数、同口径差减、估算、未披露、未提供、不适用 |
| 来源 | 文件、公告日、页码、附注、定义、是否重述 |
| 计算链 | 公式、比较基数、假设、限制、项目范围和校验结果 |

**最低财务数据集：**三大报表和附注；发电、供热、煤炭及其他业务收入成本、分部抵销、燃料、折旧、财务费用、税费、补贴和绿证收入；应收电费及补贴、现金与受限资金、借款、项目投资、股息及或有事项。

**最低行业及运营数据集：**

- 按火电、风电、光伏及其他披露技术分别记录期初、期末和期间平均并表／权益装机；新增、收购、退出、试运行及正式并网时间与权益比例。
- 分技术、项目及地区记录发电量、上网电量、利用小时、厂用电率、弃电与限电；标明并表或权益范围、含自用与否、统计期间及口径。
- 分省份、技术和合同记录结算电价、电量、含税／不含税及输配电等费用；区分中长期、现货、容量电价、辅助服务、补贴及绿证收益。
- 火电燃煤采购量与成本、长协／市场煤、热值、运费、库存、供电煤耗及机组利用小时；煤炭自供、外购和内部交易按实际披露分别列示。
- 新能源项目核准、建设、并网、结算和回款进度；国家及地方补贴的应收余额、账龄、减值和收款，以及绿证确权、交易和收入会计位置。
- 资本开支预算、发生额及现金付款，项目投资、融资、借款到期、受限资金、资本承诺、股息及维护投入。可取得时记录生产及新增装机指引，尽可能取得至少 8 个可比季度；不足时降低周期和季节性判断的置信度。

**取数优先级：**在定义和范围可比的前提下，优先使用财务报表及附注原数、公司同口径运营资料、同口径累计差减、管理层正文约数。第三方市场价格是行业坐标，不能替代公司实现价格。

**单季重建：**只有同一财年、口径一致的累计流量才能相减；列明两份来源并标为“同口径推导”。期末装机、期末余额、利用小时、均价、比率及权益占比不得简单相减；不得由取整增速反推明细。

**基础勾稽：**核对收入及成本至经营利润、税前利润、集团净利润与归母净利润；核对资产＝负债＋权益及期初现金经三类现金流、汇率等调节至期末现金。分类汇总前确认合并、内部抵销及权益范围，无法解释的差额单列。

### D. 电力行业专属分析口径

#### D1. 电力市场、电价与需求

- 分别跟踪适用省份的中长期合同、现货、电力辅助服务、容量电价及公司实际结算电价；记录电量、时段、价格、含税状态、输配电费及结算节点。政策或机制只按报告期适用的可核验文件描述，不预设固定电价或补偿标准。
- 公司平均电价可能包含地区、时段、技术、合同、附加收费及交易组合变化；没有同口径资料时不将平均电价变化全部归因于同一项目的市场价格。
- 发电侧电价、用户侧电价、交易中心报价、结算价格和收益不互换；燃料成本与电价传导可能存在合同、地域及时间差，煤价下降不自动推断利润同步增长。
- 结合可核验的电力需求、来水、新能源供给、气候、电网限制及交易规则观察行业；区分行业事实、管理层判断和分析判断。资料不足时不推断周期位置或市场份额。

#### D2. 装机、发电、上网与利用小时

- 分技术列示期末装机、期间平均装机、发电量及上网电量；注明控股／并表、权益口径、是否包含联营合营项目、试运行、停运及新增并网日期。项目额定容量不是期间实际产量。
- 发电量和上网电量之间可能涉及厂用电、自用、计量及项目范围等差异；无完整口径时不得把差额全部称为厂用电或限电。上网电量也不必然等于当期已结算、已收款电量。
- 仅在技术、期间、项目、权益及发电口径一致时，计算近似利用小时 `期间发电量（MWh）÷ 期间加权平均装机（MW）`；此为计算值，与公司披露的利用小时定义可能不同。新项目分阶段并网时，应按实际投运时间加权，不能简单用期末装机作全年分母。
- 同口径容量因子可按利用小时除以期间实际小时数估算；跨年须按实际日历小时数、检修和项目范围说明。期末装机除法、混合权益口径或期间不一致时不计算。
- 弃风弃光、可利用率、停机和限电各有不同分母及原因；缺项目或电网数据时不以利用小时变化倒推弃电率。光伏容量须确认交流侧／直流侧及额定标准。

#### D3. 火电、供热及燃煤成本

- 分列上网电量、结算电价、供热收入、燃料成本、折旧、检修、环保及财务费用；只在相同业务、期间、税费、项目和抵销范围下计算单位收入、单位成本或毛利。
- 煤价应区分长协／市场、坑口／到厂、煤种、热值、运费、含税状态和采购／消耗时间；期末库存价格或外部指数不能直接替代当期入炉煤结转成本。
- 记录供电煤耗的原定义、标准煤单位及供电量分母；发电煤耗与供电煤耗不能混用。只有成本、热值、煤耗及电量同口径时才估算燃料成本，列明单位转换和误差。
- 供热与发电共用燃料、机组和折旧，需核查成本分摊及计量；缺分摊依据时不能将全部机组成本除以上网电量称为单位发电成本。
- 按披露分析煤炭自有产量、外购、贸易和电厂采购；核查内部供应价格及合并抵销，不将煤炭内部销售和电力最终收入机械相加，也不能以自有煤产量代替电厂消耗。

#### D4. 新能源、补贴及绿色权益

- 分风电、光伏及其他技术，核查项目地点、资源、并网时间、利用小时、结算电价、限电和交易方式；资源、天气和电网消纳影响需有资料支持，不能从一个季度直接外推全年。
- 区分可再生能源补贴资格、确认收入、应收补贴、现金回款和账龄；核查项目纳入清单、计价、财政及电网结算、减值及融资安排。应收补贴不是已收现金，缺账龄或政策资料时不能断定回收日期或损失。
- 绿证、绿电及环境权益按项目、期间、确权、交易、会计列报和可适用规则核查；不能默认所有绿证均可单独出售，也不能将已包含于电价的绿色溢价、补贴及另列绿证收入重复计算。
- 关注平价或市场化项目实际结算和电量波动；不根据项目标签自动假定电价、补贴或优先消纳条件。电池储能或配套项目如有披露，核查其成本、收入、利用和控制关系。

#### D5. 电量与收入归因

- 仅在上网／结算电量、实现价格、技术、项目、期间、币种、税费、补贴及并表／权益范围一致时，计算量价桥：量影响 `(Q1 − Q0) × P0`，价影响 `(P1 − P0) × Q0`，交互 `(Q1 − Q0) × (P1 − P0)`；先换算单位，再与**对应口径**收入变化勾稽。
- 分技术、地区或项目计算时确认类别互斥且覆盖完整；项目并购、调度、合同组合、供热、容量电费、辅助服务、补贴、绿证及抵销产生的未解释差额单列。
- 缺少同口径已结算电量或实现价格时，明确无法拆分；不以发电量乘市场报价冒充财报收入，不由取整增速倒推明细。允许按披露处理可能出现的负电价，不将其自动判为无效数据。

#### D6. 项目、现金流与资产质量

- 分开项目核准、开工、建设、试运行、并网、商运和收款；预算、资本承诺、会计发生额、在建工程余额及实际付款不是同一概念。项目投产及新增装机不可等同当期全年发电能力。
- 核查火电及风光资产的折旧年限、残值、资产组、利用小时、电价、煤价、折现率和减值敏感性；资本化利息、在建转固、维修与改造按政策核对，不把经常性折旧一概加回为可分配现金。
- 单列拆除、退役、生态修复及安全环保义务，区分预计负债、折现变动、资本化及实际付款；关注碳排放配额、采购与处置的会计政策和适用范围，不把碳成本默认计为零。
- 区分经营现金流、项目 CapEx 现金付款、并购、租赁、偿债和股息；应收补贴、应收电费及债务余额变化不直接等同现金流。项目公司现金可能受债务契约、少数股东或跨境调拨限制。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示主体、证券代码、期间、公告日、会计准则、币种、审计／审阅状态、信息截止日及资料缺口。先给一句话结论，区分披露事实、计算和判断。

#### 二、电力市场与燃料成本坐标

列出可核验的分省电价、合同及交易口径、公司实现价格、煤炭采购或燃料成本；说明供需、消纳、政策及成本传导限制，不用外部报价代替公司账单。

#### 三、业绩、量价及利润质量

列示收入、成本、经营利润、集团净利润、归母净利润及同比；分火电、风光、供热、煤炭及其他实际披露业务分析。可比时量化结算电量、电价、煤耗和燃料成本；将非控股权益、权益法投资收益、补贴、减值及其他损益分开，无法拆分的不强行归因。

#### 四、装机、电量与项目运营

列示控股／权益装机、期间平均装机、发电及上网电量、利用小时、实际电价、补贴和消纳，按地区及技术拆分；跟踪在建、并网、供热、煤炭供应、安全与环保资料，注明定义及缺口。

#### 五、资本开支、现金流与资产负债

### G. Python 最小计算规范

统一币种、电量、税费和价格口径，保留原始精度；仅展示时四舍五入。计算函数不代替来源和可比性核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        raise ValueError("Missing input")
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Value must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if previous <= 0 or current < 0:
        raise ValueError("Growth requires a positive base and non-negative current value")
    return current / previous - Decimal("1")


def price_volume_bridge(q0, q1, p0, p1):
    q0, q1, p0, p1 = map(D, (q0, q1, p0, p1))
    if q0 < 0 or q1 < 0:
        raise ValueError("Electricity quantities must be non-negative")
    volume = (q1 - q0) * p0
    price = (p1 - p0) * q0
    interaction = (q1 - q0) * (p1 - p0)
    return {
        "volume_effect": volume,
        "price_effect": price,
        "interaction": interaction,
        "reconciled_change": volume + price + interaction,
    }


def utilization_hours(generation_mwh, weighted_average_mw):
    generation, capacity = D(generation_mwh), D(weighted_average_mw)
    if generation < 0 or capacity <= 0:
        raise ValueError("Generation must be non-negative and capacity positive")
    return generation / capacity


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if capex < 0:
        raise ValueError("Cash capex must be entered as a positive outflow")
    return ocf - capex
```

使用限制：

- 量价桥数量是**同口径结算电量**，价格为对应电量实际结算价格；核对税费、补贴、供热、绿色溢价及内部抵销。`亿千瓦时 × 元／千瓦时 = 亿元`；MWh 换算为千瓦时须乘 1,000。
- 量价桥不自动解释项目或合同组合、容量电费、补贴和收入确认差额；缺数或不可比时说明无法计算，不以市场报价补数。程序抛出的输入错误须明确告知，不得静默替换为零。
- 利用小时分母是按实际投运时间加权、与发电量相同范围的平均 MW；分子为对应 MWh。示例 `876,000 MWh ÷ 100 MW = 8,760 小时`；实际使用须确认时段及公司定义。
- 公司 FCF 与分析 FCF 定义分开；现金 CapEx 未披露时不以预算、发生额或资产余额变化替代。检查租赁、补贴融资及退役付款是否已包含，避免重复扣减。
- 负基数、跨零值或零分母不计算误导性增长率；优先列金额变化或“由盈转亏”。容量因子、单位成本和情景须先满足对应定义及范围。
