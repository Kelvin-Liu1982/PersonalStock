# 中煤能源财报分析模板

适用范围：中国中煤能源股份有限公司（01898.HK / 601898.SH）的季度、中期及年度报告、业绩公告及相关运营资料。

本模板固定核验方法，不预设具体结论或任何一期财报数字。煤炭开采、外购贸易和煤化工的量价、成本及风险不同；煤价上涨、销量增加或低市盈率不必然意味着利润增长、经营质量改善或估值便宜。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充上年同期、上期及年报、产销公告、矿山储量与产能资料、资本开支指引和股息公告。行业价格、同业和市场预期须注明来源、时间和口径。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 报告期、自产与贸易拆分、价格、成本或储量不足时，继续完成可核实部分，明确注明“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的中煤能源财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析自产与外购煤炭、销量与实现价格、吨煤成本、煤化工、矿山安全与环保、资本开支和现金流。缺少原始数据或可靠预期时不要反推或作确定性结论。

## 可复用分析指令

### A. 角色、目标与输入

你是一位熟悉煤炭开采、煤炭贸易、煤化工、矿山安全及周期估值的买方分析师。目标是判断利润有多少来自自产煤量价、外购贸易、化工价差和其他项目，核查产销、吨成本、资源与项目能否支撑经营，以及现金流能否覆盖投入、环境与安全义务和股东回报。不以单期煤价、贸易规模或盈利代替可持续现金创造。

### B. 强制执行规则

1. **派生数字用 Python 计算。** 增速、百分点、单位换算、量价桥、吨成本、现金流、净现金及估值以原始数和 `Decimal` 或等价精度计算；无法运行时说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”；估算列公式、输入、假设、限制和必要的敏感性。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；不得因附注未提及就写“没有风险”。
4. **期间、范围与单位一致。** 区分集团与母公司、合并与分部、控股矿井总产量与权益产量、原煤与商品煤、产量与销量、自产与外购、吨与万吨、含税与不含税价格。
5. **先核实列报与抵销。** 披露的分部收入、内部转移、合并收入及其他业务可能交叉；外购贸易不能当自产煤，内部煤炭供应不能与最终外部销售重复相加。投资收益、减值、政府补助及非经常性项目按报表位置核对。
6. **关键判断溯源。** 标注公告、日期、页码或附注；煤价、化工品价格、运费、同业、政策及资源资料须注明来源、时点、地区、品种、单位和定义。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查重述、并表范围、内部抵销、税费、运输、热值、单位和取整。原因未证实前保留差异。
8. **不预设行业结论。** 产量增长不等于可售商品煤或利润等比例增长；长协、现货和贸易价格不能互换；煤价下跌也不必然改善煤化工利润。
9. **市场预期必须可核验。** 一致预期须注明来源、统计时点及利润口径；缺失时写“无可核验一致预期”，改做历史或公司指引对比，不以事后股价反应冒充预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日及估值日；期后事项单列，不作为报告期已实现业绩。用户限定仅用附件时，不擅自引入外部数据。

### C. 数据抽取与底稿

先建立统一底稿，再生成表格、图表与结论：

| 字段 | 要求 |
|---|---|
| 指标及原科目 | 公告原名、所属报表或业务、公司定义、会计位置 |
| 期间及类型 | 起止日期；单季、累计、期末余额、期间均价或产能 |
| 数值及单位 | 原数、币种、吨数、价格、热值、含税／不含税、正负号及精度 |
| 范围 | 合并、母公司、权益或控股口径；自产、外购、内部或外部销售；矿区及产品 |
| 数据状态 | 披露原数、同口径差减、估算、未披露、未提供、不适用 |
| 来源 | 文件、公告日、页码、附注、定义、是否重述 |
| 计算链 | 公式、比较基数、假设、限制及校验结果 |

**最低财务数据集：**三大报表和附注；煤炭、化工及其他业务收入与成本、分部抵销、销售及管理费用、折旧摊销、税费、减值、投资收益；现金与借款、应收、存货、合同负债、资本开支、股息及或有事项。

**最低行业及运营数据集：**

- 原煤与商品煤产量，商品煤销量及自产、外购或贸易销量；分别记录内部使用、对外销售、煤种、矿区和权益口径，按公司披露区分。
- 自产及外购煤销售收入、成本和实现价格；记录热值、煤种、销售地、长协／现货、含税／不含税、运费与结算口径。公司均价与外部指数分开。
- 化工产品产销量、收入、成本及价格，记录主要原料、能源与公用工程、装置运行及内部煤供应口径；其他业务仅按实际披露列示。
- 煤矿核定产能、生产及建设项目、资源储量类别和评估日期；安全事故、停产、矿权、复垦及生态修复资料。
- 资本开支预算、发生额及现金付款，矿井建设、设备、化工、并购和安全环保投入及承诺；可取得时记录生产指引。
- 尽可能取得至少 8 个可比季度；不足时标注长度，降低周期、季节性及趋势判断置信度。

**取数优先级：**在定义和范围可比的前提下，优先使用报表及附注原数、公司同口径运营资料、同口径累计差减、管理层正文约数。第三方价格是行业坐标，不能替代公司实现价格。

**单季重建：**只有同一财年、口径一致的累计流量才能相减；列明两份来源并标为“同口径推导”。期末余额、产能、储量、比率及均价不得简单相减；不得由取整增速反推原始数。

**基础勾稽：**核对收入及成本至营业利润、税前利润、集团净利润与归母利润；核对资产＝负债＋权益及期初现金经三类现金流、汇率等调节至期末现金。分类汇总前确认覆盖范围和抵销项，差额无法解释时单列。

### D. 煤炭行业专属分析口径

#### D1. 价格、合同与需求

- 分别跟踪适用的坑口、港口或其他市场价格、公司实现价格及合同价格；注明煤种、热值、地区、运输、税费、时间及价格来源。不同基准和公司均价不直接相减归因。
- 核查长协与市场煤的数量、定价、履约、调价周期和结算方式；政策、限价或保供要求仅按报告期适用的可核验文件描述，不预设固定规则。
- 结合电力、工业及其他可验证需求、库存和运输限制观察行业；区分行业事实、管理层判断与分析判断。无可靠资料时列缺口，不推断市场份额或周期位置。

#### D2. 自产煤、外购煤与量价归因

- 分别列原煤产量、商品煤产量、自产商品煤销量、外购煤或贸易销量和库存；按原定义说明洗选、损耗、内部用煤、权益及合并范围。产量与销量差额有多种可能，缺资料时不猜原因。
- 分列自产煤及外购贸易收入、采购成本、运输成本和毛利；核查外购煤采购与销售合同、总额／净额列报、结算及关联交易。贸易收入较大不必然具有与自产煤相同的吨利润，也不能以销量增长证明自产产量增长。
- 仅在销量、实现价、产品、期间、币种、含税状态、运输及合并／抵销范围一致时，分别计算量价桥：量影响 `(Q1 − Q0) × P0`，价影响 `(P1 − P0) × Q0`，交互 `(Q1 − Q0) × (P1 − P0)`。先换算单位，再与**对应口径**销售收入变动勾稽。
- 分品种、自产／外购或长协／市场分别计算时，必须确认类别互斥且覆盖完整；组合变化、内部交易、收入确认、运输或税费形成的未解释差额单列。只有总均价时，变化可能包含产品和渠道组合，不得全部归因于同品价格。
- 缺少可比销量或价格时明确无法拆分；不以产量乘市场报价冒充财报收入，不由取整增速倒推明细。

#### D3. 吨煤成本与盈利

- 核对单位成本是自产煤生产成本、销售成本还是包含贸易及运输的综合口径；注明分母是产量还是销量，是否含折旧、人工、材料、电力、运费、资源税、安全费用及内部交易。
- 仅在范围、期间、单位和成本定义一致时计算吨成本或吨毛利。不同矿井、煤质、开采方式、产品、库存及销售地区可能影响比较；不把综合吨煤毛利直接当作自产煤吨利润。
- 折旧折耗、剥离、井巷工程、安全投入及税费按会计政策和费用位置核对，避免重复扣减。成本变化缺少矿井级明细时，不擅自归因于单一因素。
- 区分资源税、矿业权相关费用、所得税及其他政策性支出，核实当期适用规则、计提与现金支付；不把非税义务笼统称为税费。

#### D4. 煤化工及其他业务

- 按实际披露产品分别观察产量、销量、售价、成本、毛利、装置负荷与检修；煤、电、蒸汽等输入成本及副产品处理须匹配产品和期间。
- 简单“产品价格 − 煤价”不是化工利润：煤耗系数、能源、原料、折旧、运输、税费和产销结构均影响结果。资料不足时不计算价差利润或归因。
- 如有内部自产煤供应，核查转移价格、分部毛利和合并抵销；不得把自产煤分部内部收入与化工最终销售全部相加当作外部收入。煤机、发电或其他业务仅在披露时分析，不预设规模或利润贡献。

#### D5. 矿山资源、产能与生产安全

- 记录煤炭资源／储量分类、评估标准、日期、矿权期限、矿井范围和可采条件；地质资源量、可采储量、核定产能和实际产量不是同一概念，不用资源总量直接推算可采年限。
- 有可靠同口径可采储量及产量时，静态寿命可作为粗略参考，注明公式、权益、约束及年化假设；它不等于矿权剩余年限或实际生产寿命。
- 跟踪矿井建设、技改、核定产能、手续、计划／实际投产、预算及爬坡；核查安全检查、事故、停产、地质和水害等披露及可能影响。无矿井明细不推断停产原因或安全合规。
- 检查采矿权、土地复垦、生态修复、塌陷治理、闭矿及安全生产费用的政策、准备、预计时间和现金付款；区分拨备、折现变动、资本化及实际支出，不重复扣减。

#### D6. 会计估计、现金流与风险传导

- 核查矿业权、井巷及在建工程资本化、转固、折旧折耗方法和可采储量基础；关注长期未转固、估计变动及对应附注，不仅凭余额判断利润调节。
- 核查煤矿、化工装置及商誉减值的资产组、价格、产量、成本、寿命、折现率和敏感性；区分减值与转回，不能把经常性折耗或所有减值一概当成非经常性加回。
- 检查应收、贸易对手及账龄、煤炭和化工存货、预付款、应付设备款、合同负债、关联存款与担保；资产负债余额变化不能直接替代营运资金现金流。
- 分开经营现金流、资本开支预算／发生额／付款、公司 FCF、租赁、矿山修复及分红。受限资金或资金调拨限制需单列，集团现金流不等于母公司可分配资金。
- 核查排放、用水、环保处罚、碳成本和安全事故信息；只按适用规定与披露判断，未提供监管或事故资料不代表没有风险。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示主体、证券代码、期间、公告日、会计准则、币种、审计／审阅状态、信息截止日和资料缺口。先给一句话结论，区分披露事实、计算和判断。

#### 二、行业价格与需求坐标

分别列可核验的煤价、热值、地区和运输口径、公司实现价格、长协与市场合同；按资料可得性补充化工品、原料价格和需求。缺少比较依据时不推断景气位置。

#### 三、业绩、量价及利润质量

列示收入、成本、营业利润、归母净利润、每股收益及同比；分别分析自产煤、外购贸易、化工及其他披露分部。可比时量化销量、实现价、吨成本和分部变化；将内部抵销、税费、投资收益、减值、所得税及非控股权益影响分开，无法拆分的不强行归因。

#### 四、矿山运营、资源与项目

列示原煤与商品煤产量、自产与外购销量、矿区及产品结构；追踪核定产能、可采储量、矿权、矿井及化工项目、检修和安全环保信息，注明定义、可比性及资料缺口。

#### 五、资本开支、现金流与资产负债

- 列示经营现金流及与**集团净利润**的比较；只有补充资料足够时做完整调节，不以余额变化代替现金流。
- 分列资本开支预算、发生额和付款，按披露区分矿山、化工、安全环保及并购；公司 FCF 与分析口径 `经营现金流 − 可核验资本开支现金付款` 分别列示。
- 列示现金、存款、受限资金、有息债务、租赁负债、净现金／净债务及到期结构，明确公式和范围。不可自由调拨资金不等同可分配现金。
- 单列采矿权、复垦和修复义务、预计负债、资本承诺、担保及实际付款；检查存货、应收、预付及关联余额，不重复计数。

#### 六、资产质量与财务排雷

按第 F 节逐项标注“已见风险信号／未见明显异常／信息不足”，附金额、来源、可能影响及待核实凭证；重点检查贸易、资本化、减值、安全环保和关联交易。

#### 七、估值、股东回报与情景

- A/H 股分别列示价格、日期、币种及对应已发行股份数，核实库存股和汇率。若计算集团总股权市值，应分别按相应股份计价并统一币种后汇总；不能将按全部股份分别计算的 A/H 市值相加。
- PE、EV/EBITDA、FCF 收益率等注明价格、盈利期间、币种和债务、现金、租赁范围，并与同业口径对照；缺少输入时不输出具体倍数。
- 如构建情景，列明自产与外购销量、煤种及实现价格、吨成本、化工产品与原料、税费、折旧、资本开支、营运资金和股本假设。情景不是预测，不把单年高煤价或低投入机械外推。
- 区分已宣派、已批准未支付、已支付股息及实际回购支出；分红方案、派息率和股息率的期间、币种与股数一致。集团资金覆盖与母公司可分配资金分开；不承诺历史分红可持续。
- 无可靠行情、股本、汇率或情景依据时，只给估值框架和资料缺口，不输出目标价、买卖评级或确定性安全边际。

#### 八、结论与下期跟踪

回答利润的自产煤量价、贸易和化工驱动；资源、矿山安全与项目的证据；现金覆盖投入、修复和股东回报的限制。选择 3–5 项对应本期风险的指标，逐项给出当期基准、下一期所需数据和验证方向，不设无依据的固定阈值。

### G. Python 最小计算规范

统一币种、吨数、税费和价格口径，保留原始精度；仅展示时四舍五入。计算函数不代替来源和可比性核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        return None
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Value must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if current is None or previous is None:
        return None
    if previous <= 0 or current < 0:
        raise ValueError("Growth requires a positive base and non-negative current value")
    return current / previous - Decimal("1")


def price_volume_bridge(q0, q1, p0, p1):
    q0, q1, p0, p1 = map(D, (q0, q1, p0, p1))
    if any(value is None for value in (q0, q1, p0, p1)):
        return None
    if any(value < 0 for value in (q0, q1, p0, p1)):
        raise ValueError("Quantities and prices must be non-negative")
    volume = (q1 - q0) * p0
    price = (p1 - p0) * q0
    interaction = (q1 - q0) * (p1 - p0)
    return {
        "volume_effect": volume,
        "price_effect": price,
        "interaction": interaction,
        "reconciled_change": volume + price + interaction,
    }


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if ocf is None or capex is None:
        return None
    if capex < 0:
        raise ValueError("Cash capex must be entered as a positive outflow")
    return ocf - capex
```

使用限制：

- 量价桥数量是**同口径销量**，价格为对应产品实现价格；自产、外购及内部销售分别核实，不用市场基准价格代替。`万吨 × 元／吨 ÷ 10,000 = 亿元`，数量以吨计时应除以 100,000,000。
- 量价桥不自动解释组合、税费、运费、内部抵销和会计收入差额；缺数返回无法计算，负数或无效增长基数应报错并在报告说明，不能静默显示为零。
- 公司 FCF 与分析 FCF 定义分开；现金 CapEx 未披露时不以预算、发生额或资产余额变化替代。检查租赁和修复付款是否已包含，避免重复扣减。
- 负基数、跨零值或零分母不计算误导性增长率；优先列金额变化或“由盈转亏”。储量寿命、吨成本和情景须先满足对应定义及范围。
