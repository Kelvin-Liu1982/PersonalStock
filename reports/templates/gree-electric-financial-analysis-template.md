# 格力电器财报分析模板

适用范围：珠海格力电器股份有限公司（000651.SZ）的季度、中期及年度报告、业绩公告及相关经营资料。上市主体、证券代码、业务范围及报告口径以实际提供的文件为准。

本模板沿用中煤能源分析框架，但围绕家电制造的产品组合、渠道与终端、季节性、原材料、售后、库存和资金运用设计。空调销售增长、经销商预收款增加、高现金余额或低市盈率，不必然意味着终端需求、盈利质量或股东回报改善。本模板不预设财报数字、政策或投资结论。

## 使用方式

1. 提供当期财报或业绩公告；如有，补充上年同期、上期及年报、产品产销和库存、渠道、售后、资本开支、分红与回购资料。行业、同业、政策及市场预期资料须注明来源、时间和口径。
2. 将“可复用分析指令”整体交给分析助手，或要求其读取本模板。
3. 销量、终端动销、渠道库存、返利、质保、现金限制或其他数据不足时，继续完成可核实部分，明确注明“未披露”“未提供”或“无法可靠计算”，不得自行补齐。

可直接使用的调用语句：

> 请按本模板分析附件中的格力电器财报，先确认上市主体、报告期、会计准则及信息截止日。使用 Python 计算派生指标并与公告勾稽，再交付中文 HTML 报告。重点分析空调和其他实际披露业务、渠道发货与终端动销、季节性、原材料成本、存货、销售费用、售后质保、现金运用及股东回报。缺少原始数据或可靠预期时不要反推或作确定性结论。

### B. 强制执行规则

1. **派生数字用 Python 计算。** 增速、百分点、单位换算、量价桥、周转、现金流、净现金及估值使用原始数和 `Decimal` 或等价精度；无法运行时说明，不声称已精算。
2. **事实、计算和判断分层。** 标明“公告披露”“同口径推导”“分析估算”“分析判断”；估算列公式、输入、假设、限制及必要的敏感性。
3. **缺失不等于零。** 区分“未披露”“未提供”“不适用”“无法可靠计算”；不得因附注未提及就写“没有风险”或假定渠道库存健康。
4. **期间、范围与单位一致。** 区分集团与母公司、空调及其他产品、境内与境外、自有品牌与代工、出货与终端销售、台数与套数、含税与不含税价格。
5. **先核实列报与抵销。** 产品、地区、渠道、分部或关联交易分类可能交叉；核查内部抵销、返利、退货、安装及售后服务收入的确认位置，不重复计算收入或利润。
6. **关键判断溯源。** 标注公告、日期、页码或附注；行业价格、终端销量、政策、天气、原材料与同业资料须注明来源、时间、地域、样本及定义。
7. **数据冲突不得静默修正。** 列示来源、差额、采用值及用途；核查重述、并表范围、统计渠道、产销单位、返利、税费、运输、汇率与取整。原因未证实前保留差异。
8. **不预设行业结论。** 产品收入增长不必然意味着终端份额提高；原材料跌价不必然即时改善毛利；合同负债增加不必然是旺盛需求或现金永久可用。
9. **市场预期必须可核验。** 一致预期须注明来源、统计时点及利润口径；缺失时写“无可核验一致预期”，不以事后股价反应冒充预期。
10. **信息时点可追踪。** 区分报告期、期末日、公告日及估值日；期后事项单列，不作为报告期已实现业绩。用户限定仅用附件时，不擅自引入外部数据。

- 经销、直营、电商及其他渠道的收入确认、出货、终端零售、渠道库存、促销、返利、退货、安装及结算条款；缺数据不将渠道发货当终端动销。
- 分产品、地区、渠道记录实际不含税销售价格及销量；说明型号、能效、产品组合、运输、折扣、返利、补贴、币种和税费。公开零售价及行业指数不替代公司实现价格。

- 安装、保修及售后政策、实际费用、预计负债计提与使用；必要时记录质量事件、召回、诉讼及未决事项。
- 经销预收、合同负债、应收与票据、库存、理财和存款、受限资金、债务、承诺、资本开支、分红及回购。尽可能取得至少 8 个可比季度；不足时降低季节性与周期判断置信度。

**取数优先级：**在定义和范围可比的前提下，优先使用报表及附注原数、公司同口径运营资料、同口径累计差减、管理层正文约数。第三方零售和行业数据是参考坐标，不替代公司出货或财报确认收入。

**单季重建：**仅同一财年、口径一致的累计流量可相减；列明两份来源并标为“同口径推导”。期末余额、均价、毛利率、周转率和市场份额不得直接相减得到单季值；可比收入、成本原数足够时先差减再计算单季比率。不得由取整增速倒推明细。

**基础勾稽：**核对收入及成本至营业利润、税前利润、集团净利润与归母净利润；核对资产＝负债＋权益及期初现金经三类现金流、汇率等调节至期末现金。分类汇总前确认覆盖范围和内部抵销，无法解释的差额单列。

### D. 家电行业专属分析口径

#### D1. 需求、季节性与竞争

- 空调需求可能受气温、销售旺季、房地产交付、更新换代、能效、渠道促销和出口等因素影响；只有资料支持时才将某项因素用于本期解释。区分管理层观点与分析判断。
- 同比优先比较同一季节；单季波动不直接年化或外推全年。冷年、自然年、财务季度与促销节点可能不同，须注明起止日期。
- 核查零售与出货的地域、线上线下覆盖、品牌、样本及统计期间。行业总销量、第三方零售额、市场份额和公司确认收入不互换；未提供可靠依据时不推断份额。
- 以旧换新、节能补贴等政策，仅按适用期、地区、产品、来源及实际会计处理分析；区分消费者补贴、经销补贴与公司政府补助，不预设金额或持续性。

#### D2. 产品、量价与盈利

- 按财报实际披露区分空调、生活电器、工业制品及其他业务，不假设每类产品一定单独披露。分产品收入和成本比较前确认分类、内部抵销与合并范围；其他收入不自动等同新业务销售。
- 仅在销量、实现价、产品、期间、币种、税费、返利和收入确认范围一致时计算量价桥：量影响 `(Q1 − Q0) × P0`，价影响 `(P1 − P0) × Q0`，交互 `(Q1 − Q0) × (P1 − P0)`；先换算单位，再与**对应口径**收入变动勾稽。
- 分型号、渠道及地区计算须确认类别互斥且覆盖完整；均价变化可能含型号、能效、渠道、地区、促销及汇率组合变化。未解释的返利、退货、税费和收入确认差额单列，不将均价变化全部归因于提价。
- 缺可比销量或实现价时明确无法拆分；不以产量、平台标价、行业均价或取整增速反推财报收入。国际业务应区分原币收入、汇率折算、关税、运费和信用风险。

#### D3. 渠道、合同负债与营运资金

- 区分制造商发货、向经销商确认收入、经销商向终端销售及消费者安装；同一批商品可能跨期。经销、直营及线上各按实际披露合同分析，不预设统一销售模式。
- 查阅控制权转移、验收、退换货、价保、返利、促销支持和可变对价政策；按披露核查销售折扣是冲减收入、计入费用还是其他处理，不因一项比例变化断定压货或违规。
- 合同负债或预收款余额受季节、收款、发货、税费和分类影响；余额增长不是终端订单或利润，期末余额变化也不直接等于现金流。需要时与已披露履约、退款和经营现金流一起核对。
- 公司库存不包括独立经销商持有的全部库存；没有可比第三方或公司披露时不得推算渠道库存、库存周数或动销率。应收、票据及经销商信用政策与收入变化一起核查。

#### D4. 原材料、制造成本与存货

- 区分铜、铝、钢、塑料、核心零部件等价格与采购、生产和销售成本结转时点；公开市场报价不能直接代替实际采购成本。核查库存计价方法、汇率、套期或锁价和采购合同。
- 毛利率受产品及渠道组合、出货价格、原材料、产能利用、人工、折旧、保修及促销等共同影响；只有同口径明细支持时才进行定量归因。
- 分别核查原材料、在产品、库存商品及发出商品的金额、变动、库龄和跌价准备；气温、旺季和备货可能影响余额，但不能未经证实解释全部变化。
- 仅在分子分母期间与范围相匹配时估算存货周转：`期间营业成本 ÷ 期间平均存货`。期初期末简单平均仅为近似，旺季或月度波动大时应优先采用披露的期间平均余额；零分母不计算。周转天数需注明期间实际天数、是否年化及简化假设，不能当作渠道库存天数。

#### D5. 销售费用、售后与产品质量

- 观察销售费用率及广告、渠道、运输、安装、促销等实际披露项目；收入扣减与费用、履约成本及运费重分类应按会计政策区分。缺项目明细不把费用率变化全部归因于营销。
- 核查保修服务承诺、预计负债的期初、计提、实际使用、转回和期末余额；质保成本按销售批次、寿命及估计计量，期末余额变化不等于当期现金支出。
- 跟踪安装能力、售后网络、产品质量、召回和诉讼；无法取得事故或投诉数据时标明信息不足，不以缺少披露推断不存在问题。
- 研发费用、资本化及无形资产按政策核查；研发投入不等于研发成果，也不将所有资本化视为异常。记录压缩机、零部件及其他业务的内部销售和抵销。

#### D6. 现金运用、财务收益及股东回报

- 分开货币资金、定期存款、受限资金、交易性金融资产、理财、结构性存款及其他投资；按流动性、期限、信用风险、公允价值和合同披露判断，不将所有金融资产视为现金等价物或保本。
- 区分借款、租赁负债、应付票据及担保；计算净现金时列公式，说明纳入的资产、受限资金和债务范围。银行承兑汇票保证金、质押资金及子公司资金可用性须单列；不将应付票据一概当有息借款。
- 利息收入、理财收益、公允价值变动、汇兑及政府补助按报表位置分别列示；投资收益不是主业利润或必然现金回款。核查关联方、财务公司存款、授信和资金往来。
- 区分经营现金流、资本开支预算／发生额／付款、公司 FCF、租赁、收购和出售金融资产现金流。投资产品到期回收及购买可能显著影响投资现金流，不等同固定资产 CapEx。
- 区分股息方案、已批准未支付、已支付股息及实际回购支出；核对回购用途、库存股、注销与股数变化。集团现金不等于母公司可分配资金，也不保证未来回报。

### E. 财报分析输出框架

#### 一、报告边界与核心结论

列示主体、证券代码、期间、公告日、准则、币种、审计／审阅状态、信息截止日和资料缺口。先给一句话结论，区分披露事实、计算和判断。

#### 二、需求、竞争及原材料坐标

列出可核验的终端零售、气候或政策、原材料与同业数据，并标记地区、期间、样本与定义；资料不足不推断市场份额、天气影响或成本传导。

#### 三、业绩、产品量价及利润质量

列示收入、成本、毛利率、营业利润、集团净利润、归母净利润及同比。按实际披露分析空调、其他产品、境内外和渠道；可比时量化销量及实现价、产品结构和成本；将返利、费用、投资收益、补助、减值及所得税分开，无法拆分的不强行归因。

#### 四、渠道、生产与售后

列示同口径产销、公司库存、渠道与终端资料、订单及合同负债、安装和保修；说明季节性、产品与统计范围。跟踪质量、研发及供应链，不能以生产量或出货量代替终端销量。

#### 五、现金流、资产负债与资本配置

- 列示经营现金流及与**集团净利润**的比较；只有补充资料足够时做完整调节，不以余额变化代替现金流。
- 分列资本开支预算、发生额及现金付款；公司 FCF 与分析口径 `经营现金流 − 可核验资本开支现金付款` 分别列示。
- 分列现金、定期存款、受限资金、金融资产、借款和租赁负债；明确净现金／净债务公式及可用性，不混同现金等价物与理财。
- 核查应收、票据、存货、合同负债、返利、预计负债、担保、资本承诺、收购、分红及回购；已计入现金或负债的项目避免重复扣减。

#### 六、资产质量与财务排雷

按第 F 节逐项标注“已见风险信号／未见明显异常／信息不足”，附金额、来源、可能影响及待核实凭证；重点检查终端动销、渠道库存、合同负债、售后、投资及资金可用性。

#### 七、估值、股东回报与情景

- 核实股价、日期、币种、已发行股份、库存股及口径；市值与利润、自由现金流比较前统一期间和股东权益范围。
- PE、EV/EBITDA、FCF 收益率等注明价格、盈利期间、债务、现金、金融资产及租赁范围，并与同业口径对照；缺少输入时不输出具体倍数。
- 如构建情景，列明空调及其他产品可比销量、实际价格、渠道与返利、原材料、毛利、费用、售后、营运资金、CapEx 和股本假设。情景不是预测，不把单季旺季或一次性收益机械外推。
- 区分拟议、批准及已支付股息和实际回购支出；派息率和股息率的币种、股数及期间一致。母公司可分配资金和集团现金分开；不承诺历史分红可持续。
- 无可靠行情、股本或情景依据时，只给估值框架和资料缺口，不输出目标价、买卖评级或确定性安全边际。

#### 八、结论与下期跟踪

### G. Python 最小计算规范

统一币种、销量、税费、期间和价格口径，保留原始精度；仅展示时四舍五入。计算函数不代替来源和可比性核验。

```python
from decimal import Decimal


def D(value):
    if value is None:
        raise ValueError("Missing input")
    result = Decimal(str(value))
    if not result.is_finite():
        raise ValueError("Value must be finite")
    return result


def growth(current, previous):
    current, previous = D(current), D(previous)
    if previous <= 0 or current < 0:
        raise ValueError("Growth requires a positive base and non-negative current value")
    return current / previous - Decimal("1")


def price_volume_bridge(q0, q1, p0, p1):
    q0, q1, p0, p1 = map(D, (q0, q1, p0, p1))
    if any(value < 0 for value in (q0, q1, p0, p1)):
        raise ValueError("Quantities and prices must be non-negative")
    volume = (q1 - q0) * p0
    price = (p1 - p0) * q0
    interaction = (q1 - q0) * (p1 - p0)
    return {
        "volume_effect": volume,
        "price_effect": price,
        "interaction": interaction,
        "reconciled_change": volume + price + interaction,
    }


def inventory_turnover(period_cost, average_inventory):
    cost, inventory = D(period_cost), D(average_inventory)
    if cost < 0 or inventory <= 0:
        raise ValueError("Cost must be non-negative and average inventory positive")
    return cost / inventory


def analytical_fcf(operating_cash_flow, cash_capex):
    ocf, capex = D(operating_cash_flow), D(cash_capex)
    if capex < 0:
        raise ValueError("Cash capex must be entered as a positive outflow")
    return ocf - capex
```

使用限制：

- 量价桥数量是**同口径销售量**，价格为对应产品实际实现价格；核查产品、渠道、返利、退货、税费和确认范围。`万台 × 元／台 ÷ 10,000 = 亿元`，数量以台计时金额除以 100,000,000。
- 量价桥不自动解释型号、产品及渠道组合、税费、运费和收入确认差额；缺数或不可比时说明无法计算，不以零售价补数。程序抛出的输入错误须明确告知，不得静默替换为零。
- 存货周转是期间营业成本除以同范围期间平均存货，非年化；如以期初期末简单平均，明确为近似。跨期间比较须处理季节性及期间长度；不将周转天数解释为渠道库存。
- 公司 FCF 与分析 FCF 定义分开；现金 CapEx 未披露时不以预算、发生额或资产余额变化替代。检查理财购买、租赁及售后付款是否已包含，避免重复扣减。
- 负基数、跨零值或零分母不计算误导性增长率；优先列金额变化或“由盈转亏”。毛利率、净现金及情景须先满足对应定义及范围。
