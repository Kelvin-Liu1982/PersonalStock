核心结论摘要
偏积极

中国石油 2026 一季报营收 7,363.83 亿元（−2.21%）、归母 483.32 亿元（+1.86%、环比 +55.8%）创历史同期新高、扣非 495.79 亿元（+5.03%）。核心叙事是「油价下行、结构优化」：上游受油价下行与实现价折价扩大拖累（原油实现价 64.08 美元/桶、−8.5%，上游经营利润 −12%），但天然气量价齐升（销量 +6.9%、经营利润 +39.7%）与炼化下游修复（炼油 +57.7%、化工扭亏改善、乙烯 +21.4%）对冲上游拖累，推动利润逆势创新高。盈利质量「真」：扣非 495.79 亿元高于归母 483.32 亿元（非经常性 −12.5 亿元为负贡献）。隐忧在于现金流与营运资金：①OCF 844.7 亿元同比 −39.4%（油价上行期存货与应收占用、其他应收较年初 +176.79%）；②资产负债率季环比回升至 39.58%（+3.5pp）；③炼化高增含库存重估增利的一次性。

✓ 核心利好
  • 业绩创历史同期新高、结构优化：归母 483.32 亿（+1.86%）；天然气经营利润 +39.7%、炼油 +57.7%、销售 +28.4%，对冲上游 −12%
  • 盈利质量「真」：扣非 495.79 亿 高于归母 483.32 亿（非经常性 −12.5 亿为负贡献），利润全靠主业结构优化，无粉饰
⚠ 核心风险
  • 上游对油价高度敏感：原油实现价 −8.5% → 上游经营利润 −12%，Q4 地缘溢价回落后油价中枢下移风险
  • 经营现金流大幅走弱：OCF 同比 −39.4%（1,395 → 845 亿），其他应收款较年初 +176.79%、资产负债率季环比回升 3.5pp

预期来源与统计时点：机构一致预期（光大证券/海通国际/国泰海通，统计时点 2026-04 披露前，IFRS/归母口径）：2026 全年归母一致预期约 1,900–2,016 亿元（光大 1,902 / 海通 2,016 / 国泰海通 1,900+）。一季度单季归母 483.32 亿元年化（×4 ≈ 1,933 亿）处区间中枢、略高于下限，属「符合预期、无显著预期差」。多家券商（光大/国泰海通/海通国际，2026-05）点评「业绩再创新高 / 基本符合预期」。注意：机构间 2026E 分歧较大（1,869–2,016 亿），富途引用某券商单季预期 532 亿、实际 483 亿略低于该预期（主因实现价折价扩大），属个别机构偏高预期。

行业坐标与供需

行业所处阶段与传导方向：石油石化行业 2026 年一季度处于「油价高位回落、低库存托底」的中高分位震荡段。核心变量：① 油价——2026 年被定义为全球石油「地缘大年」，美伊冲突致霍尔木兹海峡一度中断、中东供应受损，过剩预期转为现货缺口；一季度布伦特均价 78 美元/桶（+4.5%），但 6 月美伊签署谅解备忘录后地缘降级、油价自高位回落；② 供需——低库存提供底部支撑，但 Q4 起 OPEC+ 增产与旺季结束或令中枢缓慢下移；③ 政策——能源安全「增储上产」+ 新能源替代加速。对公司的传导：关键在「实现价 vs Brent」的折价——一季度公司原油实现价 64.08 美元/桶（同比 −8.5%）因结算滞后折价扩大，行业高价未全额传导至上游，导致上游利润 −12%；而天然气量价齐升与炼化下游修复成为利润增长主源。行业坐标：油价处中高分位但公司实现价折价扩大，业绩「以量补价 + 结构优化」驱动，与三季报（油价上行全面增长）形成镜像。

量价 / 供需 / 价格位置 / 政策：量：天然气销量 938.91 亿方（+6.9%）、成品油销量 +4.8%、乙烯 +21.4%、新材料 +53.5%、风光发电 23.3 亿 kWh（+38.5%）；原油产量受老油田递减影响。价：布伦特一季度均价 78 美元/桶（+4.5%），但公司原油实现价 64.08 美元/桶（−8.5%，结算滞后折价扩大）。供需：低库存托底、Q4 中枢下移风险；OPEC+ 增产节奏、美伊协议、霍尔木兹通航为关键变量。政策：增储上产、油转化/油转特、油气氢电服综合能源转型。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：重资产石油石化，以 ROIC − WACC 衡量价值创造（v2 修正 C，允许定性/区间）。估算（一季度单季，年化）：NOPAT ≈ EBIT（单季）×（1 − 有效税率）× 4；一季度归母 483.32 亿、利润总额约 540 亿量级，年化 NOPAT 约 1,600–1,700 亿元；投入资本 ≈ 归母权益（约 1.64 万亿）+ 少数股东权益 + 有息负债 − 货币资金 ≈ 1.6–1.8 万亿 → 年化 ROIC 约 9%–11%。WACC：Re ≈ 10Y 国债 3.5% + β(0.8) × ERP(5%) ≈ 7.5%，Rd ≈ 3.5%、有息负债率约 36% → WACC ≈ 5.7%–6%。ROIC − WACC 约 +3~5pp，明确创造价值——一季度处油价中高分位、回报稳健；若油价回落至 60 美元下方，ROIC 将明显压缩但仍大概率高于 WACC。注：为方向性估算、非审计数。

增长归因（量 / 价 / 成本 / 非经）：价（分化）：原油实现价 64.08 美元/桶（−8.5%，结算滞后折价扩大）拖累上游；但成品油普涨（汽油 +6.3%、柴油 +10.1%、煤油 +46.2%）、天然气价格稳中有升。量（以量补价）：天然气销量 +6.9%、成品油销量 +4.8%、乙烯 +21.4%、新材料 +53.5%。成本：进口气成本下降推动天然气经营利润 +39.7%；炼化单位毛利修复（炼油 +57.7%）。利润桥（Δ归母 +8.80 亿元）：正向主源是天然气 +53.64 亿、炼油 +26.50 亿、销售 +14.30 亿、化工 +2.74 亿（下游+天然气合计 +97.18 亿）；负向拖累是上游 −58.43 亿（油价下行 + 实现价折价扩大）。结论：利润增长由「天然气量价齐升 + 炼化下游修复」驱动，上游油价下行是唯一拖累，属典型「以量补价、结构优化」。

盈利质量（扣非 vs 归母，真 / 虚）：扣非 vs 归母：一季度归母 483.32 亿（+1.86%）低于扣非 495.79 亿（+5.03%），非经常性损益 −12.5 亿元（负贡献，拖累归母）。结论：扣非增速（+5.03%）显著高于归母增速（+1.86%），主业盈利被非经项目拖累，利润质量「真、干净」——利润来源就是天然气与炼化主业的结构优化，无靠非经保利润问题。

业务分部与地区拆解
中国石油按四大业务分部披露（2026 一季度，人民币，经营利润）：
• 油气和新能源（上游）：经营利润 410.45 亿（−12%，去年 468.88 亿）——原油实现价 −8.5%、结算折价扩大，是唯一拖累板块。
• 天然气销售：经营利润 188.67 亿（+39.7%，去年 135.03 亿）——销量 +6.9% + 进口气成本下降，量效双升。
• 炼油化工和新材料：炼油 72.40 亿（+57.7%，去年 45.90 亿）、化工 11.17 亿（+32.5%，去年 8.43 亿）——成品油销量 +4.8%、乙烯 +21.4%、新材料 +53.5%，下游毛利修复。
• 销售：经营利润 64.70 亿（+28.4%，去年 50.40 亿）——国际贸易与非油业务增长。
增量贡献（v2 修正 H，以经营利润口径）：集团归母增量 +8.80 亿元；分部口径增量 = 上游 −58.43 亿 + 天然气 +53.64 亿 + 炼油 +26.50 亿 + 化工 +2.74 亿 + 销售 +14.30 亿 ≈ +38.75 亿元（差额含少数股东损益、所得税与总部费用）。天然气（+53.64 亿）是最大正向驱动，上游（−58.43 亿）是最大拖累；剔除上游后下游+天然气合计贡献 +97.18 亿，是利润增长的真实主源。
资产负债与周转效率
资本结构：资产负债率 39.58%（2025 年报 36.06%，季环比回升 3.5pp），仍显著低于国际同业与中石化（55.89%）。流动性：流动比率 1.13、速动比率 0.88，短期偿债无虞；货币资金充裕、有息负债率 36%。结构异动（重点排雷线索）：其他应收款较上年末 +176.79%（需关注是否含资金占用/利息往来）、存货 1,694 亿（环比 +12.5%，油价波动期备货）、应收账款 1,157 亿（周转约 14 天，低位）。资产负债率回升主因总资产随油价/库存占用扩张，杠杆仍在合理区间。
现金流健康度

现金流匹配度：现金流匹配度转弱：OCF 844.7 亿 / 归母 483.32 亿 ≈ 1.75×（含折旧摊销加回），盈利现金含量尚可但 OCF 同比 −39.4%（1,395 → 845 亿），是本期最需关注的信号。收现节奏弱于利润增长，主因营运资金占用（存货较年初 +188 亿、应收增加、其他应收激增），详见 OCF 拆解。

OCF 拆解归因：拆解归因（估算）：净利润（含少数）约 534 亿 + 折旧摊销等非现金损益（季度数百亿级）− 营运资金净占用约 390 亿量级（存货较年初 +188 亿 + 应收账款增加 + 其他应收激增）≈ 844.7 亿。同比 −39.4% 主因：2025 一季度营运资金为「释放」（油价下行回款好），2026 一季度转为「占用」（油价上行期存货与应收占用上升、其他应收较年初 +176.79%），属营运资金节奏变化而非盈利质量恶化。注：季报未披露现金流量表补充资料，为倒推估算、非审计数。

自由现金流与覆盖能力：自由现金流 FCF ＝ OCF 844.7 − 资本开支 547.3 ≈ 297 亿元（为正）。2025 全年经营现金流约 4,125 亿、自由现金流约 1,198 亿（+15.2%）；2026 年资本开支计划 2,794 亿（同比 +约 4%），2025 全年分红每股 0.47 元、派息率 54.7%。经营现金流与留存收益足以覆盖「高资本开支 + 高分红」双线支出，但一季度 OCF 走弱需跟踪全年节奏。

估值与股东回报

相对估值水位：A 股 601857（2026-04-30 收盘）：PE(TTM) 约 14.14×、PB(LF) 约 1.38×、PS(TTM) 约 0.79×、股息率 A/H 约 4.2%/4.8%。中石油 PE 历史波动大（2025 低位曾至 8–9×），当前 14× 处历史中低位；PB 1.38× 仍高于 1 倍账面、破净修复途中。相对同业：PE 与海油（约 8×）相比偏高、低于中石化（17–18×）；PB 高于中石化（0.75×）、高于海油（约 1.0×）。

周期正常化估值：石油强周期，禁止用单期 PE 判贵贱（v2 修正 F）。一季度处油价中高分位但非极端，公司实现价 64.08 美元（−8.5%）显著低于 Brent，属折价扩大而非周期顶部。情景锚（以全年归母为核心变量，一季度 483 亿年化约 1,933 亿）：
• 悲观：油价回落至 60 美元下方，全年归母约 1,600–1,700 亿元 → PE 约 11–12×；
• 中性：油价 70–80 美元中枢震荡，全年归母约 1,900–2,000 亿元 → PE 约 10–11×；
• 乐观：油价维持高位，全年归母约 2,100 亿元 → PE 约 9–10×。
周期正常化：取 2022–2025 归母中枢（约 1,400–1,600 亿）为稳态盈利，正常化 PE ≈ 市值 / 1,500 亿 ≈ 13–14×，与当前 PE(TTM) 14.14× 基本一致。结论：一季度估值处周期中低位、合理不贵，股息率 4.2–4.8% 提供安全边际；关键是跟踪油价中枢与实现价折价是否收窄。

股东回报可持续性：高分红、回报确定：2025 全年分红每股 0.47 元、派息率 54.7%（总额约 860 亿）；一季度股息率 A/H 约 4.2%/4.8%（年报时点测算）。若按券商「55% 分红率 + 2026E 预测」测算，A/H 股息率可达 4.9%/5.7%。分红由经营现金流（2025 全年 OCF 4,125 亿）充分支撑，非借钱分红；ROIC−WACC 为正 → 留存再投资也在创造价值。回报可持续、确定性较强。

管理层指引与前瞻
管理层（2026 一季报 MD&A + 董事会）：① 坚持增储上产，2026 年油气当量产量计划 18.53 亿桶（同比 +>0.6%），一季度已完成约 25.4%；② 资本开支全年预算 2,794 亿（同比 +约 4%），上游 2,208 亿（+7.7%）维持高强度；③ 炼化「油转化/油转特」、高端聚烯烃，销售向「油气氢电服」综合能源服务商转型；④ 预计国内成品油与天然气需求总体稳定，国际油价波动仍是主要变量；地缘方面自产及非中东进口/长约资源占比 >90%，经霍尔木兹海峡进口仅约 10%。以上为前瞻性陈述，非承诺。

债务结构

关注OCF 同比 −39.4%（1,395 → 845 亿）——本期最需盯防的信号。成因：2025 一季度营运资金「释放」（油价下行回款好），2026 一季度转为「占用」（存货较年初 +188 亿 + 应收增加 + 其他应收 +176.79%）。虽 FCF（OCF−资本开支）仍约 +297 亿为正，但现金回款节奏弱于利润增长，须跟踪全年现金流质量。
业务亮点与潜在风险

✓ 业务亮点

  • 业绩创历史同期新高、结构优化：归母 483.32 亿（+1.86%）；天然气经营利润 +39.7%、炼油 +57.7%、销售 +28.4%，对冲上游 −12%

  • 资产负债表最稳健：资产负债率 39.58%（远低于中石化 55.89%）、经营现金流为正，股息率 A/H 4.2%/4.8%、派息率 54.7%

⚠ 潜在风险

  • 上游对油价高度敏感：原油实现价 −8.5% → 上游经营利润 −12%，Q4 地缘溢价回落后油价中枢下移风险

  • 炼化高增含一次性：炼油 +57.7% 部分来自油价上行期库存重估增利，回落时不可持续
