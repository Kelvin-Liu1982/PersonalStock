中性偏谨慎

2026 中报营收 1,119.22 亿元（+2.59%）、归母净利润 134.19 亿元（−23.48%）、扣非 133.87 亿元（−23.35%）、基本 EPS 0.88 元（−21.43%）、加权 ROE（半年）5.70%（−1.65pp）。业绩呈现典型「营收微增、利润显著回落」的强周期特征：营收增主因集装箱量稳增（码头总吞吐量 8,015.70 万TEU、+7.89%）+ 供应链收入 240.90 亿（+11.61%）+ Q2 运价反弹（CCFI Q2 环比 +19.5%、SCFI 6 月末较年初 +95.65%）；利润降 −23.5% 主因①集装箱航运毛利率 17.19%（−3.29pp）：单箱收入 −2.1%（1,180.68 美元/TEU）、国际油价上行推高燃油成本、船队扩张刚性支出；②财务费用转正 3.57 亿（去年同期净收益 20.98 亿，+24.55 亿）：利息收入 −11.09 亿 + 美元贬值致汇兑净损失 8.10 亿。亮点在财务端：经营现金流 233.30 亿（OCF/归母 174% 极高）、货币资金 1,414.42 亿、资产负债率 41.0%（净现金约 700 亿）、中期股息每股 0.43 元（占 H1 归母 49%）。估值低估（A 股收 16.88 元、PE(TTM) 10.3x、PB 1.13x、股息率 TTM ~6%、机构 90.9% 买入），具高股息+破净修复防御价值，但强周期运价波动是核心风险。

✓ 核心利好
  • 营收微增、利润显著回落（强周期特征）：H1 营收 1,119.22 亿（+2.59%）、归母 134.19 亿（−23.48%）、扣非 133.87 亿（−23.35%）、EPS 0.88 元（−21.43%）、加权 ROE（半年）5.70%（−1.65pp）。利润降主因单箱收入 −2.1% + 燃油成本升 + 财务费转正（+24.55 亿：利息降 + 汇兑净损 8.10 亿）。
  • 分部与量价：集装箱航运收入 1,072.98 亿（+2.38%）、毛利率 17.19%（−3.29pp）；码头收入 63.27 亿（+8.30%）、总吞吐量 8,015.70 万TEU（+7.89%）；供应链收入 240.90 亿（+11.61%）为增量亮点；Q2 运价反弹（CCFI Q2 +19.5%、SCFI 6 月末较年初 +95.65%）部分对冲 H1 均价微降。
  • 财务极稳健、现金含量极高：资产负债率 41.0%、货币资金 1,414.42 亿、净现金约 700 亿；经营现金流 233.30 亿（OCF/归母 174%）、中期股息每股 0.43 元（占 H1 归母 49%）；扣非≈归母、非经常性仅 −0.32 亿，盈利质量极干净。
  • 低估破净边缘高股息：A 股收 16.88 元、PE(TTM) 10.3x、PB 1.13x（近破净）、股息率 TTM ~6%、机构 90.9% 买入、平均目标价 18.17 元（+7.6%），具高股息+破净修复防御价值。
⚠ 核心风险
  • 运价周期波动（核心红旗）：集运强周期，业绩与 CCFI/SCFI 高度绑定；2027 新船交付高峰→运力过剩隐忧，当前运价反弹属 3–6 个月窗口期而非永续，回落将直接压制利润。
  • 地缘 / 贸易政策（核心红旗）：红海绕行（吸收 6–8% 运力）、美伊局势、美国新 301 关税前抢运、贸易政策不确定性，多重扰动双向影响运价与燃油/碳税成本。
  • 汇率与成本：美元贬值致汇兑净损失 8.10 亿、财务费转正；国际油价上行推高燃油成本（存货 +34.08%）、船队扩张刚性支出 + 环保改造成本扩大，持续挤压毛利率（−3.29pp）。
  • 营收质量：应收账款 111.18 亿（较年初 +37.96%）、存货 84.57 亿（+34.08%）快于营收，账期略放宽/油价驱动，需下季跟踪周转。

行业坐标与供需

行业所处阶段与传导方向：集装箱航运行业处于「周期高位震荡、供给过剩隐忧」阶段：2026H1 全球集装箱贸易量增速 5.3%（温和复苏），但运力供给全年增长约 4.2%、2027 年迎新船交付高峰，供需走向「平衡偏宽松」。运价受多重扰动共振：红海绕行（吸收 6–8% 有效运力）、美伊局势、7 月美国新 301 关税前抢运、燃油附加费上调，推动 SCFI 上半年均值 1,956.53（+15%）、CCFI 上半年均值 1,249（同比微降 0.26%，但 Q2 环比 +19.5%）。中远海控以「集装箱航运 + 港口 + 数字化供应链」一体化应对，船队运力约 366 万TEU（订单合计破 530 万TEU）、码头吞吐量全球领先，规模与网络优势显著。

量价 / 供需 / 价格位置 / 政策：① 运价：CCFI 上半年均值 1,249（同比 −0.26%，Q2 环比 +19.5%）；SCFI 上半年均值 1,956.53（+15%），6 月末较年初 +95.65%；单箱收入 1,180.68 美元/TEU（−2.1%）。② 量：码头总吞吐量 8,015.70 万TEU（+7.89%，控股 +2.50%/参股 +9.43%）；集装箱航运双品牌（中远海运集运 + 东方海外）共运营 42 组东西干线、运力稳居第一梯队。③ 船队：现有运力约 366 万TEU（自有+租赁），手持自有新造船订单 82 艘约 118 万TEU、租赁订单约 50 万TEU，合计突破 530 万TEU；2026H1 运力增长 +2.1%。④ 成本：国际油价大幅上行（存货 +34.08% 主因燃油采购成本升）、船队扩张刚性支出、环保规则（碳税/技术改造）成本扩大。⑤ 财务费：利息收入 −11.09 亿（存款余额降+利率降）、汇兑净损失 8.10 亿（美元贬值）。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：重资产航运，以ROIC−WACC 衡量价值创造（v2 修正 C，允许定性）。估算（半年年化）：NOPAT ≈ 归母 134.19 亿×2 ≈ 268 亿（少数股东与财务费已含）；投入资本 IC = 归母净资产 2,337.62 亿 + 净负债（有息负债 ~712 亿 − 货币资金 1,414 亿 = 净现金 ~702 亿，故 IC ≈ 净资产 − 净现金 ≈ 1,636 亿）；ROIC（年化）≈ 268 / 1,636 ≈ 16.4%（半年口径 ROE 5.70% 年化约 11.4%，受净现金放大）。WACC ≈ 7.5%（航运 β 中性、债权占比低、股权为主）。ROIC−WACC ≈ +8–9pp，价值创造为正——但强周期下 ROIC 随运价大幅波动（2022 峰值 ROE >50%、2023 谷底 ~10%），当前处周期中低位仍为正利差。投资逻辑偏「高股息 + 破净修复 + 周期拐点」而非稳态 ROIC 扩张（v2 修正 C 允许定性）。

增长归因（量 / 价 / 成本 / 非经）：量：营业收入 1,119.22 亿（+2.59%）：集装箱航运 1,072.98 亿（+2.38%）、码头 63.27 亿（+8.30%）、供应链收入（除海运）240.90 亿（+11.61%）；码头总吞吐量 8,015.70 万TEU（+7.89%）。价：整体毛利率约 17.8%（同比 −3.11pp，集装箱航运 17.19%−3.29pp、码头 27.63%−0.42pp），净利率 12.00%（−3.9pp）——单箱收入 −2.1%（1,180.68 美元/TEU）、国际油价上行推高燃油成本、船队扩张刚性支出。成本/费用：营业成本增（集装箱航运成本 +6.62% 快于收入 +2.38%）；管理费用 39.06 亿（+7.4%）、研发费用 5.28 亿；财务费用转正 3.57 亿（去年同期净收益 20.98 亿，+24.55 亿：利息收入 −11.09 亿 + 汇兑净损失 8.10 亿）。投资/其他：投资收益 30.02 亿（对联营/合营 28.18 亿，港口与物流联营）；资产减值 −0.23 亿、信用减值 −0.81 亿（极小）。结论：归母 −23.48% = 毛利率 −3.11pp（燃油+成本升）− 财务费用 +24.55 亿（利息收入降+汇兑损）− 所得税随利润降 + 投资收益持平 + 供应链/码头增量缓冲；经营基本盘受运价/成本/汇率三重挤压。

盈利质量（扣非 vs 归母，真 / 虚）：质量「真」、极干净。扣非 133.87 亿 vs 归母 134.19 亿，非经常性仅 −0.32 亿（几乎无）；非经常性含其他收益 5.44 亿（政府补助，同比 −40%）、公允价值 −0.11 亿、资产减值 −0.23 亿，无依赖资产处置/政府补助粉饰，盈利含金量高。现金验证：经营现金流净额 233.30 亿（−9.49%），OCF/归母 ≈ 174%（远超 100%），盈利有真金白银支撑，无借钱分红；货币资金 1,414.42 亿、净现金约 700 亿，现金含量极高。

业务分部与地区拆解
中远海控按业务分部披露（2026 中报，人民币）：
• 集装箱航运业务 收入 1,072.98 亿（+2.38%）、毛利 184.45 亿、毛利率 17.19%（−3.29pp）、EBIT 21.99 亿美元（−26.6%）——主业，受单箱收入 −2.1% + 燃油成本升 + 船队刚性支出拖累；双品牌（中远海运集运 + 东方海外货柜）共运营 42 组东西干线、运力稳居第一梯队。
• 码头业务（中远海运港口） 收入 63.27 亿（+8.30%）、毛利率 27.63%（−0.42pp）、总吞吐量 8,015.70 万TEU（+7.89%）——全球 40 港 394 泊位，控股为主、重点参股差异化经营。
• 供应链（除海运） 收入 240.90 亿（+11.61%）——一体化延伸增量亮点。
增量利润归因：集装箱航运 EBIT −26.6% 被码头 + 供应链 + 对联营合营投资收益（28.18 亿）部分缓冲；分部间抵销后整体利润降 −23.5%。
资产负债与周转效率
资本结构（极稳健、净现金）：资产负债率 41.0%（负债合计 1,983.19 亿 / 总资产 4,836.30 亿，较年初 41.4% 略降）；有息负债 ≈ 短期借款 7.77 + 长期借款 215.12 + 租赁负债 305.99 + 一年内到期 183.01 ≈ 711.89 亿；货币资金 1,414.42 亿 → 净现金约 702 亿。
流动性（极强）：流动资产 ≈ 1,705 亿（货币 1,414 + 应收 111 + 其他）、流动负债合计 1,179.68 亿，流动比率 ≈ 1.45；现金短债比（货币 / 短期有息 ~191 亿）≈ 7.4x，短期偿债无虞。
资产质量与周转：应收账款 111.18 亿（较年初 +37.96%，账期略放宽/6 月营收增）、存货 84.57 亿（+34.08%，主因国际油价上行燃油采购成本升、非滞销）；商誉 61.44 亿（占净资产 2.6%，无泡沫）；固定资产 1,481.65 亿 + 使用权资产 402.96 亿（租赁船队并表）；长期股权投资 774.69 亿（港口/物流联营，权益法）。
现金流健康度

现金流匹配度：回落但现金含量极高。经营现金流净额 233.30 亿（−9.49%，去年同期 257.77 亿），OCF/归母 ≈ 174%，盈利现金含量远超 100%，无背离。销售商品收到现金 1,107.43 亿（+2.8%，与营收匹配）；购买商品支付 792.42 亿（+10.6%，主因燃油成本升 + 绕行附加支出）；支付税费 33.97 亿（−47%，利润降致所得税降）；投资活动净流出 119.12 亿（船舶建造/码头/理财）、筹资净流出 182.32 亿（分红 + 回购注销 + 偿债）。经营净流入充分覆盖，净现金累积。

OCF 拆解归因（v2 修正 E）：OCF 拆解（亿元）：经营净流入 233.30（−9.49%）。关键项：① 收款端：销售商品收到 1,107.43（+2.8%）匹配营收；应收账款 111.18 亿（较年初 +37.96%，6 月营收增 + 账期略放宽）。② 支出端：购买商品支付 792.42（+10.6%，燃油成本升 + 航线绕行附加成本）；支付税费 33.97（−47%，利润降）；支付职工与其他约 28.4 亿。③ 投资：投资活动净流出 119.12（新船建造/码头投资 + 理财）；④ 筹资：净流出 182.32（中期分红 65.65 + 回购注销 + 偿债）。归因：OCF 回落主因购买商品支出增（燃油/成本）与应收占用，非盈利质量恶化。

自由现金流与覆盖能力：由充沛经营现金流与净现金覆盖。H1 投资活动流出 119.12 亿（船舶建造/码头为主），FCF ≈ OCF 233.30 − 经营相关 CapEx（约 80–100 亿）≈ 半年 +130–150 亿（为正），因净现金充裕。中期分红 65.65 亿仅占 OCF 28%、由经营现金流充分覆盖，非借钱分红；全年 CapEx（新船建造为主）由经营 + 净现金支撑，财务极稳健。

估值与股东回报

相对估值水位：低估值、破净边缘、高股息。以 2026-08-28 收盘价 A 股 16.88 元计：总市值约 2,577 亿，PE(TTM) 10.29x、PB(LF) 1.13x（近破净）、股息率 TTM ~5.97%；H 股 01919 收 17.20 港元（≈15.8 人民币，AH 小幅溢价）。机构 11 家评级 90.9% 建议买入（63.64% 买入 + 27.27% 强推）、平均目标价 18.17 元（+7.6%），部分来源区间 17.70–18.80 元。相对国际同业（马士基/达飞/赫伯罗特 PE 8–12x 但处周期高位利润），中远海控估值处历史中低位。

周期正常化估值（v2 修正 F）：集运强周期，利润正常化以中性运价还原（v2 修正 F）。当前 2026H1 归母 134.19 亿处周期中低位（2022 峰值 648 亿、2023–24 谷底 ~165–169 亿、2025 恢复 175 亿、2026H1 年化 ~268 亿）。若取近 3 年（2023–2025）平均归母 ~170 亿为「周期中性」参考，正常化 PE ≈ 2,577 亿 / 170 亿 ≈ 15x；若按 2025 全年 309 亿则 ~8.3x。结论：当前 PE(TTM) 10.3x + PB 1.13x（近破净）+ 股息率 ~6%，已反映周期担忧；下行有净现金 ~700 亿 + 高股息托底，上行取决于运价中枢与 2027 供给释放节奏。

股东回报可持续性：高分红 + 回购注销、回馈股东。2026 中期股息每股 0.43 元（含税），合计约 65.65 亿，占 H1 归母 49%（延续 50% 左右高派息率）；2025 全年分红（中期 0.56 + 末期）延续高回报。报告期内延续股份回购注销（2025H1 累计回购注销 A 股 1.02 亿股 + H 股 2.37 亿股，增厚 EPS、维护股东权益），2026 按规划接续。中期分红由 OCF 174% 充分覆盖，分红可持续、非借钱分红；2025–2027 股东分红回报规划维持高派息。
