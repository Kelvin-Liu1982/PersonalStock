偏积极

✓ 核心利好
  • 业绩超预期：营收 +5.3% 至 1.53 万亿、归母净利 +22.0% 至 1,039 亿，油价上行 + 炼化修复双轮驱动。
  • 现金流极强：OCF 2,513 亿、OCF / 净利 ≈ 2.4×，自由现金流 1,763 亿覆盖中期派息 3.7 倍。
  • 估值合理偏低：PE(TTM) ≈ 13×、PB ≈ 1.3×，处历史中低位；机构一致预期 26E EPS ≈ 0.97 元。
⚠ 核心风险
  • 油价周期回落：实现油价 76.53 美元 / 桶（同比 +15.6%），若跌破 60 美元上游利润将明显压缩，周期正常化估值须警惕顶部误读。
  • 资产负债率温和抬升：38.9%（+2.8pp），总负债 +13.9%，须关注杠杆走势。
  • 海外产量下滑：海外原油产量 −14.2%，地缘与项目波动影响创效。

行业坐标与供需

行业所处阶段与传导方向：行业处于「油价温和上行、结构分化」阶段——上游油气价格回暖（实现油价 +15.6%、煤油 +46.2%）直接利好勘探开发；下游炼化化工价差仍偏薄但环比改善（化工经营利润由负转正并 +31.4%）；天然气产销稳增、进口依存度边际回落。传导方向：价格↑→中石油上游利润↑，下游成本↑但售价部分传导对冲。

量价 / 供需 / 价格位置 / 政策：量价：2026H1 原油实现价 76.53 美元 / 桶（同比 +15.6%），成品油普涨（汽油 +6.3%、柴油 +10.1%、煤油 +46.2%）；天然气销量 +3.9%、价格 +1.7%。供应：OPEC+ 维持减产、地缘扰动支撑油价；国内原油产量 462.9 百万桶（−2.8%，老油田自然递减），天然气 2,746 Bcf（+2.3%）。需求：成品油表观消费分化、化工弱复苏。政策：能源安全「增储上产」、新能源替代加速。位置：油价处近年中低位回升区间，非周期顶部。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：中石油为上游重资产企业，经营利润 1,393.83 亿、折旧折耗摊销 1,255.28 亿，资本回报远高于资本成本。因中报未披露分部投入资本，无法精确计算 ROIC−WACC，但经营性现金流 / 净利润 ≈ 2.4×、加权 ROE 6.3%（+0.9pp）且自由现金流充沛，判断 ROIC 显著 > WACC（创造价值）；属正向，非金融企业特征下创造价值明确。

增长归因（量 / 价 / 成本 / 非经）：营收 +5.3% 主因油气 / 化工产品价格上涨（实现油价 +15.6%、煤油 +46.2%、柴油 +10.1%）及销量变化。归母净利 +22.0% 快于营收，源于：① 油价上行带动上游弹性释放——油气和新能源分部经营利润 +15.3%（1,004 亿）；② 炼化化工经营利润修复 +31.4%（化工扭亏改善）；③ 天然气销售利润 +29.3%；④ 销售分部利润 +50.2%（国际贸易 + 非油业务）。成本端：折旧摊销 +2.9%、员工费用 +3.7%、石油特别收益金随油价 +90.87 亿，整体费率受控，呈正运营杠杆。

盈利质量（扣非 vs 归母，真 / 虚）：扣非归母净利润 1,055.33 亿 > 归母净利 1,039.36 亿（扣非高 1.5%），主业质量「真」、非经常性损益为负向扰动（公允价值 / 处置等约 −16 亿），归母净利含金量高；盈利现金含量 OCF / 归母 ≈ 2.4×，现金含量极高。

资产负债与周转效率
资产负债率 38.9%（较上年末 36.1% +2.8pp），仍处低位；流动比率 1.15（流动资产 7,318 亿 / 流动负债 6,364 亿）；总负债 +13.9%（流动负债 +17.8%，含存货、应收及定期存款增加），归母权益 +1.3% 至 1.64 万亿。结论：财务结构稳健，杠杆温和抬升但安全边际充足。红旗关注：资产负债率较年初上升 2.8pp，后续跟踪总负债增速与流动比率。周转：应收账款及存货随营收上升（流动资产 +22.1%），未见异常恶化。
现金流健康度

现金流匹配度：OCF 2,512.81 亿 vs 归母净利 1,039.36 亿，OCF / 净利 ≈ 2.4×，盈利现金含量极高（>1），长期无「OCF 低于净利润」红旗；与重资产上游属性一致——折旧摊销规模≈净利润，是 OCF 远超净利润的主因。

OCF 拆解归因：经营现金流净额 2,512.81 亿 ≈ 集团净利润 1,151.13 亿 + 折旧折耗摊销 1,255.28 亿 + 营运资金净变动及其他非现金损益（净额约 +106 亿，含递延所得税、资产减值等）− 资本性应付等。背离主因：重资产上游折旧摊销规模≈净利润，是 OCF 远超净利润的主因；不存在「经营现金流长期低于净利润」的红旗。

自由现金流与覆盖能力：自由现金流 FCF = OCF 2,512.81 亿 − 资本开支 750.15 亿 = 1,762.66 亿。覆盖能力：FCF 为中期派息（475.85 亿）的 3.7 倍，覆盖资本开支 + 分红 + 到期债务无忧；资本开支由经营现金流支撑，未依赖筹资（全年资本预算 2,794 亿，节奏可控）。

估值与股东回报

相对估值水位：截至 2026-08-28 收盘，股价 ≈ 11.20 元，总市值 ≈ 2.0 万亿；PE(TTM) ≈ 13×、PB ≈ 1.3×。PE 处历史中低位（近 5 年中枢约 10–15×），PB 1.3× 接近净资产。相对同业：PE 与海油（约 13×）接近、低于中石化（约 19×）；PB 高于中石化（0.7×）、低于海油（1.9×）。

周期正常化估值：中石油盈利强周期（油价驱动），单期 PE 13× 看似不贵但须结合油价位置：当前实现油价 76.53 美元（同比 +15.6%，处近年中低位回升区间）。正常化盈利（按布油 70–75 美元稳态）预计归母净利 1,500–1,800 亿区间，对应正常化 PE 约 11–13×。结论：周期中性、估值合理偏低；须警惕周期顶部勿单看低 PE。

股东回报可持续性：中期股息每股 0.26 元，总派息 475.85 亿，H1 派息率约 45.8%；股息率 TTM 约 4.8%（年化，估算）。分红由经营现金流（FCF 1,762.66 亿）充分支撑，可持续性高；公司亦持续实施股份回购。

管理层指引与前瞻
管理层：① 坚持增储上产，油气当量产量稳中提质、天然气占比提升；② 资本开支全年预算 2,794 亿（严谨 / 效益投资），聚焦油气和新能源（2,208 亿）；③ 推进新能源（风光发电、地热）与炼化转型升级；④ 油价判断维持区间震荡，优化采购与套保。敏感性：布油每 ±10 美元，对上游经营利润影响约 ±数百亿（按 9.2 亿桶当量产量与实现价弹性估算）。
同业可比与相对表现
相对同业：① 增速——中石油归母 +22.0% 高于中石化（炼化占比高、化工承压）、与海油上游高增相当；② 估值——PE 13× 介于海油（10–13×）与中石化（19×）之间，PB 1.3× 居中；③ 业务结构——中石油「油气 + 炼化 + 销售 + 天然气」全链条，抗周期性强于纯炼化（中石化）、但上游弹性弱于纯上游（海油）。份额：国内原油产量占国内约 50%+，天然气主力供应商。
