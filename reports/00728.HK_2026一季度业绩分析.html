预期来源与统计时点：无权威单季一致预期（港股 Q1 罕有卖方单季预测，口径亦分 IFRS/经调整）。按 v2 修正 B 改用 TTM 进度校验：以 2025 全年归母 331.85 亿 / 营收 5,295.59 亿（HKFRS）为基准，2026Q1 占比 22.1% / 24.9%，与历史 Q1 占比中枢（约 22–24%）一致，未见显著 miss。行业层面：工信部 2026Q1 电信业务收入 −1.8%、三大运营商归母合计 −8.5%（通信产业报/中新经纬，2026-04-23/24），公司表现与行业同步。

行业坐标与供需

行业所处阶段与传导方向：行业处于成熟期 / 新旧动能转换期：传统语音、短信持续萎缩，移动用户规模首次下降，5G 渗透近 70% 见顶，流量「增量减收」。传导方向：对传统服务收入（价）压制、对传统利润（成本刚性）负面，但对算力 / 云 / AI（量）正面——公司正处于「此消未彼长」的转型阵痛，业绩短期承压、长期向新。

量价 / 供需 / 价格位置 / 政策：① 工信部 2026Q1：电信业务收入 4,394 亿（−1.8%），电信业务总量 +8.3%（不变价，反映降价压力）；移动电话去话时长 −5.6%，移动短信收入 −12.2%，移动互联网流量 +19.1%（DOU 23.4GB，+13.8%）。② 增值税税目调整：自 2026 年起境内流量/宽带等服务税目由「增值电信服务」调为「基础电信服务」，税率 6%→9%，摩根士丹利测算拉低运营商净利约 10pp，属一次性账面冲击。③ 资本开支由 5G 转向 AI 算力（联通 2026 Capex ~500 亿、算力占比 >35%/175 亿+；移动算力网络 Capex +62.4%）。④ 新动能高增：天翼云 +6.8%、智能收入 +39.4%、联通算力 +8.3%/智算 +11.7%。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：数据不足硬算，定性提示：Q1 经营收益率 6.2%、负债率 ~45.9%、10Y 国债 ~1.8%、β~0.5 → 估算 WACC≈5–6%；公司投入资本回报（ROIC，重资产 PPE 约 4,018 亿）约 4–5%，与 WACC 基本持平或略低——此为重资产电信业常态。结论：ROIC−WACC ≈ 0 附近，不构成显著价值毁灭，但亦无超额回报；价值创造主靠稳定经营现金流与股息，而非 ROIC 溢价（v2 修正 C 降级处理）。

增长归因（量 / 价 / 成本 / 非经）：量：5G 网络用户净增 1,232 万（渗透 71.3%）、手机上网流量 +17.7%、DOU +12.6%，基本盘用户仍增。价：服务收入 −1.6%（增值税税目 + 流量增量减收，价格下行）。成本：销售/一般/管理费用 +2.1%、人工成本 +1.6%、资产减值损失 +38.3%（3,795 百万），费用刚性上升。非经：应占联营收益 +53%（9.91 亿）、投资收益及其他 1.99 亿（去年同期 0.07 亿）正向贡献，但未能对冲。结论：利润下滑主因 = 收入端税目调整 + 价格下行 + 费用/减值刚性。

盈利质量（扣非 vs 归母，真 / 虚）：实。经营收益 81.51 亿占税前利润 93.24 亿的 87.4%，主业贡献扎实；Q1 condensed 未单列扣非，但非经占比低，盈利质量「真」。需关注：减值损失 +38.3% 与应收账款激增（见 §4/§9）的关联——若回款不及预期，减值或持续。

业务分部与地区拆解
Q1 condensed 未披露分部利润，按 v2 §3 降级以「业务线运营指标」替代：
• 基础业务（移动/宽带/固网）：移动用户 4.41 亿（季净增 190 万）、5G 网络用户 3.14 亿（渗透 71.3%，净增 1,232 万）、有线宽带 2.02 亿（净增 44 万）；传统语音/短信继续萎缩。
• 产业数字化 / 天翼云：天翼云收入 +6.8%、智能收入 +39.4%（2025 天翼云 1,207 亿、IaaS 国内第二）。
• 国际业务：持续拓展（一带一路、海缆、天翼视联国际平台）。
• 增量利润贡献占比：Q1 未披露分部利润，无法计算 Δ 分部贡献（v2 修正 H）；定性判断：传统基础业务承压、产业数字化增长但体量尚不足以完全对冲（「此消未彼长」）。
资产负债与周转效率
资本结构：负债率 45.9%（负债 4,032 亿 / 资产 8,791 亿），稳定；有息负债约 455 亿（短贷 22.5 + 1 年内到期长贷 15.0 + 长贷 56.0 + 租赁 362 亿），有息负债/权益 ≈ 9.7%，极低。
流动性：流动比率 0.68、净流动负债 (1,058 亿) 为结构性（经营应付为主，非债务危机）；现金短债比 =（现金 456.6 + 短期存款 396.2）/ 短期有息债（225+150+154=529 亿）≈ 1.6x，若将短存计入则更充裕，短期偿债无虞。
周转效率：应收账款 697.08 亿（+31.2% vs 上年末 531.46 亿），应收周转天数 ≈ 170 天；应收增速 >> 营收增速（−2.6%）→ 营收质量警示。存货 37.47 亿（仅占营收 0.4%）稳健；合同负债 627.90 亿（−6.4%）。
现金流健康度

现金流匹配度：表面极强、含节奏性。经营现金流净额 230.57 亿（+123.3%），OCF/净利 = 23,057 / 7,273 ≈ 3.17x（极高）。但高 OCF 主因经营性负债（应付账款、预提费用）季节性交增加，需看全年是否可持续，非纯经营盈利能力跃升。

OCF 拆解归因（v2 修正 E）：OCF 拆解（百万元，v2 修正 E）：税前利润 9,324 ＋ 折旧摊销 25,724 ＋ 金融资产及合同资产减值 3,795（↑38%）＋ 其他非现 ≈ 38,034；营运资金：应收账款增加 (19,953)（仍处季节性高位）、应付账款增加 +2,852（去年同期 −8,790）、预提费用及其他应付款 +9,818（去年同期 +6,743）、合同负债 (4,299) → 经营性应付净增推高 OCF 约 +85 亿（去年同期为 −88 亿）。归因：OCF 大增主因 = 应付账款/预提费用等经营性负债增加（节奏性延付）＋ 应收账款回款，部分被应收继续增加抵消；可持续性待全年验证。

自由现金流与覆盖能力：FCF 由负转正。FCF = OCF − CapEx = 230.57 − 146.90 = +83.67 亿（去年同期 103.27 − 137.10 = −3.83 亿）。覆盖能力：经营现金流远超单季 CapEx（146.9 亿）与历史单季分红（2025 全年派息 248.90 亿 ÷ 4 ≈ 62 亿），余量充足。投资活动 −312.24 亿含 treasury placement（投资支付 428.46 亿 / 处置投资 273.58 亿），非核心 Capex。

估值与股东回报

相对估值水位：合理偏低、防御属性突出。PE(TTM)≈12.8x（2026-04-24，历史分位 63%，近中枢略高）、PB 0.91x（近破净）、PS(TTM)≈0.81x、股息率 TTM≈5.9%。相对同业：PE 高于联通（~10x）、接近移动（~13x）；PB 最低（破净），估值安全边际最高。

周期正常化估值（v2 修正 F）：电信非强周期，盈利稳定（2021–2025 归母 CAGR≈6%、连续 5 年双增）。正常化盈利 ≈ 当前 ~330–350 亿（无大幅周期摆动）。正常化 PE ≈ 12–13x，处历史中枢，非显著低估亦非泡沫（v2 修正 F）；PB<1 提供资产安全边际，下行有底。

股东回报可持续性：可持续、且慷慨。2025 全年派息 248.90 亿（占归母 75%），股息率 TTM≈5.9%–6.0%；2026 预期维持高分红（行业「前低后稳」、OCF 充沛）。分红由经营现金流（230 亿/季）充分覆盖，非借钱分红，可持续性强。

管理层指引与前瞻
战略：全面实施「云改数转智惠」，以打造领先 AI 服务商为目标，以 Token（词元）服务为经营主线；完善「息壤」一体化智算平台与「云霆」算电调度能力。
资本配置：行业 2026 资本开支由 5G 转向 AI 算力（联通算力 Capex >35%/175 亿+；移动算力网络 +62.4%）；公司持续加码智算（Q1 未单列）。分红：2025 派息率 75%，预期延续。
敏感性：增值税税目调整（一次性 ~10pp）、算力投入节奏、AI Token 商业化进度。（前瞻性陈述，非承诺）
同业可比与相对表现
三家运营商 2026Q1 横向对比（HKFRS 集团口径）：
• 营收增速：电信 −2.6% ＜ 联通 −0.5% ＜ 移动 +1.0% → 电信垫底。
• 归母增速：电信 −17.1% ≈ 联通 −17.6%（并列最弱）＞ 移动 −4.2%。
• 服务收入增速：电信 −1.6% / 移动 −1.1% / 联通 −0.9%。
• 估值：PE 电信 ~12.8x / 移动 ~13x / 联通 ~10x；PB 电信 0.91x（破净）/ 移动 ~1.1x / 联通 ~0.55x；股息率 电信 ~5.9% / 联通 ~6.8% / 移动 ~4%。
• 新动能：天翼云 +6.8%/智能 +39.4%（电信）、算力 +8.3%/智算 +11.7%（联通），移动未披露具体。
结论：中国电信 Q1 营收与利润增速均垫底（弱于移动、与联通并列最弱），但 PB 破净＋股息率提供防御；行业集体承压源于税目调整＋传统业务见顶，非个股基本面恶化。

审计意见

关联交易 / 其他应收

存货

非经常性损益
实经营收益占税前利润 87.4%，主业贡献扎实；但投资收益及其他（1.99 亿 vs 0.07 亿）、应占联营（+53%）正向贡献部分利润，需看是否一次性。
现金流背离
关注OCF/净利 3.17x 极高（表面安全），但主因经营性负债季节性交增加，含节奏性，全年可持续性待验。
收入确认激进（v2 新增）
关注应收 +31% vs 营收 −2.6%，Q1 condensed 渠道库存/终端动销/账龄不可得 → 需中报核实应收账款账龄结构与回款质量，排除压货/提前确认。
表外 / 担保 / 或有负债（v2 新增）
关注Q1 未披露对外担保余额、未决诉讼及并表范围变动 → 待年报/中报核实，排除明股实债或利润搬移。
合同负债
关注合同负债 627.90 亿（−6.4% vs 上年末 671.13 亿），递延收入下降，未来收入可见度略降。
现金结构
关注现金及等价物 456.63 亿（−25.6% vs 上年末 613.94 亿），而 FVTPL 金融资产 +133%（117→273 亿），现金转为 treasury placement，流动性结构变化但整体可控。
