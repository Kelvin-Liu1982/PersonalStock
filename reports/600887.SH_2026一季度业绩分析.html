偏积极

2026 年一季度伊利股份实现营收 348.25 亿（同比 +5.47%）、归母净利润 53.95 亿（+10.68%）、扣非 53.29 亿（+15.11%），在 2024–2025 连续两年的增长波动后重回稳健扩张，且利润增速约为营收增速的两倍，盈利质量「真」。核心驱动是原奶价格历史低位带来的成本红利（毛利率升至 38.5%、同比 +0.7pp）叠加产品结构升级（奶粉及奶制品、冷饮高增）与费用率优化（销售费率 −0.2pp）。经营现金流净额 37.35 亿（+293.92%）大幅改善，净现比由 0.19x 升至 0.69x。资产质量稳健（资产负债率降至 59.5%、ROE 9.44%）。核心风险在于：应收账款 +19.3% 快于营收、短期借款 +29.4% 至 590 亿、合同负债腰斩、以及原奶价格 2026 下半年或回升将削弱成本红利——当前 A 股 25.49 元、PE(TTM) 20.1x、股息率 ~5.4%–6.7%，估值处历史中低位。

✓ 核心利好
  • 2026Q1 营收 348.25 亿（+5.47%）、归母 53.95 亿（+10.68%）、扣非 53.29 亿（+15.11%），利润增速约为营收两倍，为 2024–2025 波动后重回稳健扩张。
  • 原奶成本红利 + 结构升级 + 费用优化：毛利率升至 38.52%（+0.7pp）、净利率 15.49%（+0.73pp）、销售费率 −0.2pp，盈利质量「真」（非经仅占 1.2%）。
  • 经营现金流净额 37.35 亿（+293.92%），净现比由 0.19x 升至 0.69x；资产负债率降至 59.5%、ROE 9.44%，资产质量稳健。
  • 龙头领先优势稳固：营收规模与净利率远超蒙牛 / 光明 / 飞鹤，婴配粉市占率 18.3% 行业第一；估值处历史中低位（PE 20x）、股息率 ~5.4%–6.7%。
⚠ 核心风险
  • 应收 / 债务信号：应收账款 +19.3% 快于营收、短期借款 +29.4% 至 590 亿（现金短债比 0.33x）、合同负债腰斩，雪球质疑「借短拖款、资金面偏紧」。
  • 经营现金流改善可持续性：OCF +293.92% 部分由应付拖款驱动，能否外推全年存疑。
  • 原奶价格回升风险：当前利润含奶价低位红利，若 2026 下半年奶价企稳回升，毛利率或边际收窄、成本红利减弱。

行业坐标与供需

行业所处阶段与传导方向：乳制品行业处于原奶下行周期尾段 / 龙头复苏早期：本轮原奶价格自 2023 下半年起持续低位（2026Q1 生鲜乳价格同比 −1.9%、GDT 全脂奶粉中标价同比 −14.5%），上游牧场（优然、现代牧业、圣牧）普遍亏损去产能，规模化牧场占比提升致周期底部拉长。对下游乳企（伊利）的传导：成本（价）强正面（奶价低位直接抬升毛利率）、需求（量）中性偏弱（终端大众乳品消费平淡、价格战延续）、结构升级（品类）正面（奶粉 / 冷饮 / 奶酪高毛利品类放量）。2026Q1 春节旺季龙头「开门红」，行业集中度进一步提升（中小品牌散奶成本优势消退后龙头回收份额）。风险点：原奶价格 2026 下半年大概率企稳回升，成本红利或边际减弱。

量价 / 供需 / 价格位置 / 政策：① 行业总量：2025 年乳制品板块整体承压（终端需求弱、价格战），但 2026Q1 龙头开门红——板块营收 / 归母 / 扣非 +4.7% / +10.5% / +11.8%（华泰）。② 伊利自身：2025 全年营收 1,159.31 亿（+0.13%）、归母 115.65 亿（+36.82%，低基数修复）；2026Q1 营收 348.25 亿（+5.47%）、归母 53.95 亿（+10.68%）。③ 产品结构：2025 液体乳 704.22 亿（−6.1%，主动控货去库存、保品牌）；奶粉及奶制品 327.69 亿（+10.4%）、冷饮 98.22 亿（+12.6%）；婴幼儿配方奶粉市占率由 2021 的 7.3% 跃升至 18.3%（行业第一）。④ 竞争：龙头要求「保盈利基础上的收入增长」，促销费用理性化、费用投放品牌化，行业竞争趋缓。⑤ 政策 / 风险：原奶价格或于 2026 下半年回升、消费需求若进一步萎缩将削弱成本红利。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：伊利以ROIC−WACC 衡量价值创造（v2 修正 C）。以 2025 全年近似：NOPAT ≈ 归母 115.65 亿 ＋ 税后净利息（财务净收入为正）≈ 120 亿；投入资本 ≈ 归母净资产 570 亿 ＋ 有息负债 508 亿 − 超额现金（货币资金 275 亿 − 经营最低 ~100 亿）≈ 903 亿；ROIC ≈ 13.3%。WACC 估算 ~5.5%（10Y 国债 ~1.8% ＋ β~0.7 × 风险溢价 + 债务成本），ROIC−WACC ≈ +7~8pp，显著创造价值。轻资产快消属性下资本回报持续高于资本成本，2026Q1 ROE 9.44%（年化 ~38%？需谨慎——Q1 单季 ROE 不可年化，全年 ROE 历史 20%+），价值创造逻辑稳固。

增长归因（量 / 价 / 成本 / 非经）：量：2026Q1 液体乳 +4.4%、奶粉及奶制品 +6.1%、冷饮 +7.1%（华泰 / 开源），全品类温和放量；婴配粉市占率 18.3% 行业第一，奶粉及奶制品成增量主源。价：原奶低位 + 结构升级（高端金典 / 安慕希 + 折扣促销收敛）推动毛利率 38.52%（+0.7pp）；但液体乳吨价仍承压、行业价格战未完全消除。成本：营业成本 214.09 亿（+4.27%，低于营收 +5.47%），奶价红利直接体现；期间费用率 ~19.9%（−0.3pp），销售费率 16.71%（−0.2pp）、管理 3.67%（−0.1pp），正运营杠杆。非经常性：非经常性损益仅 0.66 亿（占净利 1.2%），投资收益 1.36 亿（联营企业转正）贡献少量正向。结论：增长「靠原奶成本红利 + 结构升级 + 费用优化」，经营质量扎实、非经占比极低。

盈利质量（扣非 vs 归母，真 / 虚）：偏「真」。非经常性损益 0.66 亿，占净利润 1.2%；扣非归母 53.29 亿（+15.11%）高于归母 53.95 亿（+10.68%）的增速，核心经营利润增速更快、无水分。毛利率同比扩大 0.7pp、净利率 15.49%（+0.73pp）均由主业贡献。须提示：2024Q1 归母 +63.84% 含一次性投资收益高基数，2026Q1 的 +10.68% 是在正常经营口径下的真实改善，质量含金量高。

业务分部与地区拆解
伊利为全品类乳企，按产品群拆解（2026Q1 增速来自华泰 / 开源，2025 全年基数来自年报）：
• 液体乳：Q1 +4.4%（2025 全年 704.22 亿、−6.1%，主动控货去库存后重回正增）；基本盘，金典 / 安慕希稳住高端、常温基础乳稳大众市场。
• 奶粉及奶制品：Q1 +6.1%（2025 全年 327.69 亿、+10.4%），增量主力；婴配粉市占率 18.3% 行业第一、成人 / 儿童营养奶粉拓展。
• 冷饮：Q1 +7.1%（2025 全年 98.22 亿、+12.6%），高毛利、增速最快。
• 酸奶 / 奶酪 / 饮用水：低温酸奶（活性益生菌）放量、奶酪（妙可蓝多协同）与家庭大包装乳品培育新曲线。
结论：增长由「奶粉 + 冷饮」双高毛利品类驱动 + 液体乳企稳，结构持续优化、毛利中枢上移。
资产负债与周转效率
资本结构（稳健、杠杆略降）：资产负债率 59.50%（−2.0pp vs 年末 61.51%）；有息负债（短期借款 590.51 ＋ 长期借款 4.50 ＋ 租赁 2.34 ＋ 一年内到期 ~24.05）≈ 621 亿；归母净资产 595.88 亿（+9.02%）。
流动性（表面偏低但含理财错配）：货币资金 197.55 亿，表面现金短债比仅 0.33x（590.51 亿短借），但公司另有其他流动资产 225.74 亿 ＋ 一年内到期非流动资产 44.41 亿 ＋ 其他非流动资产 382.37 亿（结构性存款 / 理财），且利息净收入为正（利息收入 5.27 亿 > 利息费用 2.66 亿）——属「借短投理」资金管理特征，非流动性危机，但杠杆结构需跟踪。
周转效率：存货 103.31 亿（−4.5%）、存货 / 营收 29.7% 健康；应收账款 35.63 亿（+19.3%，快于营收，详见排雷）；应收账款周转率 39 次（2025）仍高。
资产质量：商誉 21.73 亿（占净资产 3.65%）、生产性生物资产 17.26 亿（奶牛群）。
现金流健康度

现金流匹配度：大幅改善但低于净利（季节性）。经营现金流净额 37.35 亿（+293.92%），OCF / 归母 = 37.35 / 53.95 ≈ 0.69x（单季季节性偏低，较 2025Q1 的 0.19x 显著改善）；营收现金比（销售商品收到现金 / 营收）= 317.82 / 348.25 ≈ 91.3%，与收入基本同步。全年口径 OCF 通常远高于净利（2025 全年 OCF 143.44 亿 / 归母 115.65 亿 = 124%）。单季 0.69x 不构成背离，但 Q1 现金流改善部分由「应付供应商款项增加（拖款）」驱动，能否线性外推全年待观察。

OCF 拆解归因（v2 修正 E）：OCF 拆解（亿元，v2 修正 E）：净利润 54.39 ＋ 折旧摊销等非现损益（约 +10）− 营运资金变动。关键项：① 销售商品收到现金 317.82 亿（+8.7%，收入增带动）；② 购买商品支付现金 220.91 亿（−1.5%，应付供应商款项增加使现金流出减少，即「拖款」）；③ 支付税费 16.73 亿（−10.3%）；④ 应收账款 +5.66 亿、存货 −4.92 亿、应付账款 +14.54 亿（营运资金净变动小幅正贡献）。归因：OCF +293.92% 由「收入增 + 现金回款改善 + 应付拖款（占用上游资金）」共同驱动，经营获现质量提升，但拖款贡献的可持续性存疑（详见排雷 14）。

自由现金流与覆盖能力：余量充足。资本开支（购建固定资产等）5.55 亿（同比 −9.1%）；FCF = OCF 37.35 − CapEx 5.55 ≈ 31.80 亿（Q1）。投资活动净流出 64.72 亿（主要为金融理财投资支付 197.88 亿、收回 129.71 亿，净配置理财）；筹资活动净流入 22.53 亿（取得借款 701.91 亿、偿还 676.96 亿，借新还旧 + 净增）。覆盖能力：OCF 远超 CapEx，分红（2025 全年 10 派 13.8 元 ≈ 87 亿）由经营现金流充分支撑（2025 全年 OCF 143.44 亿），非借钱分红；FCF 余量充裕。

估值与股东回报

相对估值水位：历史中低位、高股息。A 股 600887 2026-04-28 收 25.49 元，PE(TTM) 20.1x、PE(动) 11.6x（基于 2026E）、PB(LF) 2.86x、股息率 TTM ~6.7%（2025 全年每股股利 1.38 元，按 25.49 元计约 5.4%）、总市值 ~1,612 亿。相对自身历史（2021 高点 PE 30x+）明显低估；52 周区间 25.13–29.50 元，当前接近底部。

周期正常化估值（v2 修正 F）：乳业非强周期但受原奶成本周期影响（成本下行致盈利阶段性改善）。正常化盈利以2025 归母 115.65 亿为锚（盈利已修复、波动趋稳），对应正常化 PE ≈ 1,612 / 115.65 ≈ 13.9x，处历史低位（v2 修正 F）。但须提示：当前利润含原奶成本红利，若 2026 下半年奶价回升、成本红利收窄，盈利或边际回落；PB 2.86x 高于食品饮料中枢但低于自身历史，高股息（~5.4%–6.7%）提供安全边际。综合：估值偏低、回报可持续。

股东回报可持续性：高分红、可持续。2025 全年拟 10 派 13.8 元（含税），分红率 ~70%–75%（分红总额 ~87 亿）；按 25.49 元计股息率约 5.4%（TTM 口径 ~6.7%）。分红由经营现金流（2025 全年 143.44 亿）充分覆盖，非借钱分红。公司连续多年稳定高分红，股东回报属性强。

管理层指引与前瞻
宏观 / 行业：管理层判断原奶价格处于历史低位、2026 下半年或企稳回升；终端消费需求温和、行业竞争理性化（与第 0.5 章行业坐标一致）。战略：坚持「保盈利基础上的收入增长」，聚焦高端化（金典 / 安慕希）、奶粉及奶制品第二曲线、冷饮与奶酪拓展；持续推进渠道下沉与全域深耕。资本配置：维持 ~70% 分红率、审慎 CapEx、结构性存款理财优化资金收益。风险应对：关注原奶价格回升对毛利率的边际影响、液体乳基本盘持续性。（前瞻性陈述，非承诺）
同业可比与相对表现
乳制品同业对比（2026Q1 / 2025 全年）：
• 伊利股份（600887）：Q1 营收 348.25 亿（+5.5%）、归母 53.95 亿（+10.7%）、净利率 15.49%；2025 全年营收 1,159.31 亿、归母 115.65 亿 —— 规模与盈利质量绝对领先。

• 中国飞鹤（6186.HK）：2025 营收 181.1 亿（−12.7%）、归母 19.39 亿（−45.68%），婴配粉存量博弈。
• 新乳业（002946）：Q1 营收 28.43 亿（+8.31%）、归母 1.86 亿（+39.89%），低温 + 并购差异化。
结论：伊利呈「规模第一 + 净利率最高 + 盈利质量最稳」特征，相对同业处领先且确定性更强水平；唯一差距在估值溢价（PE 20x 高于光明 / 飞鹤亏损口径），但高股息与稳定性支撑溢价。

业务亮点与潜在风险

✓ 业务亮点

  • 2026Q1 营收 348.25 亿（+5.47%）、归母 53.95 亿（+10.68%）、扣非 53.29 亿（+15.11%），利润增速约为营收两倍，为 2024–2025 波动后重回稳健扩张。
  • 原奶成本红利 + 结构升级 + 费用优化：毛利率升至 38.52%（+0.7pp）、净利率 15.49%（+0.73pp）、销售费率 −0.2pp，盈利质量「真」（非经仅占 1.2%）。
  • 经营现金流净额 37.35 亿（+293.92%），净现比由 0.19x 升至 0.69x；资产负债率降至 59.5%、ROE 9.44%，资产质量稳健。
  • 龙头领先优势稳固：营收规模与净利率远超蒙牛 / 光明 / 飞鹤，婴配粉市占率 18.3% 行业第一；估值处历史中低位（PE 20x）、股息率 ~5.4%–6.7%。

⚠ 潜在风险

  • 应收 / 债务信号：应收账款 +19.3% 快于营收、短期借款 +29.4% 至 590 亿（现金短债比 0.33x）、合同负债腰斩，雪球质疑「借短拖款、资金面偏紧」。
  • 经营现金流改善可持续性：OCF +293.92% 部分由应付拖款驱动，能否外推全年存疑。
  • 原奶价格回升风险：当前利润含奶价低位红利，若 2026 下半年奶价企稳回升，毛利率或边际收窄、成本红利减弱。
