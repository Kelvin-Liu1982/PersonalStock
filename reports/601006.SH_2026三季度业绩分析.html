中性偏谨慎

大秦铁路 2026 前三季度呈「累计平稳、单季失速」的双重特征：营收 582.35 亿元（+2.06%）、归母净利润 58.24 亿元（−6.42%）、扣非 57.89 亿元（−6.46%），累计降幅温和；但 Q3 单季营收 186.38 亿元（−5.74%）、归母 15.69 亿元（−25.59%）、扣非 15.46 亿元（−26.02%），失速明显。核心驱动是大秦线煤炭运量三季度转弱——前三季度累计运量 29,758 万吨（+4.10%）尚可，但 Q3 单季 9,382 万吨（−3.42%）、9 月单月 3,138 万吨（−5.05%），8 月日均运量一度不足 100 万吨；成因是山西主产区产量边际承压（供给）+ 居民用电转弱、煤价走高致下游采购放缓（需求）。成本刚性放大了运量下滑的杀伤力：Q3 营业成本 172.16 亿元仅 −0.66%，致 Q3 毛利率 7.63%（−4.72pp）。两大缓冲垫：① 投资收益 23.66 亿元（+9.26%，对联营合营 23.63 亿，主为朔黄铁路），占利润总额 28%，Q3 单季 7.98 亿（+8.3%）提供稳定托底；② 财务结构极佳——资产负债率仅 16.23%、货币资金 274.46 亿元 + 国铁财务公司定期存款约 200 亿元，净现金约 138 亿元。股东回报持续：中期分红 15.89 亿元（派息率 37.34%）、回购 4–5 亿元已执行 1.33 亿元。估值 PB 0.59×（深度破净）、股息率 TTM 4.59%，但机构已普遍下调盈利预测（华创 66.1 亿、申万 57.39 亿），「业绩低于预期」为卖方共识。

✓ 核心利好

预期来源与统计时点：卖方一致预期与点评（2026-10-27/28）：① 申万宏源：明确「业绩低于预期」，指出「西煤东运供需双弱」，下调大秦线运量增速假设至 3%、平均运距至 500km、上修人员费用涨幅至 4%，2026E–28E 归母下调至 57.39 / 63.56 / 66.77 亿元（原 76.59 / 82.42 / 88.83，降幅约 25%），对应 PE 17 / 15 / 15×，维持「增持」。② 华创证券：Q3 单季运量转弱致业绩承压，投资收益筑底；调整 2026–28 年归母至 66.1 / 72.4 / 77.4 亿元（原 76.7 / 80.9 / 85.2），EPS 0.33 / 0.36 / 0.39 元，PE 15 / 14 / 13×，维持「推荐」，强调破净高股息配置价值。③ 另一家券商预计 2026–28 年营收 804.46 / 831.72 / 859.10 亿元、归母 63.27 / 67.03 / 70.70 亿元，维持「增持」。预期差结论（v2 修正 B）：前三季度归母 58.24 亿元，相对华创 66.1 亿元预测完成度约 88%、相对申万 57.39 亿元约 101%——机构分歧显著，但「Q3 单季低于预期」为共识；综合判定「累计符合至略低于预期、单季明确低于预期」，分歧焦点在 Q4 运量修复幅度。

行业坐标与供需

行业所处阶段与传导方向：铁路运输行业 2026 年前三季度处于「货运需求转弱、政策仍偏支持」的分化期。核心变量：① 供给端——山西等主产区合规减产、安全生产监管趋严，煤炭产量边际承压，直接减少西煤东运货源；② 需求端——Q3 居民端用电转弱、电煤需求季节性走弱，叠加煤价走高使下游电厂采购计划放缓，运输市场货盘减少；③ 政策——国家「调整运输结构」目标延续推进，「公转铁」仍有较大空间，且煤炭生产重心加快向「三西」地区集中，使大秦线区位优势进一步凸显；④ 竞争——浩吉铁路、张唐铁路等西煤东运/北煤南运新通道分流，以及公路运输在短途的竞争。对公司的传导：大秦铁路作为国铁集团西煤东运龙头，运量（量）是收入的第一驱动、运价受政策管制（价）弹性小，而折旧/人工/电力成本高度刚性，因此运量小幅下滑即被经营杠杆放大为利润大幅下滑（Q3 运量 −3.42% → 归母 −25.59%）。行业坐标：当前处「量价双弱的成本刚性考验期」，短期业绩承压；中期看公转铁与三西产能集中仍提供结构性支撑，投资逻辑以高股息 + 破净修复为主，而非成长。

量价 / 供需 / 价格位置 / 政策：量：大秦线 2026 前三季度累计货运量 29,758 万吨（+4.10%）；分季 H1 20,376 万吨（+8%）、Q3 9,382 万吨（−3.42%）、9 月单月 3,138 万吨（−5.05%），8 月日均运量不足 100 万吨。价：铁路货运运价受国家管制，弹性小，公司未披露运价调整。成本：Q3 营业成本 172.16 亿元（仅 −0.66%）——折旧摊销、人员费用、电力及燃料刚性，叠加转型物流过程中前后端物流辅助费用增加。政策：国家「调整运输结构」「公转铁」持续推进；煤炭生产重心向三西地区集中；山西主产区合规性减产。同业参照：申万选取宁沪高速（2026E 归母 48.26 亿、分红比例 53.73%、股息率 4.04%）与皖通高速（2026E 归母 20.39 亿、分红比例 60.06%、股息率 4.24%）作为股息率定价对标。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：重资产铁路，以 ROIC − WACC 衡量价值创造（v2 修正 C，允许定性/区间）。ROIC 侧：NOPAT ≈ 营业利润 84.84 亿 ×（1 − 有效税率 22.7%）≈ 65.58 亿（1–9 月），年化约 87.44 亿；投入资本 IC ≈ 归母权益 1,645.58 亿 + 少数股东权益 159.34 亿 + 有息负债约 136.28 亿（短期借款 2.01 + 长期借款 101.80 + 一年内到期非流动负债 10.14 + 租赁负债 22.33）− 货币资金 274.46 亿 − 定期存款约 200.94 亿（其他流动资产 121.98 + 其他非流动资产 78.96，属现金等价物性质的财务公司存款）≈ 1,465.80 亿 → 年化 ROIC 约 6.0%。WACC 侧：Re ≈ 无风险利率（10Y 国债约 1.7%）+ β（铁路约 0.6–0.8，防御性资产）× ERP 5.5% ≈ 5.0%–6.1%；债权成本极低（利息费用 2.65 亿 / 有息负债 136.28 亿 ≈ 2.6% 税前、税后约 2.0%），债权占比低（约 8.5%）→ WACC 约 4.8%–5.8%。ROIC − WACC 约 +0.2~1.2pp，勉强创造价值但缓冲极薄——较 2023 年（归母 119.30 亿）显著下滑，主因运量回落 + 成本刚性 + 重资产基数大（固定资产 866.12 亿 + 无形资产 338.67 亿）。注：货币资金与定期存款是否作为「超额现金」扣除存在主观性；若不作扣除，ROIC 降至约 5.2%，与 WACC 基本持平——即公司当前处于「价值创造与毁灭的临界点」，运量恢复是扭转的关键。

增长归因（量 / 价 / 成本 / 非经）：利润桥（Δ利润总额 = 84.36 − 92.58 = −8.22 亿元）：正向——投资收益 +2.00 亿（21.66 → 23.66 亿，对联营合营 +2.01 亿）、管理费用 −1.84 亿（5.43 → 3.59 亿，−33.83%，党组织工作经费减少）、所得税 −3.96 亿（23.14 → 19.18 亿，有效税率 25.0% → 22.7%）、信用减值转回 +0.22 亿、资产处置收益 +0.08 亿。负向（主因）——毛利减少 −10.32 亿（营收 +11.77 亿、营业成本 +22.89 亿）：营收 570.58 → 582.35 亿（+2.06%），而营业成本 494.02 → 516.91 亿（+4.63%），成本增速是收入增速的 2.2 倍 → 毛利率由 13.42% 降至 11.24%（−2.18pp）；财务费用多减 −1.18 亿（利息收入由 5.17 亿降至 3.98 亿，因货币资金减少）、其他收益 −0.13 亿。量价拆解：前三季度大秦线运量 +4.10%（量增）但营收仅 +2.06%，隐含单位收入下降（运距缩短或货品结构变化）；成本端三项刚性——折旧摊销（固定资产 866.12 亿 + 无形资产 338.67 亿）、人工（支付给职工现金 159.03 亿，+2.8%）、电力燃料，叠加转型物流的前后端辅助费用增加。Q3 单季放大效应：运量 −3.42% → 营收 −5.74%，而成本仅 −0.66% → Q3 毛利率 7.63%（−4.72pp）、归母 −25.59%。结论：利润下滑由「成本增速快于收入 + 单季运量转弱」双因素驱动，成本刚性是核心放大器。

盈利质量（扣非 vs 归母，真 / 虚）：利润质量「干净」，主业与非经界限清晰。归母 58.24 亿 vs 扣非 57.89 亿，非经常性损益仅 +0.357 亿元（占归母 0.6%）——构成：政府补助 +0.827 亿、非流动资产处置 +0.060 亿、其他营业外收支 −0.453 亿，减所得税影响 0.103 亿、少数股东影响 −0.027 亿。扣非增速（−6.46%）与归母增速（−6.42%）几乎一致，说明利润变动完全由经营因素驱动，无靠非经保利润或洗大澡迹象。需注意的口径问题：投资收益 23.66 亿元（对联营合营 23.63 亿）属经常性损益（权益法核算的长期股权投资收益），却占利润总额 28%、归母的 40.6%，且不产生经营现金流入（本期取得投资收益收到现金 26.81 亿元系联营企业实际分红，时点与利润确认存在错配）。剔除投资收益后的「经营性利润」约为 60.70 亿元，同比 −13.3%——下滑幅度大于表观 −6.42%，即主业实际承压程度比表观更重，参股资产（朔黄铁路）掩盖了部分恶化。综合收益总额 65.20 亿元（−6.14%），与净利润 65.18 亿元基本一致，无其他综合收益扰动。

业务分部与地区拆解
公司按业务类型披露（2026 半年度口径占比，三季报未细分）：
• 货运业务（核心）：2026H1 收入 278.83 亿元，占营收 70.42%——以大秦线煤炭运输为主，是公司绝对核心；前三季度大秦线运量 29,758 万吨（+4.10%），Q3 单季 9,382 万吨（−3.42%）。
• 客运业务：2026H1 收入 53.69 亿元，占 13.56%。
• 其他业务：2026H1 收入 59.60 亿元，占 15.05%——含向国内其他铁路运输企业提供服务（委管费等，对应应收账款 +33.59%）、物流辅助业务（转型方向）。
• 投资收益：23.66 亿元（+9.26%），其中对联营合营 23.63 亿元（+9.28%），相当于第二增长极，主要来自朔黄铁路等参股路产；Q3 单季 7.98 亿元（+8.3%）。
增量贡献（v2 修正 H）：利润总额同比 −8.22 亿元中，投资收益 +2.00 亿元是唯一显著正向贡献（若剔除投资收益，经营性利润同比降幅由 −8.89% 扩大至约 −13.3%）；负向主源是毛利 −10.32 亿元（成本刚性所致）。结论：本期唯一增长引擎是参股资产投资收益，主业（货运 + 客运 + 其他）合计为负贡献，运量转弱是主因。
资产负债与周转效率
资本结构：总资产 2,154.69 亿元（较年初 +1.72%）、负债 349.78 亿元（+8.36%）→ 资产负债率仅 16.23%（上年末 15.24%，+0.99pp），远低于 A 股平均，财务杠杆极低。归母净资产 1,645.58 亿元（+0.17%）、少数股东权益 159.34 亿元（+4.4%）。有息负债约 136.28 亿元（短期借款 2.01 + 长期借款 101.80 + 一年内到期非流动负债 10.14 + 租赁负债 22.33），货币资金 274.46 亿元 + 国铁财务公司定期存款约 200.94 亿元（其他流动资产 121.98 亿 +534% + 其他非流动资产 78.96 亿 +88.54%）→ 净现金约 339 亿元（宽口径）/ 138 亿元（仅计货币资金）。资产端异动：其他流动资产 +534.09%、其他非流动资产 +88.54%（在国铁财务公司存入定期存款，安全性高但收益率低于经营资产）；在建工程 34.88 亿元（+295.61%），主因运输设备大修项目增加；固定资产 866.12 亿元（−3.4%）、无形资产 338.67 亿元（−1.9%），系折旧摊销。负债端异动：合同负债 35.87 亿元（+97.10%，预收运费增加，属利好）、其他应付款 61.70 亿元（+38.29%，含应付股利 15.89 亿元已宣告未支付）、长期应付款 +71.00%（收到超长期国债补贴）、短期借款 −30.52%（子公司还款）。商誉 0、开发支出 0、预计负债 0——资产负债表极度干净。
现金流健康度

现金流背离
关注OCF 96.31 亿元 / 归母净利润 58.24 亿元 ＝ 1.65×（重资产折旧摊销大，属正常）；但 OCF 同比 +168.39% 与净利润 −6.42% 方向明显背离，必须拆解：支付的各项税费由 55.96 亿元降至 19.66 亿元（−64.88%，少付 36.30 亿元），系上年同期缴纳契税形成的高基数——这一项贡献了 OCF 多增 60.42 亿元中的约六成，且完全不具持续性；其余来自销售商品收到现金 +34.97 亿元（+9.9%，运输进款增加）。结论：现金流与利润的背离并非盈利质量改善的信号，而是税费支出的基数效应 + 折旧摊销的非现金属性所致；剔除税费因素后经营性现金改善约 24 亿元，仍健康但远非表观那般亮眼。
收入确认激进（v2新增）
低风险铁路运输收入按运输服务完成时点确认，不存在渠道压货、完工百分比法或提前确认的空间。反向证据：合同负债 35.87 亿元（+97.10%，预收运费增加）、预收款项 +37.95%（子公司预收房屋租金）——预收款大幅增加恰恰说明公司在收到款项后并未提前确认收入，会计处理审慎。营收 +2.06% 与大秦线运量 +4.10% 的方向一致（单位收入略降，系运距缩短或货品结构变化），相互印证，无虚增迹象。
表外/担保/或有负债（v2新增）
低风险预计负债为 0，季报未披露对外担保、未决诉讼或明股实债事项；少数股东权益 159.34 亿元（+4.4%）主要来自控股子公司（如侯禹铁路、太兴铁路等），结构历年稳定，本期少数股东损益 6.94 亿元（−3.8%）占比稳定。或有事项方面：专项储备 3.37 亿元（+72.81%，计提安全生产费增加，铁路行业特有）、长期应付款 1.07 亿元（+71.00%，收到超长期国债补贴）、递延收益 1.94 亿元（政府补助）。外币敞口：汇兑损益为 0、无外币报表折算差额，无汇率风险。
煤炭运量周期下行（行业特有·核心红旗）
核心红旗大秦线运量三季度实质性转弱：前三季度累计 29,758 万吨（+4.10%）尚可，但 Q3 单季 9,382 万吨（−3.42%）、9 月单月 3,138 万吨（−5.05%），8 月日均运量一度不足 100 万吨，增速由 H1 的 +8% 边际收窄至 +4.10% 并转负。成因供需双弱：① 供给——山西主产区合规性减产，煤炭产量边际承压；② 需求——Q3 居民端用电转弱、电煤需求季节性走弱，叠加煤价走高使下游电厂放缓采购。危险在于经营杠杆：铁路成本高度刚性，Q3 营业成本 172.16 亿元仅 −0.66%，运量 −3.42% 直接被放大为营收 −5.74%、Q3 毛利率 7.63%（−4.72pp）、归母 −25.59%。这是本期最实质的经营红旗，须紧盯 Q4 冬储煤旺季运量与 2027 年山西产量恢复节奏。
成本刚性与投资收益依赖（行业特有·红旗）
红旗两项结构性弱点并存。① 成本刚性：营业成本 516.91 亿元（+4.63%）增速是营收（+2.06%）的 2.2 倍，毛利率由 13.42% 降至 11.24%（−2.18pp）；刚性来源为折旧摊销（固定资产 866.12 亿 + 无形资产 338.67 亿）、人工（支付给职工现金 159.03 亿元，+2.8%）、电力燃料，叠加转型现代物流带来的前后端物流辅助费用增加；在建工程 34.88 亿元（+295.61%，运输设备大修）转固后折旧压力将进一步上升。② 投资收益依赖：投资收益 23.66 亿元（+9.26%）占利润总额的 28%、归母的 40.6%，且为权益法核算（对联营合营 23.63 亿元，主为朔黄铁路），不产生经营现金流。剔除投资收益后的经营性利润约 60.70 亿元、同比 −13.3%，降幅远大于表观的 −6.42%——即参股资产掩盖了主业更大幅度的恶化，这是解读本期业绩最需要警惕的一点。

  • 现金流大幅改善：经营现金流净额 96.31 亿元（+168.39%），销售商品收到现金 387.64 亿元（+9.9%），OCF / 归母 ＝ 1.65×
