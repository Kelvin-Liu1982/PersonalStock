  • 电价与资本开支：市场化交易比例提升或压电价；葛洲坝航运扩能等资本开支持续

行业坐标与供需

行业所处阶段与传导方向：水电属强来水依赖型公用事业，业绩第一驱动力为流域来水与消纳电价。2026 上半年长江流域来水显著分化——三峡来水偏丰 28.74%、乌东德偏枯 16.94%，行业整体呈「区域分化、联调制胜」格局；电价端受电力市场化改革推进，水电综合电价温和承压但降幅可控。对公司传导：来水决定电量、电价决定单位收益，二者共同决定营收；利率下行则通过财务费用改善利润。

量价 / 供需 / 价格位置 / 政策：装机：公司水电总装机 7179.5 万千瓦（国内 7169.5 万千瓦，占全国水电 15.77%），为全球最大水电上市公司。来水：三峡水库上半年来水 1744.90 亿 m³（同比 +28.74%），金沙江下游（乌东德/白鹤滩/溪洛渡/向家坝）偏枯。电价：水电上网电价由政策标杆 + 市场化交易构成，市场化比例提升带来小幅波动。政策：绿电消纳优先，抽蓄与新能源拓展获政策支持。

盈利质量与增长归因

ROIC − WACC（创造价值判据）：重资产水电 ROIC 与 WACC 接近（估算约 3–4%），因其价值不在高 ROIC 而在于特许经营稀缺资产 + 极度稳定现金流；加权 ROE 6.55%（+0.46pp），债务成本下行推升 ROE。结论：ROIC−WACC 大致持平，价值以「确定性分红」体现，而非高资本回报（数据不足，降级为定性提示）。

增长归因（量 / 价 / 成本 / 非经）：增长归因——量：发电量 +4.81%（三峡 +31.62%、葛洲坝 +11.05% 拉动，上游四站小幅下滑被对冲）；价：综合电价基本平稳；成本：营业成本 −0.81%、财务费用 −13.62%（利息费用 −14.1%）是利润增速跑赢营收的主因；非经：金融资产公允价值变动收益 6.38 亿（去年同期 −0.15 亿）贡献约 5.6 亿税前。结论：增长约 2/3 来自主业降本 + 发电量微增，约 1/3 来自非经常性收益。

盈利质量（扣非 vs 归母，真 / 虚）：盈利质量——扣非归母 142.94 亿（+8.37%）vs 归母 147.56 亿（+13.02%），非经常性损益 4.62 亿（占净利 3.13%），其中金融资产公允价值变动 6.38 亿为主。扣非增速低于归母，说明主业真实增速约 8%，质量「真实但含少量非经」，需剔除公允价值变动看核心。

业务分部与地区拆解
业务高度集中水电：2026H1 主营业务 378.34 亿（占总营收 99.7%），境内水电为主。分电站发电量（亿千瓦时，同比）：三峡 450.73（+31.62%）、葛洲坝 91.15（+11.05%）、溪洛渡 267.04（−4.51%）、向家坝 150.09（−3.73%）、白鹤滩 243.92（−5.05%）、乌东德 124.51（−16.76%）。增量利润主源为三峡（来水偏丰 + 电价稳健）+ 财务费用下降；上游四站减发被下游联调对冲。国际业务（秘鲁）净利润同比 +30%+，贡献增强。
资产负债与周转效率
资本结构：总资产 5613.51 亿（+0.38%），归母净资产 2161.31 亿（−2.35%，因分红减少留存）。有息负债（合并）2823.59 亿（−2.35%），短期借款 67.03 亿（较期初 −84.78 亿，债务结构优化）；货币资金 93.73 亿（较期初 +47.87 亿）。流动性：流动比率 0.20、速动比率 0.19（重资产行业常态，靠长期债务 + 稳定经营现金流覆盖，非预警）；现金短债比 = 93.73 / 67.03 = 1.40（改善）。利息保障倍数 5.21（+25.2%）、EBITDA 利息保障 7.42（+20.9%），偿债能力强劲。
现金流健康度

现金流匹配度：现金流匹配度极高：OCF 241.28 亿 / 净利润 150.34 亿 = 1.60×，盈利现金含量远超 1，利润全部转化为真金白银；销售商品收现 399.04 亿 > 营收 379.29 亿（收现比 1.05），营收质量扎实。

OCF 拆解归因：OCF 拆解归因（将净利调节为经营现金流）：净利润 150.34 亿 + 折旧摊销等约 94.6 亿（固定资产折旧 92.32 亿 + 使用权资产摊销 0.59 + 无形资产 1.57 + 长期待摊 0.10）+ 财务费用 42.51 亿 − 投资收益 24.76 亿（投资回报不计入 OCF）− 公允价值变动收益 6.38 亿（未实现）− 经营性应收增加 31.60 亿（电网回款节奏，对手方低信用风险）+ 经营性应付增加 14.55 亿 = OCF 241.28 亿。主因：重折旧资产天然高现金含量；应收增加是主要营运资金占用。

自由现金流与覆盖能力：自由现金流 FCF = OCF 241.28 − 资本开支 44.35 亿 = 196.93 亿（CapEx 同比 −29.7%，在建工程转固节奏放缓）。FCF 充裕：覆盖 2025 全年分红 244.68 亿的 80%（H1 已派部分），覆盖资本开支 4.4 倍；FCF 收益率 = 196.93 / 总市值 6863 亿 ≈ 2.9%，叠加高分红具长期压舱价值。

估值与股东回报

相对估值水位：相对估值（2026-08-28 收盘 28.05 元）：总市值 6863 亿，PE(TTM) 19.0×、PE(动) 25.4×、PB 3.29×，股息率(TTM) 3.57%。PE 处历史中高位（水电稀缺资产溢价），PB 3.29× 反映资产重估；股息率 3.57% 与十年期国债 1.69% 息差 1.91%（历史高位），防御属性突出。

周期正常化估值：周期正常化：水电非强周期但受来水波动，利润随丰枯水年摆动。以正常化盈利看，近四年归母 237→272→325→345 亿、2026E 约 361 亿（国金），稳态盈利 340–360 亿对应 PE 19–20× 属合理中枢；若按 70% 分红承诺，2026 年股息约 0.92–0.97 元/股，股息率 3.3–3.5%，下行有分红托底。当前估值未显著高估，但已反映「确定性溢价」。

股东回报可持续性：分红确定性极强：公司承诺 2026–2030 年每年现金分红比例不低于当年归母净利润的 70%（白纸黑字锁定）。2025 全年分红合计 244.68 亿（末期 7.90 元/10 股 + 已实施中期），创历史新高；2026H1 无中期分红预案（延续年报分红惯例）。按上半年归母 147.56 亿外推，全年分红有望维持 70% 高位。控股股东三峡集团 2025-08 至 2026-08 增持 1.62 亿股（44.99 亿、均价 27.84 元），增持后合计持股 53.23%，彰显长期价值认可。

管理层指引与前瞻
管理层指引与前瞻：① 来水：主汛期（7–8 月）金沙江下游来水改善明确（溪洛渡/向家坝 7 月入库流量同比 +31.3%/+34.5%），下半年发电量有支撑；② 资本开支：葛洲坝航运扩能、抽蓄（巩义/张掖/奉节/攸县/寻乌）与新能源持续推进，未来几年有持续投入；③ 电价：市场化交易比例提升或带来电价小幅波动，公司通过「生产-调度-营销」协同足额兑现发电效益；④ 敏感性：利率每降 10bp 约减财务费用数亿，直接增厚利润；来水每偏离均值 ±5% 影响电量约 ±3–4%。指引为前瞻性陈述，非承诺。
同业可比与相对表现
同业可比（2026H1）：长江电力营收 379.29 亿（+3.36%）、归母 147.56 亿（+13.02%）——明显领跑水电同业，是唯一营收与利润双增且利润两位数增长的龙头。对比：华能水电营收 131.47 亿（+1.45%）归母 43.76 亿（−5.05%）、国投电力营收 238.86 亿（−7.05%）归母 35.35 亿（−6.83%）、川投能源营收 6.80 亿（−4.53%）归母 23.30 亿（−5.34%），均受来水/电价拖累利润下滑。长电凭六库联调在分化来水中逆势双增，相对同业呈「盈利确定性溢价」，估值 PB/PE 高于同业但由稀缺资产与高分红支撑。
财务排雷
商誉
—账面对外无重大商誉余额（以自有梯级水电资产为主，并购型商誉极少），商誉/净资产、商誉/年利润均无泡沫风险。
研发资本化
—研发费用 3.28 亿全部费用化（同比 +43.8% 系科研投入加大），无资本化率的异常上升，无利润注水。
资产减值
—资产减值损失仅 25 万元、信用减值损失 1051 万元，金额极小，无大额一次性减值（洗大澡/平滑利润）迹象。
债务结构
关注有息负债（合并）2823.59 亿，短期借款 67.03 亿（较期初 −84.78 亿）占比低；现金短债比 1.40 改善。但流动比率仅 0.20（重资产常态，靠长期债+稳定现金流覆盖），需持续关注期限错配。
审计意见
—半年报按惯例未经审计（上市公司中报普遍如此），无保留意见/无违规提示，审计层面无异常。
关联交易
—经营性应收主要为电网（国网/南网）电费，关联交易以电能销售与电站托管为主；未发现其他应收畸高或资金占用迹象。
营收质量
关注应收账款 103.20 亿，较年初（72.52 亿）+42.3%，增速高于营收，或反映电网回款周期拉长；但对手方为电网、坏账风险极低，销售收现比仍达 1.05。
存货
—水电几乎无产成品存货（仅备品备件），存货/营收极低、周转无压力，无积压/滞销或跌价准备不足风险。
非经常性损益
关注非经常性损益 4.62 亿（占净利 3.13%），主为金融资产公允价值变动收益 6.38 亿；扣非增速(+8.37%)低于归母(+13.02%)，主业真实增速约 8%，质量真实但含少量非经。
现金流背离
健康OCF/净利 = 1.60×，长期远高于 1，盈利现金含量极高，无背离；经营收现比 1.05，利润全部转化为现金。
收入确认激进（v2新增）
低风险水电按「发电量×上网电价」确认收入，电量由电网计量、电价由政策/合同锁定，无渠道压货、无完工百分比提前确认；营收与现金流匹配（收现比 1.05），收入确认激进风险极低。
表外/担保/或有负债（v2新增）
低风险对外担保规模小、以经营类履约担保为主，未见重大未决诉讼或并表范围突变量利润搬移；控股股东可交换债属集团层面、非公司表内担保，表外风险可控。
外币折算/汇率
—国际业务（秘鲁）占比小（境外资产 538.42 亿、占 9.59%），汇率波动对整体影响有限，本期汇兑损益微小。
资本开支与FCF覆盖
健康资本开支 44.35 亿（同比 −29.7%），FCF 196.93 亿充裕，覆盖资本开支 4.4 倍、可覆盖全年分红；自由现金流支撑双线支出无虞。
