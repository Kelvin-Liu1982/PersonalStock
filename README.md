# 中远海控 · 主营与业绩追踪看板（方向C + 趋势增强）

一个面向 **中远海控（601919.SH / 01919.HK）** 的单文件 HTML 追踪看板：把集装箱航运主业、港口码头、财报、供给、成本、宏观与政策等关键维度，以模块化卡片 + 长期趋势对比的方式集中呈现，便于日常跟踪公司经营节奏与景气变化。

- **交付物**：`中远海控追踪看板(方向C).html` —— 单文件、自包含（数据与时序图已 base64 内嵌，无外部 CDN 依赖），双击即可在浏览器打开。
- **风格**：浅色卡片网格 + 状态 chip + 迷你趋势(sparkline)；点「趋势」看完整长期图；底部「长期趋势专区」集中对比。
- **视觉约定**：红 = 上行(涨) / 绿 = 下行(跌)（A 股惯例）。

## 快速开始

1. 直接用浏览器打开 `中远海控追踪看板(方向C).html` 即可，无需任何安装或联网。
2. 顶部为当日行情快照（A 股 / H 股）；每张卡片 = 最新快照 + 迷你趋势；点「趋势」按钮查看完整长期图。

## 重新构建（修改数据后）

### 依赖

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt   # openpyxl, matplotlib
```

### 仅用已提交的 数据源/ 重生成看板（离线、最常用）

```bash
python build_tracker.py
python render_html.py
```

### 一键全流程（含原始数据制备）

```bash
python build.py
```

`build.py` 会依次执行：`build_financials.py` → `build_buyback.py` → `build_tracker.py` → `render_html.py`。
其中 `build_financials.py` 会尝试联网抓取东方财富业绩报表，失败则回退到本地 `财报原始数据_缓存.json`。

## 数据源说明

| 文件 | 用途 |
|---|---|
| 中远海控分析_行业供需与运价数据库(2025-2026).xlsx | 运价(SCFI/CCFI 各航线)、港口吞吐量、出口总额、运力/闲置率、停航率、成本与宏观指标等 |
| 中远海控核心运营指标数据库(2021-2026).xlsx | 分航线箱量与收入占比、季度航运货运量明细等 |
| 中远海控_2021-2025年报及2026Q1财报核心数据.xlsx | 营收/归母净利/毛利率/ROE（年度+季度）、成本结构、港口码头业务、分红 |
| 中远海控_2026回购明细.xlsx | 2026 年 A 股 / H 股回购明细 |
| 2026年中国出口集装箱运输市场周度报告数据分类汇总.xlsx | 周度运价报告数据（参考） |

> 宏观与政策类指标（PMI、燃油价、租船费率、EU ETS 碳价、红海绕航比例等）为公开数据近似，非公司披露口径，看板内已标注。
