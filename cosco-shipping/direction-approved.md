# 中远海控追踪看板 · 方向确认单

## 选定方向
- **方向C + 趋势增强**：模块化追踪看板（浅色卡片网格 + 状态 chip + 进度条/数据源标注）叠加长期趋势集成。
- 最终交付物：`cosco-dashboard.html`（原型阶段的设计稿 design-demos/ 已清理）。

## 设计原则
- 单文件 HTML 交付，双击即开，移动目录不裂图。
- 快照（卡片最新值）与趋势（图表/Sparkline）同源驱动：数据从同一份 Excel 抽取，避免两张表打架。
- 诚实占位：数据库中缺失的维度标为「待更新」并给出补充清单，不编造数字。
- 红涨绿跌：A 股惯例。

## 数据主源
- **主文件**：`中远海控_行业供需与运价数据.xlsx`
- **财务副文件**：`中远海控_财报核心数据.xlsx`（本次新增的独立交付文件）
- 约定：后续行业/运价/供需数据更新以主文件为准；财报数据更新以财务副文件为准。更新后运行 `python build.py` 即可刷新整个看板。
- 当前已接入：
  - `周运价指数(SCFI&CCFI)`：SCFI/CCFI、5 条主力航线运价、舱位利用率、市场行情简评。
  - `需求端-港口吞吐量&出口`：港口吞吐量、出口总额、分区域出口增速。
  - `供给端-运力&闲置率`：全球运力、闲置率、手持订单比例。
  - `供需调控-停航率&联盟`：美线/欧线停航率、联盟调控策略。
  - **财务核心指标**：2021–2025 年报 + 2026Q1 季报（营收、净利、毛利率、净利率、ROE、资产负债率、经营现金流、EPS 等），来自财务副文件。
  - **成本结构**：航线成本分项（设备货物/航程含燃油/船舶含租船/其他）+ 航线单箱成本(USD/TEU) + 货运量，2021–2025，来自财务副文件「成本结构」表。注：燃油费/租船费年报未单列，隐含于航程/船舶成本。
  - **航线结构占比**：分航线箱量与收入明细（2021–2025 全年），来自运营副文件「分航线箱量与收入明细」表；包含五条主力航线（美线、欧地线、近洋线、内贸线、其它国际）的货运量占比与收入占比。
- **运营副文件**：`中远海控_货运量与航线结构数据.xlsx`（独立交付文件，含年度核心运营指标、分航线箱量与收入明细、港口吞吐量，用于航线结构占比）
- **回购副文件**：`中远海控_回购明细.xlsx`（独立交付文件，含 A股第4/5轮、H股2026逐日明细）
- 尚未在数据库中、以「示例」暂存的：船队运力（维度1 仍示例）。
- 港口码头业务财务数据已并入 **财报核心数据.xlsx「港口码头业务」** 工作表（收入/成本/毛利率/毛利/总吞吐量/营收占比）；泊位利用率、海外布局按用户意见暂不细化（业务占比仅约 2%–6%）。

## 更新工作流
1. 编辑数据主源 Excel。
2. 在终端运行：
   ```bash
   cd cosco-shipping
   /Users/sto1/.workbuddy/binaries/python/envs/default/bin/python build.py
   ```
3. 产物：`cosco-dashboard.html` 会自动刷新。
