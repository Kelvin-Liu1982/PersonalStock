## 3. 抓取架构与代码模块

```
data_pipeline/
├── config.py          # 标的/路径/年份/输出目录/Eastmoney 接口常量
├── sources.py         # 数据来源登记表（见第 2 节）
├── fetcher.py         # 真实抓取层：Eastmoney HTTP 请求 + JSON 缓存 + build_fetched_snapshot()
├── annual_report_data.py  # 已核验指标字典 METRICS（逐字段标注 source/note，TBD=None）
├── transform.py       # 转换层：METRICS + 实时抓取覆盖(2025) + 单季推导 → 5 文件表结构
├── store.py           # 持久化层：三-sheet XLSX 写入（与中国移动 build_excel.py 同款样式）
├── run.py             # 入口：抓取 → 组装 → 写盘
└── cache/             # 原始抓取 JSON 缓存（hk_income / hk_balance / a_income / hk_quote）
```

**抓取与覆盖逻辑（关键）：**
1. `fetcher.build_fetched_snapshot()` 实时抓取 00728.HK 最新年度利润表/资产负债表，转换为 `{年份: 值}`（金额类元→亿元；EPS 保持元/股）。
2. `transform.reconcile_with_fetch()` 用实时值 **覆盖 METRICS 中的 2025 单元格**（revenue / net_profit / eps / ebitda / ar / debt_ratio），保证最新年度始终来自接口。
3. `transform._quarterly_rows()` 从 H 股 F10 **累计利润表推导单季**：Q1=一季报，H1=半年−Q1，Q3=前三季−H1，Q4=全年−前三季；跨入新财年时累计归零（2026Q1 单独计）。
4. 网络不可用时，`fetcher` 回退到 `cache/`；`reconcile` 失败则保留已核验值，不影响产出。

**实测校验（2025 实时抓取值，单位亿元/元）：**
- 营业额 5295.59 · 股东应占溢利 331.85 · 每股基本盈利 0.36 · 经营溢利 396.74 · 折旧与摊销 1041.98
- → EBITDA = 396.74 + 1041.98 = **1438.72**
- 总资产 8706.44 · 总负债 4023.84 · 股东权益 4608.28 · 应收账款 **531.46**
- → 资产负债率 = 4023.84 / 8706.44 × 100 = **46.22%**
- 单季营收求和（2025Q1+Q2+Q3+Q4）= 1354.98+1359.71+1255.29+1325.61 = **5295.59**（=全年，自洽）

## 4. 存储结构与格式

每个 `.xlsx` 含三张 sheet：

### Sheet1 · 年报数据
- 表头（第 4 行）：`指标 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 备注`
- 指标为行、年份为列（metrics-as-rows）；最后一列"备注"写口径/来源提示（琥珀底 `#FDF3E3`）。
- 数值右对齐、两位小数 `#,##0.00`；无法核验年份显示 `—`。
- 冻结窗格 `B5`（横向滚动锁定指标列，纵向锁定表头）。
- 标题（第 1 行）：如"中国电信 · 财务健康与盈利质量（2020–2025）"；第 2 行为口径说明。

### Sheet2 · 季报数据
- 表头：`指标 | 2025Q1 | 2025H1 | 2025Q3 | 2025全年 | 2026Q1 | 备注`
- 仅含两张推导行：**营业收入(单季,亿元)**、**本公司股东应占溢利(单季,亿元)**（均由累计利润表推导）。
- 其余文件复用同一张单季表（全看板口径一致）。

### Sheet3 · 数据来源与口径说明
- 纯文本逐行说明：数据来源、单位、核心口径（H 股营业额 vs A 股营业收入差异、红筹口径、EBITDA 算法）、2025 实时抓取覆盖、事件驱动项（服务增值税 9%）、行情依赖字段说明，以及"抓取时间"戳。

## 6. 口径与处理原则

1. **H 股 vs A 股口径**：营业收入统一采用 H 股"营业额"（经营收入），与港交所年报披露及业绩发布会一致（如 2025=5296 亿）；A 股合并利润表"营业收入"为较窄列报，2020–2025 约低 57 亿（如 2025=5239 亿），二者为同一合并主体不同列报口径。净利润采用 H 股"本公司股东应占溢利"（=A 股归母净利润），红筹口径下二者一致（不同于中国联通 H/A 差异大）。
2. **`—` 处理**：所有未能在权威来源核验的年份统一填 `None`，写入 XLSX 显示为 `—`，**绝不编造**。待补年份已在备注标注（如 2021 服务收入/用户/ARPU、2023/2025 IDC、2025 智算/5G 基站、2020-2021 股息等）。
3. **实时抓取覆盖**：2025 年 revenue/net_profit/eps/ebitda/ar/debt_ratio 以 `fetcher.build_fetched_snapshot()` 实时返回为准，运行日志打印 `[reconcile] 2025 X 已用实时抓取覆盖 = …`。
4. **单季推导**：季报数据由累计利润表算术推导，2026Q1 因跨财年累计归零单独计；单季营收求和自洽等于全年营收。
5. **行情依赖字段**：股息率/股息利差需刷新行情快照（EM_QUOTE）后回填，本地存储预留字段，当前为空。

## 7. 运行方式

```bash

cd china-telecom/data_pipeline
python run.py          # 实时抓取 → 组装 → 生成 5 个 XLSX 至 ../

# 仅测试抓取（校验接口可达性与字段）
python -c "import fetcher as F; print(F.build_fetched_snapshot())"
```

- 依赖：`openpyxl`、`requests`（项目隔离 venv：`~/.workbuddy/binaries/python/envs/default`）。
- 网络：Eastmoney 接口需联网；失败自动回退 `cache/`，`reconcile` 失败保留已核验值。
- 产出：`china-telecom/中国电信_*.xlsx`（5 个），每个含三 sheet。
