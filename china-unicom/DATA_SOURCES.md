# 中国联通（00762.HK）数据本地存储 · 来源 / 字段 / 结构说明

> 本目录下的数据，按 **中国移动（china-mobile）业绩追踪看板** 的本地存储规范实现：
> 每个维度一个 `.xlsx`，每张表含 **年报数据 / 季报数据 / 数据来源与口径说明** 三张 sheet；
> 抓取代码位于 `data_pipeline/`，从权威数据源真实抓取并持久化。

---

## 1. 概述

- **标的**：中国联合网络通信(香港)股份有限公司（中国联通 H 股，代码 **00762.HK**）。
- **合并口径**：00762.HK 与 A 股 600050.SH 为同一合并主体。本数据集**净利润采用 H 股合并口径**
  （"本公司权益持有者应占盈利"，2025 = 208.16 亿元），与 A 股归母净利润（约 90 亿）口径不同，
  差异源于红筹结构（详见第 5 节）。
- **年份口径**：2020–2025 全年；2026 为计划/中报值，单列于季报 sheet 或备注。
- **币种**：人民币。金额单位亿元（每股指标为元/股，比率见列名）。
- **真实性原则**：能机器抓取的（H 股最新年度利润表/资产负债表、A 股历史营收、行情）由代码实时抓取；
  运营 KPI 与历史年度序列来自**港交所披露易（HKEXnews）历年年报/业绩公告**等一手披露，逐字段标注来源；
  无法核验的年份一律显示 `—`，不臆造。

## 4. 存储结构与格式

```
china-unicom/
├── data_pipeline/                 # 抓取与持久化代码
│   ├── config.py                  # 标的、年份、路径、Eastmoney 接口常量
│   ├── sources.py                 # 数据来源登记表（SOURCES）
│   ├── fetcher.py                 # 真实 HTTP 抓取（Eastmoney HK/A 财报 + 行情）+ 缓存
│   ├── annual_report_data.py      # 已核验年报指标（METRICS，逐字段标注 source）
│   ├── transform.py               # 抓取值覆盖 2025 + 组装 5 文件表结构 + 单季推导
│   ├── store.py                   # openpyxl 写入（三 sheet，与中国移动同款样式）
│   ├── run.py                     # 入口：抓取→合并→持久化
│   └── cache/                     # 原始接口响应 JSON（可追溯）
├── 中国联通_财务健康与盈利质量.xlsx
├── 中国联通_核心业务运营与结构转型.xlsx
├── 中国联通_资本开支与基础设施.xlsx
├── 中国联通_客户生态与政企业务.xlsx
├── 中国联通_宏观政策与股东回报.xlsx
└── DATA_SOURCES.md                # 本说明
```

**XLSX 三 sheet 规范**（与中国移动一致）：
- **年报数据**：指标为行、年份(2020–2025)为列，末列"备注"（含单位与来源 Key）。
- **季报数据**：单季口径（由累计利润表推导：Q1=一季报，Q2=H1−Q1，Q3=Q3−H1，Q4=全年−Q3；跨入新财年累计归零）。
- **数据来源与口径说明**：逐文件列出权威来源、口径、无法核验项的说明与抓取时间。

## 5. 口径与可追溯性说明

1. **H 股 vs A 股净利润**：00762.HK 是合并上市主体，披露"本公司权益持有者应占盈利"（全集团净利，2025=208.16 亿）；
   A 股 600050.SH 归母净利润为母公司口径（约 90 亿）。本看板统一用 **H 股合并口径**，与移动看板一致。
2. **营收一致性**：A 股宽表（`EM_A_F10_INCOME`）营收与 H 股合并营收金额一致，故 2020–2025 营收历史取自 A 股宽表。
3. **实时抓取优先**：运行 `run.py` 时，2025 年的营收/净利/EPS/应收账款/资产负债率/EBITDA 由 Eastmoney 实时抓取并覆盖已核验值（见控制台 `[reconcile]` 日志）。
4. **`—` 处理**：未能在权威来源核验的年份显示为 `—`，待补公司历年年报（如移动 ARPU、5G 套餐用户绝对数、2020–2022 服务收入等）。
5. **行情依赖字段**：股息率(TTM)、股息利差需刷新 00762.HK 行情快照与 10 年期国债收益率后在文件 5 回填（预留字段）。

## 6. 运行方式

```bash
cd china-unicom
python data_pipeline/run.py        # 需隔离 venv：pip install openpyxl requests
```

依赖：Python 3.9+，`openpyxl`、`requests`（已装入 `china-unicom` 隔离环境）。
运行后重新生成 5 个 XLSX，并在控制台打印实时抓取覆盖日志与生成路径。
