# 应收账款增速差（指标说明）

## 一、指标定义

**应收账款增速差**是指企业**应收账款增长率**与**营业收入增长率**之间的差额，用于衡量二者增长节奏的偏离程度。

- 当应收账款增速快于营业收入增速（差值为正且扩大）时，说明收入的「账面增长」明显快于「回款增长」；
- 当二者增速趋同或应收增速低于营收增速（差值收窄或为负）时，说明回款节奏与收入节奏基本同步甚至更优。

该指标本质上是一个**结构性背离信号**，用以透视收入增长的质量与可持续性，而非单纯看规模增长。

## 二、指标意义

### 1. 反映企业回款能力与收入质量
指标的偏离方向直接体现「账面收入」转化为「真实现金」的效率。增速差越大，越提示收入中含「未回款」的部分偏高，收入含金量相对下降。

### 2. 增速差扩大：警惕信用政策放松与回款恶化
增速差持续走阔可能意味着：
- **信用政策放松**：为冲收入而延长账期、放宽赊销条件；
- **赊销占比上升**：新增收入中赊销比例提高，现金回笼滞后；
- **回款恶化**：下游客户付款能力或意愿下降，应收账款积压。

这三种情形都会推高营运资金占用与坏账风险，是经营质量走弱的先行信号。

### 3. 增速差收窄或为负：回款改善与收入确认质量提升
增速差收窄、归零甚至转负，通常表明：
- 回款节奏快于收入确认节奏，现金回笼改善；
- 收入确认更审慎、赊销管控更严格；
- 整体收入质量与盈利「含金量」提升。

### 4. 使用要点
- 该指标应结合**绝对值水平**与**趋势变化**一并观察，单期数值意义有限；
- 需区分行业季节性、大客户结算节奏等结构性因素，避免误读；
- 建议与「经营现金流 / 营收」「应收账款周转天数」等指标交叉验证。

## 三、计算公式

### 核心公式

```
应收账款增速差 = 广义应收账款增速 − 营业收入增速
```

### 分步拆解与计算方法

为得出最终的增速差，需要分别通过报表计算以下三个数值：

#### 1. 确认「广义应收账款」的基数

单纯的「应收账款」科目无法完全涵盖已确认收入但未结款的政企项目，因此必须加上「应收票据」和「合同资产」。

```
广义应收账款 = 应收账款 + 应收票据 + 合同资产
```

#### 2. 计算「广义应收账款增速」

使用资产负债表（Balance Sheet）中的期末数据与去年同期数据进行对比。

```
广义应收账款增速 = (本期期末广义应收账款 − 去年同期期末广义应收账款) / 去年同期期末广义应收账款 × 100
```

#### 3. 计算「营业收入增速」

使用利润表（Income Statement）中的当期累计数据与去年同期数据进行对比。

```
营业收入增速 = (本期营业收入合计 − 去年同期营业收入合计) / 去年同期营业收入合计 × 100%
```

### 变量说明

| 变量 | 含义 | 取值说明 |
| --- | --- | --- |
| 应收账款增速差 | 应收与营收增速的偏离度 | 结果为正表示应收增长快于营收；为负表示慢于营收 |
| 广义应收账款 | 应收账款 + 应收票据 + 合同资产 | 使用资产负债表期末余额；建议采用净额口径，序列内保持一致 |
| 广义应收账款增速 | 广义应收账款的同比增速 | 本期期末广义应收与去年同期期末广义应收对比 |
| 营业收入增速 | 营业收入的同比增速 | 利润表当期累计收入与去年同期累计收入对比 |
| 本期期末广义应收账款 | 观察期末的广义应收账款余额 | 取自资产负债表 |
| 去年同期期末广义应收账款 | 对比基期的广义应收账款余额 | 去年同期同一报告期 |
| 本期营业收入合计 | 观察期内的营业收入累计额 | 取自利润表 |
| 去年同期营业收入合计 | 对比基期的营业收入累计额 | 去年同期同一报告期 |

### 口径提示
- **广义应收账款口径**：建议采用净额（已扣除坏账准备），且序列内保持一致；
- **期间对齐**：应收账款期末余额与营业收入累计数据必须取自同一报告期（同为年度或同为累计季报），否则差值无可比性；
- **符号约定**：增速差为正 → 应收增速快于营收（偏负面信号）；为负 → 应收增速慢于营收（偏正面信号）。
